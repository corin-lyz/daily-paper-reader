## 摘要
前馈3D高斯泼溅（3DGS）能够实现高效且可泛化的3D重建，但当前用于场景理解的前馈3DGS方法在很大程度上仍是面向类别的。相比之下，实例感知的3DGS方法通常依赖逐场景优化，且往往将重建与实例和语义学习解耦，限制了它们之间的相互促进作用。我们提出了InstanceSplat，一个统一的前馈3DGS框架，用于从无位姿的多视角图像中进行可泛化的3D重建和实例感知的场景理解。在单次前向传播中，InstanceSplat构建了一种实例感知的高斯表示，联合编码外观、几何、实例身份和语言对齐的语义。共享的3D高斯跨视角锚定实例身份，生成可渲染且跨视角一致的实例特征。为了让重建和场景理解相互受益，我们进一步设计了一种以实例为中心的学習策略，通过共享实例结构将重建、实例学习和语义学习连接起来。具体而言，实例线索指导重建，语言对齐的语义增强对易混淆同类实例的判别能力，实例区域将语义证据聚合为连贯的物体级预测。在不同输入视角设置和未见数据集上的新视角合成、实例分割和开放词汇语义理解实验表明，该方法达到了最先进的性能、实际效率高且泛化能力强。

## Abstract
Feed-forward 3D Gaussian Splatting (3DGS) enables efficient and generalizable 3D reconstruction, but current feed-forward 3DGS methods for scene understanding remain largely category-oriented. In contrast, instance-aware 3DGS methods typically rely on per-scene optimization and often decouple reconstruction from instance and semantic learning, limiting reciprocal interactions among them. We present InstanceSplat, a unified feed-forward 3DGS framework for generalizable 3D reconstruction and instance-aware scene understanding from pose-free multi-view images. In a single forward pass, InstanceSplat constructs an instance-aware Gaussian representation that jointly encodes appearance, geometry, instance identity, and language-aligned semantics. Shared 3D Gaussians ground instance identities across views, producing renderable and cross-view-consistent instance features. To allow reconstruction and scene understanding to benefit from each other, we further design an instance-centric learning strategy that connects reconstruction, instance learning, and semantic learning through shared instance structure. Specifically, instance cues guide reconstruction, language-aligned semantics strengthen the discrimination of confusing same-category instances, and instance regions aggregate semantic evidence into coherent object-level predictions. Experiments on novel-view synthesis, instance segmentation, and open-vocabulary semantic understanding under varying input-view settings and on an unseen dataset demonstrate state-of-the-art performance, practical efficiency, and strong generalization.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 整体框架
InstanceSplat由三部分组成：
1. **实例感知高斯表示构建**（Instance-Aware Gaussian Representation）
2. **3D一致实例接地**（3D-Consistent Instance Grounding）
3. **实例中心耦合**（Instance-Centric Coupling）

### 2.2 实例感知高斯表示
- **公式化定义**：给定N张无位姿输入图像，前馈网络F预测相机参数、深度图、点图及稠密高斯集：
  `F: {Ii} → {(ti, Di, Pi)}, G`
- **骨干网络**：采用VGGT（预训练DINOv2 + 24层Transformer），含视图内与跨视图注意力；DPT风格解码器预测相机参数、深度和点图，第二个DPT解码器回归高斯属性与紧凑语义特征；实例解码器（借鉴IGGT）预测像素对齐的8维实例特征图。
- **高斯表示**：每个像素生成一个高斯原语，组合位置μ、旋转R、尺度s、颜色c、不透明度α、置信度C、实例嵌入S∈R⁸和语义特征L∈R^(d_s)：
  `G = {(μ_k, R_k, s_k, c_k, α_k, C_k, S_k, L_k)}`
- **体素化压缩**：借鉴AnySplat的置信度感知体素化策略，合并冗余原语得到紧凑的体素对齐高斯集G'，同时融合实例嵌入和语义特征。

### 2.3 3D一致实例接地
- **可微渲染**：对体素化高斯的实例嵌入执行与RGB渲染相同的alpha合成，得到渲染的实例特征图 S̃i = R_ins(G', t_i)。
- **原型对比学习**（核心损失，公式5-8）：
  - **Pull项**：使每个像素特征与其所在实例原型（实例内像素特征平均后L2归一化）靠近：`L_pull = [‖f_i(p) − f̄_k^(i)‖₂ − δ_pull]₊`
  - **Push项**：使不同实例原型彼此分离：`L_push = [δ_push − ‖f̄_k^(i) − f̄_l^(i)‖₂]₊`
  - **Cross项**：对齐跨视图同一实例的原型（跨视角一致性）：`L_cross = [‖f̄_k^(i) − f̄_k^(j)‖₂ − δ_cross]₊`
  - 总损失：`L_ins = λ_pull·L_pull + λ_push·L_push + λ_cross·L_cross`
- **关键机制**：由于不同视角通过同一组3D高斯耦合，图像空间的实例监督能在3D中建立一致的实例身份。

### 2.4 实例中心耦合
- **边界感知重建**（公式9-11）：
  - 由像素对齐实例特征计算局部余弦距离最大值，得到边界分数ri(p)，经局部膨胀和sigmoid映射为软边界权重bi(p)；
  - 边界权重加权Charbonnier RGB损失：`L_bd-rgb = (1/N)Σ_i [Σ_p b_i(p)ρ_i(p)] / [Σ_p b_i(p)]`
  - 效果：实例边界处获得更大的重建监督权重，改善深度不连续处的几何和RGB合成质量。
- **语义引导的实例判别**：
  - 渲染紧凑语义特征并经投影层映射到语言对齐教师空间（`E_i(p) = Φ_sem(L̃_i(p))`），用余弦距离损失对齐LSeg教师特征（`L_sem`）；
  - 构造实例级语义原型，计算实例间语义相似度η^(i)_(k,l)，并将其用于push项的加权（公式15）：语义相似（易混淆的同类实例）的实例对获得更大的分离权重，从而强化同类不同实例的判别。
- **实例接地语义聚合**（推理阶段）：
  - 渲染实例和语义特征图，用HDBSCAN聚类归一化实例嵌入得到物体区域；
  - 在预测的实例区域内聚合对齐语义特征，得到物体级原型，再与文本嵌入比较分配开放词汇标签。
  - 效果：抑制局部语义噪声，产生物体内语义一致的预测且保持实例边界。

### 2.5 总体训练目标
`L = L_rgb + L_distill + λ_ins·L_ins + λ_sem·L_sem + λ_bd·L_bd-rgb`
其中L_rgb包含MSE与感知损失，L_distill约束预测几何（位姿和深度）与几何基础模型的伪监督一致。

## 6. 论文的主要结论与发现

- InstanceSplat在单次前向传播中构建实例感知高斯表示，实现联合重建与实例级场景理解，在ScanNet上所有视图设置下均取得最佳PSNR和LPIPS，且mIoU在所有非消融方法中最高。
- 实例特征经共享3D高斯渲染式监督后具备跨视角一致性：T-mIoU 64.03和T-SR 51.04，优于IGGT（61.99/45.15）。
- 在未见数据集LERF上优于逐场景优化的OpenGaussian和InstanceGaussian（8视图mIoU 63.22 vs 26.23/10.72），同时推理速度提升约3个数量级。
- 消融验证了：
  1. 共享3D高斯是建立一致实例身份的有效3D载体；
  2. 联合优化高斯几何/不透明度能提升实例区域质量和渲染效果；
  3. 语义引导的硬负样本重加权能改善同类实例判别；
  4. 实例接地语义聚合能产生更连贯的物体级语义预测；
  5. 边界感知重建能有效改善深度不连续处几何（RMSE 0.1985 vs 0.2375，AbsRel 0.0911 vs 0.0995）。

## 7. 优点

- **统一性**：首次在前馈框架中用共享3D高斯同时承载几何、外观、实例身份和语言语义，实现"重建即理解"。
- **互惠耦合设计**：实例结构作为重建与语义的共享接口，三个方向（重建、实例学习、语义学习）互相增强，而非简单拼接。
- **跨视角一致性**：通过在共享3D高斯的渲染空间中施加跨视图原型对齐，实例特征天然具备3D一致性和可渲染性。
- **高效实用**：单次前馈、约3秒推理，对比逐场景优化方法（数十分钟到数小时）在效率和泛化上均有显著优势。
- **不依赖位姿**：无需SfM或已知相机参数，直接从多视图图像联合预测位姿与表示。
- **实验验证充分**：在多个设置（视图数、数据集、任务）下系统评估，消融实验覆盖面广。

## 8. 不足与局限

- **聚类开销**：作者自述，推理时HDBSCAN特征聚类随着视图数和高斯数量增加而变昂贵，限制大规模场景的扩展性。
- **跨数据集的域偏移**：在LERF上从8视图增加到16视图时性能下降，推测原因是域偏移导致姿态精度下降、跨视图错位累积，说明对分布外数据的鲁棒性仍需提高。
- **场景类型覆盖有限**：训练和评测均为室内场景，未验证室外或大规模场景的泛化能力。
- **类别不平衡影响**：部分设置下（如4视图mAcc略低）受目标视图采样导致的类别不平衡影响，宏平均指标波动较大。
- **与IGGT对比范围受限**：IGGT不支持NVS，因此只比较了上下文视图上的实例一致性，未在完整NVS场景下对比。
- **对教师语义特征的依赖**：语言对齐语义依赖LSeg等预训练教师，其固有权衡可能限制开放词汇性能的进一步提升空间。
