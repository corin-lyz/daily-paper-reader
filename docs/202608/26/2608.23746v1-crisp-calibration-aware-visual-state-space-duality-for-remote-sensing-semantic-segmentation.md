## 摘要
状态空间模型，尤其是视觉状态空间对偶（VSSD），已成为用于密集视觉任务的Transformer的高效线性时间替代方案。然而，我们观察到VSSD将空间上下文压缩为全局聚合，抑制了高频响应，导致遥感语义分割中边界过度平滑。为解决这一问题，我们提出了CRISP，一个包含两个组件的校准框架。其核心，对偶校准算子（DCO），通过残差注入和频率校准在VSSD主干网络中恢复局部对比度和边界响应，且不改变其线性复杂度。为保留恢复的细节，一个正交多原型（OMP）头为每个类别分配多个正交约束的原型，以建模较大的类内方差。在Potsdam、Vaihingen和LoveDA上进行的大量实验表明，在大约30M参数的情况下，CRISP在平均F1（mF）和mIoU上取得了持续改进，同时与最先进方法保持竞争力。代码可在https://github.com/crazylifeha/CRISP获取。

## Abstract
State space models, especially Visual State Space Duality (VSSD), have emerged as efficient linear-time alternatives to Transformers for dense visual tasks. However, we observe that VSSD compresses spatial context into a global aggregation that suppresses high-frequency responses, causing excessive boundary smoothing in remote sensing semantic segmentation. To address this, we propose CRISP, a calibration framework with two components. Its core, the Duality Calibration Operator (DCO), restores local contrast and boundary responses through residual injection and frequency calibration within the VSSD backbone, without altering its linear complexity. To retain the recovered detail, an Orthogonal Multi-Prototype (OMP) head assigns multiple orthogonally constrained prototypes per class to model large intra-class variance. Extensive experiments on Potsdam, Vaihingen, and LoveDA show that, with approximately 30M parameters, CRISP achieves consistent gains in mean F1 (mF) and mIoU while remaining competitive with state-of-the-art methods. Code is available at https://github.com/crazylifeha/CRISP.

- **VSSD的局限**：视觉状态空间对偶（VSSD）作为Mamba-2/SSD的视觉扩展，通过多方向扫描和全局聚合机制实现了线性复杂度。但论文实证发现：VSSD将空间上下文压缩为全局位置无关聚合，类似于一个低通滤波器，**系统性抑制高频响应**，导致边界过度平滑（over-smoothing），在遥感分割中表现为边界模糊、细薄结构丢失。
- **实证证据**：论文通过边界敏感指标（Boundary F-score）和特征频谱能量比（E_high/E_low，对中间层做2D FFT）两个视角验证了上述现象——高频能量比随骨干网络层数加深逐层衰减。
- **核心挑战**：如何在不牺牲VSSD线性复杂度的前提下，校准被抑制的高频信息和局部对比度，同时保留恢复出的类内多模态细节。

## 2. 方法论：核心思想、关键技术细节

### 整体框架
CRISP包含两个核心组件：骨干内的**对偶校准算子（DCO）**和轻量解码器中的**正交多原型（OMP）分割头**，二者协同作用，从像素级特征到最终分类共同保留类内多模态结构。

### 2.1 问题建模与频率分析
- SSD输出可视为带距离衰减核的线性注意力形式：y_i = Σ_{j≤i} κ(i,j)⟨c_i, b_j⟩v_j。
- VSSD将严格因果的多方向扫描放宽为全局归一化聚合的近似形式：ŷ_i ≈ (Σ_j w_{i,j} v'_j) / (Σ_j w_{i,j})。
- 频率分析表明：当融合权重在大感受野内平滑变化时，加权求和会平均掉零均值的高频振荡分量ε_j，因而输出中的高频能量衰减——即归一化聚合等效为低通滤波。

### 2.2 对偶校准算子（DCO）
DCO插入在每个VSSD块融合操作之后，包含三个近恒等校准步骤：

1. **状态级残差注入**（恢复值重缩放中被去除的对比度）：
   - 残差提取：Δv_j = v_j − v'_j；
   - 复用已算出的核化键/查询统计量，线性时间累积 S_Δ = Σ_j k_j Δv_j^T（k_j = ψ_v(b_j)）；
   - 按查询特征读出残差 r_i ≈ q_i^T S_Δ（q_i = ψ_v(c_i)），并通过小增益近恒等门注入：ỹ_i = ŷ_i + (ε + λ_h) ⊙ r_i，λ_h初始化为0.01。
   - 核函数采用 ψ_v(x) = ELU(x) + 1（保证内积非负），S_Δ共享于所有查询位置，一次计算，无二次交互。

2. **Token级高通调制**（增强去均值后的边界响应）：
   - y'_i = ỹ_i + ω_h ⊙ (ỹ_i − μ)，其中 μ 为序列均值，ω_h初始化为0.01。

3. **通道级DC/HC重平衡**（重新分配低频语义与高频细节间的通道能量）：
   - 将输出分解为均值分量（Y_dc）和波动分量（Y_hc）：Y_out = (1 + s) ⊙ Y_dc + (1 + t) ⊙ Y_hc，s、t初始化为0.01。

所有门均从零（近恒等）开始，避免破坏预训练骨干，额外参数O(H+D)，几乎可忽略。

### 2.3 正交多原型（OMP）解码头
- **动态Token生成**：通过双路径全局池化（max+avg）提取通道统计，经共享MLP融合生成内容自适应查询权重，再从学习的原型嵌入库中通过加权Einsum组合出动态类Token；随后与空间特征进行堆叠的双向交叉注意力细化。
- **超原型匹配**：由超网络将细化后的类Token映射为每类K个原型 P ∈ R^{B×|C|×K×d_h}；像素描述符与归一化原型做最大响应匹配：z_{c,i} = max_{1≤k≤K} ⟨Û_i, P̂_{c,k}⟩，使不同子原型可特化到不同类内模态。
- **双重原型正则化**：
  - 类内正交性 L_orth 惩罚冗余子原型；
  - 类间角度间隔 L_margin 强制类中心之间保留margin δ。
  - 总损失：L_total = L_seg + λ_orth L_orth + λ_margin L_margin。

## 6. 主要结论与发现

- VSSD的全局归一化聚合等效于低通滤波，会系统性抑制高频响应，这是遥感分割中边界过度平滑的机制性根源。
- DCO通过状态级残差注入+Token级高通调制+通道级DC/HC重平衡三层次校准，在不增加渐近复杂度（保持O(L)）、不显著增加参数的前提下，有效恢复衰减的高频信息。
- OMP头通过正交约束的多原型匹配，把DCO恢复出的类内多模态结构保留到最终分类，避免单原型分类器将类内差异坍塌到一个方向。
- **DCO为主、OMP为辅**的因果关系明确：OMP脱离DCO时性能不如基线（85.63 vs 87.32），而DCO先修复特征后OMP才发挥增益（最高88.25），说明多原型匹配是特征可分离性的受益者而非替代者。
- CRISP以约30M参数在三个遥感分割基准上达到与SOTA相当甚至更优的精度，准确率-效率权衡明显优于先前的Mamba类方法。

## 7. 优点

- **问题定位精准**：从SSD对偶形式和VSSD全局聚合的数学结构出发，用频率分析机制性地解释过平滑来源，而非仅凭经验观察。
- **设计高度轻量且优雅**：DCO复用骨干已算出的聚合统计量，不引入额外的二次交互或独立频谱分支，额外参数不到10^-3M，实现“校准”与“线性复杂度”兼得；门控近恒等初始化，不破坏预训练模型。
- **第一性创新**：首次直接校准SSM聚合本身而非外部添加频谱分支或解码端融合模块，与骨干拓扑/扫描路径正交，易嵌入其他VSSD变体。
- **解码器设计有理论依据**：OMP结合类内正交、类间角间隔与互信息目标，端到端学习子原型，避免离线聚类与对比训练的工程复杂性。
- **实验设计细致**：子组件消融、协同消融、边界带宽诊断、跨数据集mBF和原型数敏感性相互支撑，论证链条完整；消融顺序和因果解释（DCO→OMP→正则）逻辑清晰且令人信服。
- **效率优势显著**：相比VSSD基线FLOPs从235.65G降至64.80G、参数量从56.10M降至32.32M、FPS从39.1提升至45.4，同时精度更高。

- **外部对比的公平性细节**：所有模型在统一协议下重新训练，但对比方法的超参是否逐一调优未说明，不能完全排除对CRISP相对有利的调参偏差。
