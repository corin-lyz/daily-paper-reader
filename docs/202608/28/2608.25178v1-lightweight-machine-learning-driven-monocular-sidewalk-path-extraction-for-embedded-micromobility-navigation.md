## 摘要
人行道尺度的路径提取需要在杂乱、地图稀疏的环境中，于紧凑、低功耗硬件上可靠运行的感知与规划。我们提出了一种用于微出行系统的单目视觉人行道路径提取管道，该管道经历了三次设计迭代，从骨架图基线，到距离变换走廊规划，再到轻量级图像空间架构，并提供了五种路径规划方法在鸟瞰图（BEV）和图像空间两个域中的系统性比较。一个紧凑的SegFormer-B0学生模型，使用OneFormer Swin-L伪标签通过半监督师生框架训练，实现了0.946的手动标注IoU，每帧11.7毫秒，优于基线检查点（IoU 0.758，18.9毫秒）。在32个手动标注帧的受控规划器比较中，图像空间中点规划实现了最低的横向中心误差（14.3像素），耗时2.2毫秒，相比BEV距离变换规划（926.8毫秒，中心误差65.0像素）实现了421倍加速，同时保持了相当的掩膜-路径对齐（98.5%对98.6%）。对六个校园序列（22,679帧）的全视频回放证实，改进的分割将时间不稳定性从1.46%降至0.33%，并将模板路径可用性从73.7%提高到79.3%。我们进一步表明，仅BEV的路径提取在单目设置中很脆弱：在一次剖面运行中，99.3%的帧未产生有效的BEV路径。最终推荐的架构——图像空间中点主用、图像空间距离变换备用、BEV保留用于可视化——在CPU上以每帧低于50毫秒的时间运行完整的感知到路径堆栈，使其适用于嵌入式行人速度微出行系统。

## Abstract
Sidewalk-scale path extraction demands perception and planning that run reliably on compact, low-power hardware in cluttered, map-sparse environments. We present a monocular vision pipeline for sidewalk path extraction in micromobility systems that progresses through three design iterations, from a skeleton-graph baseline through distance-transform corridor planning to a lightweight image-space architecture, and provides a systematic comparison of five path-planning methods across both bird's-eye-view (BEV) and image-space domains. A compact SegFormer-B0 student model, trained with a semi-supervised teacher-student framework using OneFormer Swin-L pseudo-labels, achieves a hand-annotated IoU of 0.946 at 11.7 ms per frame, improving over the baseline checkpoint (IoU 0.758, 18.9 ms). In a controlled planner comparison on 32 hand-labeled frames, image-space midpoint planning achieves the lowest lateral center error (14.3 px) at 2.2 ms, a 421x speedup over BEV distance-transform planning (926.8 ms, 65.0 px center error), while maintaining comparable mask-path alignment (98.5% versus 98.6%). A full-video replay across six campus sequences (22,679 frames) confirms that the improved segmentation reduces temporal instability from 1.46% to 0.33% and increases template-path availability from 73.7% to 79.3%. We further show that BEV-only path extraction is fragile in monocular settings: in one profiled run, 99.3% of frames produced no valid BEV path. The final recommended architecture, image-space midpoint primary, image-space distance-transform fallback, and BEV reserved for visualization, runs the full perception-to-path stack in under 50 ms per frame on CPU, making it suitable for embedded pedestrian-speed micromobility systems.

## 2. 论文提出的方法论

**总体架构：** 模块化单目视觉管道，包含四个阶段：语义分割 → 可选 BEV 投影 → 路径规划（五种方法比较）→ 航点平滑。系统经过三次向后兼容的设计迭代演进。

**核心技术细节：**

**（1）分割模块与半监督训练策略**

- **学生模型：** SegFormer-B0（3.7M 参数），输入分辨率 640×360。
- **教师模型演进：**
  - 迭代 1：SegFormer-B2（24M 参数），在 300 帧手标注数据上微调，为 2,300 帧未标注数据生成伪标签。
  - 迭代 2：OneFormer Swin-L（ADE20K 预训练），为最多 1,419 帧未标注数据生成密集二值伪标签。
- **伪标签生成公式：** 教师预测像素级 logits 后经 softmax 转概率，以置信度阈值 τ=0.60 产生二值掩膜（见论文式(1)），再经连通分量滤波和形态学平滑清理。

- **混合训练集：** D = DL ∪ DP，合并手标注与伪标注帧，手标注优先。
- **损失函数：** L = LWCE + LDice，加权交叉熵损失 + Dice 损失。
- **优化配置：** AdamW，初始学习率 5×10⁻⁵，batch size 4，训练 10 epoch，10% 线性预热 + 余弦衰减。

**（2）BEV 投影**

- 通过平面单应性 H，将图像像素 p 映射到 BEV 坐标 p′（p′ ~ Hp）。
- 假设：地面平坦、相机位姿固定——该假设在实验中受到检验并发现不可靠。

**（3）BEV 掩膜精化：** 形态学闭运算与开运算 → 连通分量滤波（仅保留接触 ego 锚点的最大连通区域）→ 可选增强（洪泛填充孔洞、高斯边界平滑、基于距离变换的分量选择）。

**（4）五种路径规划方法**

| 域 | 方法 | 核心思想 |
|---|---|---|
| BEV | 骨架图规划器 | Guo–Hall 并行细化 → 像素级图构建 → 两阶段剪枝 → Dijkstra 路径枚举，按曲率 + 横向偏移评分 |
| BEV | 距离变换脊规划器 | 欧氏距离变换 (EDT) → 代价场 c=1/(d+ε)^α → Dijkstra 全局最大净空路径 → Savitzky–Golay 平滑 |
| BEV | 模板弧规划器 | 固定弧模板库（直行、左/右缓弯、左/右急弯）→ 走廊包含度评分 → 置信门控，失败时回退 DT 脊 |
| 图像空间 | 中点规划器 | 逐行计算左右边界中点 → 少于最小像素数的行跳过 → Savitzky–Golay 平滑 |
| 图像空间 | 距离变换规划器 | 图像平面 EDT → 带横向漂移约束的动态规划前向扫描 → 追踪最宽走廊的脊线 |

**（5）时间平滑：** 路径级 EMA（自适应 α：高置信 0.85，低置信 0.35，拓扑变化检测器重置）+ 航向角循环 EMA（±180° 环绕处理，Δ>45° 时重置）。

## 6. 论文的主要结论与发现

**核心结论：**

1. **半监督训练显著提升分割质量：** OneFormer Swin-L 教师训练的 SegFormer-B0 将手标注 IoU 从 0.758 提升至 0.946（+24.8%），同时推理时间从 18.9ms 降至 11.7ms（38% 加速）。精度从 0.910 → 0.983，召回从 0.835 → 0.962。

2. **图像空间中点规划是最优主规划器：** 横向中心误差 14.3px（优于 BEV 最优 65.0px 约 4.5 倍），延迟 2.2ms（相对 BEV DT 的 926.8ms 实现 421 倍加速），掩膜-路径对齐率 98.5%（与 BEV 的 98.6% 相当）。

3. **图像空间 DT 是最优后备规划器：** 最高 inside-GT 比率（99.4%），108.1ms 仍比 BEV DT 快 8.6 倍。

4. **BEV 规划方法在单目行人场景中整体不具竞争力：**
   - 运行时：骨架图 380.3ms，BEV DT 926.8ms，近场 BEV DT 更慢（1,603ms）。
   - 精度：BEV 最优方法中心误差 65.0px，远高于图像空间的 14.3px。
   - 近场 BEV DT 因近场图构建更密集而更慢（反直觉）。

5. **BEV 在单目下根本性脆弱：** 4,407 帧剖面中 99.3% 无有效 BEV 路径（BEV 掩膜平均占用率 0.0002）。Oracle 实验证明这是单目 BEV 几何问题而非分割质量问题——即使使用真实掩膜，BEV DT 精度（69.2px）仍差于图像空间 DT（62.5px）。

6. **时间稳定性显著改善：** 不稳定率从 1.46% 降至 0.33%（77% 相对下降），模板路径可用率从 73.7% 提升至 79.3%，回退率从 19.0% 降至 14.3%。

7. **端到端性能达标：** 推荐架构（图像空间中点主 + 图像空间 DT 备 + BEV 仅可视化）在 CPU 上达到 59.2 FPS（16.9ms/帧），全栈小于 50ms，适合行人速度嵌入式平台。

## 7. 优点

**方法设计亮点：**

- **模块化与可解释性：** 每个阶段产生可检查的中间表示，现场团队无需重训练模型即可检查和调优各阶段。
- **三次向后兼容迭代：** 设计演进清晰且可对比，每次迭代都保持与上一版兼容，实现受控比较。
- **半监督训练策略务实高效：** 用大规模预训练教师（OneFormer Swin-L）为轻量学生模型提供丰富伪标签，显著减少人工标注负担，同时大幅提升学生模型性能。
- **多层次对比设计：** 2 个规划域 × 5 种规划器 + oracle 掩膜实验，系统性地回答了"规划域 vs. 分割质量"的因果问题。

**实验设计亮点：**

- 全视频回放验证 32 帧手标注结果的泛化性，避免小样本偏差。
- Oracle 实验隔离了分割与规划域的影响，增强了"BEV 脆弱性是几何问题"结论的因果性。
- BEV 占用率量化（0.0002）提供了 BEV 失败的直观、可测的物理原因证据。

**结果呈现亮点：**

- 惊人对比（421 倍加速、99.3% 失败率）直观、有冲击力且可复现。
- 运行时逐模块分解清晰，方便工程落地参考。

## 8. 不足与局限

**实验覆盖的局限：**

- 规划器比较仅基于 32 帧手标注帧，统计效力有限（作者自认需更大标注基准）。
- 全部数据来自单一校园环境，未验证城市街道、恶劣天气、夜间等场景的泛化性。
- 场景中虽有行人，但动态障碍物未显式建模——移动物体仅作为隐式不可通行掩膜，无预测与主动避让。

**方法层面的局限：**

- 单应性固定于单一相机位姿，相机安装偏移或震动需重新标定。
- 图像空间方法放弃了度量地面推理能力，无法直接输出真实世界距离（需事后换算）。
- 对宽交叉口/广场等弱边界场景，所有规划器均可能失败——分割无法解析人行道延续方向。
- 分割在明亮或低对比度区域存在边缘渗漏（虽然改进模型已显著减少）。

**系统与工程局限：**

- 无闭环部署验证——全部为离线评估，未在真实车辆上测试感知-规划-控制的端到端延迟和稳定性。
- 系统级分析中 YOLO 检测（CPU 上 39ms）是运行时瓶颈之一，但未与完整导航栈联合优化。
- 数据隐私限制：原始视频包含可识别行人，代码开源但数据无法公开，影响可复现性。

**风险与偏差：**

- 伪标签的置信度阈值（0.60）可能引入系统性偏差——低置信但正确的边界区域被丢弃。
- BEV 方法与图像空间方法之间的参数调优工作量可能存在不对称，BEV 方法的优势可能未完全发挥。
- 论文未报告随机种子数量或多轮重复实验的方差，尚不确定结果对初始化的稳定性。
