## 摘要
单目深度估计（MDE）在面对非朗伯表面和恶劣天气条件时，由于单图像有限信息中固有的视觉模糊性而面临挑战。现有工作通过图像修复或增强单独处理这些问题，导致鲁棒性提升有限。语言作为视觉的强大互补模态，已被证明可以通过详细的长描述增强视觉语言模型（VLM）的视觉感知能力。然而，先前的语言集成MDE方法由于文本输入短且信息有限、全局文本特征学习粗糙以及深度解码过程中语言引导不足，未能充分利用这一潜力。为解决这些局限性，我们提出了CapDepth，这是一种用于鲁棒MDE的新框架，利用详细长描述的引导来缓解挑战性场景中的视觉模糊性。首先，我们设计了一种详细的长描述输入模板，明确传达多个原子句子之间丰富的空间关系。其次，引入动态描述编码器，通过渐进式掩码注意力提取细粒度的深度相关文本特征。最后，我们提出了一种文本自适应解码器，通过稳定的自适应层归一化用文本特征引导增强的深度解码。大量实验验证了CapDepth的有效性，其性能优于最先进的方法，在非朗伯表面上深度误差减少了25.0%，在恶劣天气条件下减少了22.0%。

## Abstract
Monocular depth estimation (MDE) faces challenges with non-Lambertian surfaces and adverse weather conditions due to the visual ambiguities inherent in single-image limited information. Existing works address them in isolation via image inpainting or augmentation, yielding limited robustness gains. Language, as a powerful complementary modality to vision, is demonstrated to enhance the visual perception capabilities of vision-language models (VLMs) via detailed long captions. However, prior language-integrated MDE methods fail to fully harness this potential due to short text input with limited information, coarse global text feature learning, and limited language guidance during depth decoding. To address these limitations, we propose CapDepth, a novel framework for robust MDE that leverages guidance from detailed long captions to alleviate visual ambiguities in both challenging scenarios. First, we design a detailed long caption input template that explicitly conveys rich spatial relationships among multiple atom sentences. Second, a dynamic caption encoder is introduced to extract fine-grained depth-relevant text features via progressive masked attention. Finally, we propose a text-adaptive decoder that guides enhanced depth decoding with text features via stable adaptive layer normalization. Extensive experiments validate the efficacy of CapDepth, which outperforms state-of-the-art methods, achieving depth error reductions of 25.0% on non-Lambertian surfaces and 22.0% under adverse weather conditions.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：单目深度估计（MDE）是一个不适定、欠约束的问题，在非朗伯表面（如玻璃、镜子）和恶劣天气条件（如夜晚、雨雾）下，由于单张图像信息有限，存在严重的**视觉歧义**，导致现有深度估计方法性能显著下降。
- **现有方法困境**：
  - 通用MDE方法（如Depth Anything等）在常规场景表现优异，但难以处理纹理歧义与能见度歧义。
  - 已有的鲁棒MDE方法（如Depth4ToM针对透明/镜面、RobustDepth针对天气）均为**场景特定**方案，彼此孤立、泛化能力有限，无法统一应对多种挑战场景。
- **研究机会**：语言作为一种强大的互补模态，可以为视觉感知提供显式的场景理解线索；已有研究证明，**详细长描述（detailed long captions）** 比简单短文本更能增强视觉语言模型的感知能力。
- **核心问题**：能否构建一个**统一框架**，同时缓解非朗伯表面和恶劣天气带来的视觉歧义？作者指出先前语言集成MDE方法存在三个关键不足：
  - 使用简单短文本模板，信息量极为有限（如“a photo of a car”）；
  - 仅提取粗粒度的全局文本特征（如[CLS] token），丢失细粒度深度相关线索；
  - 深度解码过程缺乏文本引导，难以弥合噪声预测特征与几何推理需求之间的鸿沟。

### 2. 论文提出的方法论

#### 总体思路
提出 **CapDepth** 框架，通过三个核心模块实现详细长描述对MDE的深度引导，以同时缓解非朗伯表面与恶劣天气下的视觉歧义。

#### 核心组件一：详细长描述输入模板（Detailed Long Caption Input Template）
- **原子句模板**：以“对象A + 空间关系短语 + 对象B”的句式构造基本描述单元（如“The car is in front of the trees.”）。
- **模板构成**：将多个此类原子句堆叠成详细长描述，涵盖场景中大量物体间的丰富空间位置关系（如“behind”“in front of”“above”“below”等）。
- **生成方式**：使用 InternVL2.5-78B 视觉语言模型按模板生成描述文字。
- **语言学统计优势**：其“空间词占比”（0.34）远高于 VPD（0.02）和 WorDepth（0.09）；平均词数（45.25）也大幅超越前者（5.30 / 8.86）。

#### 核心组件二：动态描述编码器（Dynamic Caption Encoder）
- **目的**：从详细长描述中提取细粒度、深度相关的文本特征，避免粗粒度全局特征造成的信息损失。
- **技术细节**：
  - 用 CLIP 提取文本 token 特征 \(z_c \in \mathbb{R}^{n \times d_c}\)；
  - 通过 MLP + Sigmoid 预测每个 token 的深度相关性得分，并扩展为 \(n \times n\) 的软掩码 \(M\)；
  - 经过 \(L\) 个**渐进式掩码注意力块**（progressive masked querying blocks），使查询 \(Q^{(i)}\) 不断与掩码后的文本特征交互，公式为：
    \[
    Q^{(i)} = \mathrm{softmax}\left(\frac{Q^{(i-1)}W_Q(z_c W_K)^T \odot M}{\sqrt{d_k}}\right) z_c W_V
    \]
  - 最终得到细粒度文本特征 \(Q^{(L)}\)。
- **可视化验证**：注意力得分可视化显示，模型能自适应地对物体名词（如“bottle”）和空间关系短语（如“in front of”）赋予更大权重。

#### 核心组件三：文本自适应解码器（Text-Adaptive Decoder）
- **问题**：扩散 U-Net 的特征是为噪声预测而非几何感知优化的，存在特征语义鸿沟。
- **核心技术——稳定自适应层归一化（SAdaLN）**：
  - 将文本特征池化后经 MLP 生成缩放向量 \(a\) 和偏移向量 \(b\)，与图像特征 \(F\) 调制融合：
    \[
    \tilde{F} = \mathrm{LayerNorm}(F) \cdot a + b
    \]
  - 该过程在解码器中重复 \(N\) 次，逐步上采样，最终经 \(3\times3\) 卷积头回归深度图。
- **稳定性优化**：因为不同输入文本差异很大，导致 \(a\)、\(b\) 波动大、特征方差膨胀，作者通过 KL 散度正则约束 \(\tilde{F}\) 服从标准正态分布：
    \[
    \mathcal{L}_{\text{reg}} = -\log|a| + \frac{a^2 + b^2}{2} - \frac{1}{2}
    \]
  - 总损失为 \(\mathcal{L} = \mathcal{L}_{\text{ssi}} + \lambda \mathcal{L}_{\text{reg}}\)，有效稳定训练收敛。

- **指标与基准的局限性**：主要依赖 AbsRel 和 δ₁ 两个指标，未涉及更多度量（如尺度不变误差、边缘精度等），且部分基准样本量较小（如 nuScenes night-rain 仅 120 张）；
- **潜在偏差**：训练数据全为合成数据集（Hypersim、Virtual KITTI 2），真实场景的域适应能力虽通过零样本验证，但对特定真实场景的泛化作用仍受数据分布限制；
- **交叉验证不足**：论文提到“VPD/WorDepth 文本对 CapDepth 也有效”的实验中，分析了文本模板的效能，但未深入讨论同一文本模板在不同模型之间泛化时的符号对齐或语义漂移问题。
