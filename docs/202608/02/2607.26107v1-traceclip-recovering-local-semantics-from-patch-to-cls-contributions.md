## 摘要
密集视觉-语言理解，包括目标定位、区域识别和开放词汇语义分割，需要将语言概念与空间定位的视觉区域相关联。CLIP通过大规模对比预训练学习共享的图像-文本嵌入空间，为这些任务提供了强大的基础。然而，其图像级目标将文本与CLS衍生的全局表示对齐，使得局部视觉-语言对应关系仅得到间接约束。现有方法要么引入额外的监督、外部模型或任务特定适应，而无需训练的方法主要从现有补丁特征中恢复密集响应，而不检查CLIP中局部语义在何处最容易访问。我们提出了TraceCLIP，一种无需训练的框架，通过隔离写入CLS注意力输出中的补丁特定项来恢复潜在的补丁级语义证据。TraceCLIP进一步将贡献派生的语义响应转换为语义测地拓扑门，校准最终层补丁亲和力以进行密集特征重建。诊断实验表明，这些贡献特征表现出强烈的局部语义判别性和文本条件空间对齐。在八个零样本语义分割基准上，TraceCLIP在平均mIoU上比最强的先前无训练方法在两个骨干网络和背景设置中取得了1.3到4.5个百分点的提升，而无需额外训练、外部视觉基础模型或区域级监督。更广泛地说，这些发现表明，空间定位的语义可能在全局对齐表示的内部构造中仍然可访问。

## Abstract
Dense vision-language understanding, including object localization, region recognition, and open-vocabulary semantic segmentation, requires associating language concepts with spatially grounded visual regions. CLIP provides a strong foundation for these tasks by learning a shared image-text embedding space from large-scale contrastive pre-training. However, its image-level objective aligns text with a CLS-derived global representation, leaving local vision-language correspondence only indirectly constrained. Existing methods either introduce additional supervision, external models, or task-specific adaptation, while training-free approaches mainly recover dense responses from existing patch features without examining where local semantics become most accessible within CLIP. We introduce TraceCLIP, a training-free framework that recovers latent patch-level semantic evidence by isolating the patch-specific terms written into the CLS attention output. TraceCLIP further converts contribution-derived semantic responses into a semantic-geodesic topology gate that calibrates final-layer patch affinity for dense feature reconstruction. Diagnostic experiments show that these contribution features exhibit strong local semantic discrimination and text-conditioned spatial alignment. On eight zero-shot semantic segmentation benchmarks, TraceCLIP achieves gains of 1.3 to 4.5 points in average mIoU over the strongest prior training-free methods across both backbones and background settings, without additional training, external vision foundation models, or region-level supervision. More broadly, these findings suggest that spatially localized semantics may remain accessible within the internal construction of globally aligned representations.

### 1.1 研究背景

- **密集视觉-语言理解任务**（如目标定位、区域识别、开放词汇语义分割）要求将语言概念与**空间定位的视觉区域**相关联。
- **CLIP** 通过大规模对比预训练建立了共享的图像-文本嵌入空间，成为这类任务的强大基础；但在基于 ViT 的 CLIP 图像编码器中，用于对比对齐的图像表示来自**最终的 CLS token**，这产生了强大的全局对齐，却使得**patch 级别的视觉-语言对应仅被间接约束**。

### 1.2 现有方法的不足

- **训练式方法**：引入区域级监督、掩码标注或任务特定适配，虽然有效但需要额外优化和监督成本。
- **无训练方法**（如 MaskCLIP、SCLIP、ClearCLIP）：聚焦于如何将现有 patch token 特征转换为更好的密集响应，但**未深入探索 CLIP 内部计算中局部语义最直接可获取的位置**。

### 1.3 核心问题

> 论文提出一个更根本的问题：**在 CLIP 的计算过程中，局部语义证据在何处最容易被直接获取？**

这一问题的意义在于：全局对齐表示内部可能**编码了可用于局部或结构化预测的信息**，从内部计算中恢复这类信息，为提升密集预测提供了一条有别于额外训练或架构调整的互补路径。

### 1.4 核心假设与发现

- 在每个自注意力块中，CLS token 的注意力更新是**各 token 位置加权 value 成分的加性组合**。
- 将 patch 对 CLS 的贡献项（patch-to-CLS contributions）分离出来，并在 CLIP 联合嵌入空间中读出，即可获得**可直接与文本嵌入比较的 patch 级特征**。
- 诊断实验表明：**贡献特征** 在区域分类、文本条件定位上显著优于最终 patch token 状态，且在**最后的注意力贡献通路中清晰暴露**，但在残差和 MLP 混合后变得难以直接访问。

## 二、方法论

### 2.1 核心思想

TraceCLIP 的整体思路是：**将 patch-to-CLS 贡献分解作为一种表示恢复机制**——把构成全局嵌入的内部项转换为可复用的局部表示，而不是仅将其视为可解释性工具。

### 2.2 Patch-to-CLS 贡献分解

**公式 1**（patch i 在层 l 、头 h 对 CLS 注意力输出的贡献，映射到 CLIP 联合嵌入空间）：

\[
C^{l,h}_i = W_{proj} \left( A^{l,h}_{0i} \cdot W^{l,h}_{OV} \cdot LN(x^l_i) \right)
\]

**公式 2**（按注意力头聚合得到 patch 级特征）：

\[
C^l_i = \sum_{h=1}^{H} C^{l,h}_i
\]

其中：
- \(A^{l,h}_{0i}\)：CLS token 到 patch i 在头 h 的注意力权重；
- \(W^{l,h}_{OV}\)：value 到输出的变换矩阵；
- \(W_{proj}\)：CLIP 视觉投影；
- \(LN\)：注意力前的层归一化。

这样得到的 \(C^l_i\) 可直接与文本嵌入比较，作为局部视觉-语言特征。

### 2.3 诊断发现（方法论依据）

通过在 COCO 验证集上的系统性诊断实验（详见第三节），论文确立了三个关键观察：

1. 最终 patch 状态和 value 特征（\(V^{(-1)}\)）的区域判别和定位能力很弱；
2. 接近最终的贡献特征（\(C^{(-1)}\)）显著提升了区域分类精度（ViT-B/16 从 11.3% → 43.1%；ViT-L/14 从 8.7% → 47.1%）和指向精度；
3. 局部语义在注意力输出中清晰可见，但**残差连接和 MLP 混合后变得难以访问**——这是支持 TraceCLIP 方法设计的关键证据。

### 2.4 TraceCLIP 框架三大模块

#### （a）基于贡献的语义先验

- 贡献特征 \(C \in \mathbb{R}^{N \times d}\) 与文本嵌入 \(T \in \mathbb{R}^{K \times d}\) 计算响应矩阵：
  \[
  S_{con} = C^\top T
  \]
- 每个 patch 取最大响应的类别作为初步语义标签 \(L_i\)，并将 softmax 概率作为置信度 \(P_i\)。

#### （b）语义-测地线拓扑门

- 在 patch 网格上构建图：边仅连接四邻域；
- **边界代价**：
  \[
  w_{ij} = 1 + \beta \cdot m_{ij} \cdot c_{ij}
  \]
  其中 \(m_{ij}\) 表示标签是否不同，\(c_{ij} = \min(P_i, P_j)\) 为边界置信度；
- 计算每对 patch 间的最短路径距离 \(D_{ij}\)；
- 将距离转换为拓扑门（**公式 6**）：
  \[
  G_{ij} = \frac{\exp(-D^2_{ij} / 2\sigma^2)}{\sum_{r=1}^{N} \exp(-D^2_{ir} / 2\sigma^2)}
  \]
  参数 \(\sigma\) 控制有效测地线范围。

#### （c）亲和力校准与密集重建

- 基于 query-query 相似度构建最终层 patch 亲和力（借鉴 ClearCLIP）：
  \[
  A_h = \text{softmax}_{row} \left( \frac{Q_h Q_h^\top}{\sqrt{d_h}} \right)
  \]
- **校准公式**（**公式 8**）：
  \[
  \tilde{A}^h_{ij} = \frac{(A^h_{ij} + \epsilon)(G_{ij} + \epsilon)^\lambda}{\sum_{r=1}^{N} (A^h_{ir} + \epsilon)(G_{ir} + \epsilon)^\lambda}
  \]
  \(\lambda\) 控制校准强度，\(\epsilon\) 为数值稳定器；
- 校准后的亲和力 \(\tilde{A}^h\) 聚合最终层的 value 特征，经输出投影、后层归一化和视觉投影后，得到重建的 patch 特征，与文本嵌入比较获得密集类别分数，最终上采样到图像分辨率。

### 2.5 超参数设置

| 超参数 | 值 | 含义 |
|--------|-----|------|
| \(\beta\) | 1.0 | 语义边界惩罚强度 |
| \(\lambda\) | 1.5 | 亲和力校准强度 |
| \(\sigma\) | 0.4 × scale coefficient | 测地线范围控制 |
| \(\epsilon\) | \(10^{-6}\) | 数值稳定器 |
| 推理 logit scale | 50 | 贡献响应缩放 |

所有超参数在所有数据集和骨干网络上保持不变。

## 六、主要结论与发现

### 6.1 核心发现

1. **“表示鸿沟”存在**：最终 patch token 状态与构建 CLIP 全局嵌入的 patch 特定项之间存在显著的表示差异；patch-to-CLS 贡献通路提供了显式的、内嵌于模型内部的局部视觉-语言证据来源。

2. **贡献特征具有更强的判别性和空间基础性**：在区域分类、文本条件定位和晚期块组件分析中，贡献特征一致优于标准 patch 级读出，且性能越接近最终视觉块越好（C(−1) 最优）。

3. **退化机制已被识别**：局部语义在注意力输出中清晰可见，但经过残差连接（与 patch 状态混合）和 MLP 后变得难以直接访问。CLS 注意力加权进一步选择了与语言监督全局路径更对齐的 patch 证据。

4. **无训练方法可显著提升密集预测**：TraceCLIP 在 8 个零样本语义分割基准上，较最强先验无训练方法在两个骨干网络和背景设置下平均 mIoU 提升 **1.3–4.5** 个百分点，且无需额外训练、外部视觉基础模型或区域级监督。

### 6.2 更广泛的含义

> 空间定位的局部语义可能**仍保留在全球对齐表示的内部构造中**。追踪这类贡献通路为理解冻结视觉-语言模型中语义信息的形成、选择与遮蔽机制提供了新的视角。

- **依赖 CLIP 内部计算路径**：TraceCLIP 利用的是 CLIP 视觉编码器中 CLS-attention 的贡献通路，若底层模型结构变化（如无 CLS token 的模型或跨模态融合架构），该方法的核心机制需要重新适配。
- **未覆盖相关任务**：论文仅聚焦于零样本语义分割，未验证方法在开放词汇目标检测（如 OV-DETR）、指称表达分割（如 RefCOCO）等密集预测任务上的泛化性。
- **计算开销问题**：逐层计算 patch-to-CLS 贡献需要访问每个注意力头的 value 输出和注意力权重，相比直接取最终 patch token 增加了存储和计算成本；最短路径距离矩阵的计算在 patch 数较多时开销较大（尽管实验窗口限制在 448×448，但更大分辨率时仍需优化）。
- **诊断实验范围有限**：关键的诊断发现仅在 COCO 验证集上验证，未检查这些现象在其他数据集分布（如城市景观、ADE20K）中的稳定性，可能影响方法设计依据的普适性。
- **超参数固定性**：虽然统一超参数有利于公平对比，但未提供针对不同数据分布或类别数量的敏感性分析，σ、λ 等参数在极端场景下是否仍然鲁棒尚不清楚。

### 8.2 潜在改进方向

- **轻量化门机制**：用可学习的轻量图网络或原型最近邻近似替代完整最短路径距离计算，降低计算复杂度。
- **跨任务迁移**：将贡献特征与训练式检测或分割头结合，在少量微调下利用内部语义先验。
- **多级贡献融合**：目前主要采用 $C^{(-1)}$，可探索多层贡献特征的自适应加权融合，避免依赖单一层。
- **动态参数调节**：根据图像内部复杂度或类别数动态调整 $\sigma$、$\lambda$，提高新场景的适应性。
- **与其他无训练方法的组合**：例如将贡献特征注入 SCLIP 或 ClearCLIP 的注意力更新流程，验证其作为通用特征源的潜力。

## 九、论文定位与可复现性评估

### 9.1 论文定位

- 本工作属于**无训练、无监督、基于模型内部机制的表示恢复**类研究，与特征后处理（如全连接 CRF）和测试时自适应（如 TPT）路线不同。
- 它连接了**可解释性分析**与**下游密集预测**，强调用诊断工具发现的信息来解决实际任务，具有跨界创新性。

### 9.2 可复现性相关评估

- **伪代码与公式**：论文提供了贡献分解、边界代价、拓扑门和校准的完整数学描述，步骤清晰；
- **超参数**：全部固定并公开（见 2.5 节），有助于直接复现；
- **代码与数据**：论文中未明确给出代码仓库链接，也未列出实验环境细节（GPU 型号、运行内存等），在一定程度上会阻碍快速复现；
- **实现提示**：论文提到所有结果均来自作者自身实现，但未说明与官方基线实现的具体差异（如是否修改了 CLIP 预处理、滑窗重合区域的处理方式等），可能引入微小偏差。

---

**总体评价**：TraceCLIP 以“追踪 CLS 贡献”为切入点，深刻揭示了冻结 CLIP 中局部语义的可访问性规律，并提出一种简洁、高效的无训练校准机制。该工作在零样本语义分割上取得了稳定且显著的提升，充分证明了“从内部表示恢复局部语义”这一路径的有效性。其诊断实验设计严谨，为后续研究提供了宝贵的方法论参考。尽管在任务覆盖和计算效率方面仍有扩展空间，但其核心发现——**局部语义在 patch-to-CLS 贡献通路中清晰暴露**——将推动视觉-语言模型可解释性与密集预测的更深度融合。
