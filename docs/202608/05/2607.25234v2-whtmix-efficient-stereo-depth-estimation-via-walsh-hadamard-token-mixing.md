## 摘要
用于驾驶、机器人和增强现实的立体深度估计必须在严格的延迟预算下以高分辨率运行，然而在基于Transformer的匹配器中，聚合场景上下文的全局自注意力随像素数量二次增长，并逐渐占据运行时间的主导。我们证明，立体Transformer的联合自注意力阶段（其作用是在两个视图之间传播上下文）可以被一种数据无关的Walsh-Hadamard令牌混合器替代，该混合器在对数线性成本下在变换域中全局混合令牌，而执行左右对应关系的数据相关的交叉注意力则被保留。在合成驾驶数据上，该混合器在端点误差上与注意力基线相当，同时将模型计算量减少了2.46倍，单图像推理延迟减少了2.65倍。复杂度分析表明，收益由序列长度与通道宽度之比决定，这解释了为什么高分辨率立体匹配是特别有利的场景，而分类Transformer则不是；我们在非立体的长序列基准上确认了这种令牌到通道的缩放关系。此外，我们引入了一种混合对数视差损失函数，旨在对对应于远距离物体的小视差像素赋予更高权重。这种方法在不产生任何额外计算开销的情况下，减少了远处物体的误差。

## Abstract
Stereo depth estimation for driving, robotics and augmented reality must run at high resolution under tight latency budgets, yet in transformer-based matchers the global self-attention that aggregates scene context grows quadratically with the number of pixels and comes to dominate runtime. We show that the joint self-attention stage of a stereo transformer, whose role is to spread context across both views, can be replaced by a data-independent Walsh-Hadamard token mixer that mixes tokens globally in the transform domain at log-linear cost, while the data-dependent cross-attention that performs left-right correspondence is retained. On synthetic driving data the mixer matches the attention baseline in end-point error while reducing model compute by a factor of 2.46 and single-image inference latency by a factor of 2.65. A complexity analysis shows the benefit is governed by the ratio of sequence length to channel width, which explains why high-resolution stereo matching is a particularly favorable setting and why classification transformers are not; we confirm this token-to-channel scaling on non-stereo long-sequence benchmarks. Furthermore, we introduce a hybrid log-disparity loss function designed to up-weight small-disparity pixels corresponding to long-range objects. This approach reduces the error on distant objects without incurring any additional computational overhead.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：用数据无关的Walsh-Hadamard变换（WHT）在变换域中实现全局令牌混合，替代立方复杂度的自注意力核心，同时保留数据相关的交叉注意力用于视差匹配。
- **WHTMix 模块结构**：
  - 输入 X ∈ R^(N×C)，先经线性投影 W_in；
  - 对**通道轴**做 WHT 变换，乘以可学习的每频率增益 g_c（log域，初始化为零即单位增益），再逆变换；
  - 对**令牌轴**（长度N零填充到2的幂次）做同样操作，乘以可学习增益 g_t；
  - 最后经线性投影 W_out 输出。
  - WHT 是正交归一变换，具有乘性自由（仅加法）、O(N log N) 蝶形计算的特点，数值稳定、可堆叠。
- **交叉注意力保留**：左右视图的对应匹配仍使用标准点积交叉注意力，确保匹配精度不受影响。
- **混合 log-视差损失**：加权系数 w_p = clip(τ/d_p, 1, w_max)，τ=16，w_max=32。对小视差（远距离物体）像素赋予更高权重，缓解标准ℓ1损失被近处大视差主导的问题，零额外计算开销。
- **复杂度分析**：
  - 自注意力块 MACs = 4NC² + 2N²C；WHTMix = 2NC²；
  - 模块级加速比 S_mod = 2 + N/C，交叉点在 N = 2C；
  - 端到端加速上限 S_e2e = (16C + 3N)/(14C + N)，当 N→∞ 时接近 3×。

### 6. 论文的主要结论与发现

- **效率-精度双赢**：在CARLA上，WHTMix计算量降低 **2.46×**、延迟降低 **2.65×**，EPE与注意力基线持平（2.27 vs 2.29，在run-to-run噪声范围内）。
- **复杂度分析准确**：经验测得的端到端加速比（2.65×@512×1024，2.85×@896×1792）与理论预测（2.90×，2.97×）高度吻合；隔离的token-mixer加速比从33×（N=16k）到162×（N=65k），自注意力近二次增长（log-log斜率1.70）vs. WHTMix近常数增长（斜率0.25）。
- **收益由 N/C 比值决定**：高分辨率立体匹配（N/C=256）是极有利场景，而分类ViT（N/C≈0.26）不在受益范围内。LRA实验确认了这一规律（N/C=16时FLOP↓4.3×，N/C=64时FLOP↓13.8×）。
- **log-视差损失显著提升远距精度**：2-4px区间EPE从3.29降至1.60（约2×改善），4-8px区间从3.36降至1.94，零计算开销。
- **诚实报告合成→真实迁移代价**：在KITTI上WHTMix精度略低于注意力基线（EPE 2.670 vs 2.204），说明固定混合器在真实数据稀缺时自适应能力不如可学习的注意力。

### 7. 优点

- **概念清晰、定位精准**：明确区分“上下文传播”（可替代）与“对应匹配”（必须保留数据相关），理论动机扎实。
- **理论指导实践**：2 + N/C 的闭合式复杂度分析不仅解释了现有结果，还能预测适用场景，且与实测延迟高度吻合。
- **工程上手简单**：WHTMix 与注意力接口一致，是字面上的“drop-in”替换；WHT无需乘法、正交归一、数值稳定，对硬件友好。
- **零成本损失改进**：log-视差损失不增加推理开销，直接改善远距离物体精度，实用价值高。
- **实验设计严谨**：单因素控制对比（混合器/损失独立变化）、端到端与隔离分析互补、多分辨率扫描验证趋势、LRA泛化测试增强结论可靠性。
- **诚实客观**：如实报告KITTI上精度下降、LRA单种子限制，不回避方法的局限。

### 8. 不足与局限

- **真实数据性能下降**：在KITTI上EPE从2.204（attn）上升到2.670（WHTMix），说明数据无关混合器在真实分布偏移下适应能力有限，需要大规模真实数据预训练弥补。
- **LRA实验强度不足**：仅单种子运行，缺乏多种子均值/方差报告；且LRA上图像任务准确率差距较大（0.314 vs 0.383），暗示方法在较短序列上优势减弱。
- **小序列效率反转**：隔离延迟显示在N=1024时WHTMix因启动开销反而比注意力更慢，说明方法存在适用规模门槛。
- **端到端加速上限受限**：由于交叉注意力和FFN共享，端到端加速上限约3×，即使混合器本身再快也无法突破Amdahl定律的限制。
- **零填充开销**：WHT要求令牌长度为2的幂次，非2幂次输入需要零填充，可能带来额外计算和内存开销，接近幂次边界时会浪费计算。
- **超参数未充分调优**：log损失中的 τ=16、w_max=32 以及WHTMix的增益初始化策略未见敏感性分析或在不同配置下的验证。
- **实验范围有限**：仅在STTR风格骨架上验证；未与其他高效注意力（如窗口注意力、FlashAttention、Mamba等）做直接对比，效率优势的相对性不够充分。
