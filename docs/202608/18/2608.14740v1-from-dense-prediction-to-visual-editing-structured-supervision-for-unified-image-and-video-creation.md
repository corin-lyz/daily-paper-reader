## 摘要
统一的图像与视频生成要求模型在保持视觉上下文中的身份、几何和时间结构的同时，遵循多样的指令。然而，仅基于语义的条件和仅面向生成的训练，并未显式监督精确、时间一致编辑所需的局部结构。因此，我们将深度和表面法线预测表述为图像形式的去噪目标，在相同的生成界面内将这些密集任务用作结构化视觉监督。我们的框架将语义解释与空间对齐的视觉注入解耦，同时在所有任务中共享一个多模态扩散Transformer（MMDiT）主干。互上下文注意力（MCA）、成对视频数据构建流程以及渐进式训练课程，将学习到的结构线索与时间定位编辑和参考条件生成联系起来。在报告的统一系统对比中，单个检查点获得了最高总分（4.15）；添加密集监督将OpenVE总体得分从3.98提升至4.06，Local Add从3.92提升至4.18。这些结果支持一个审慎有限的结论：面向感知的密集监督将有用的结构知识迁移到下游生成中，尤其是编辑的局部性和保持性；我们不声称作为独立密集预测器具有优越性。

## Abstract
Unified image and video creation requires a model to follow diverse instructions while preserving identity, geometry, and temporal structure from visual context. However, semantic-only conditioning and creation-only training do not explicitly supervise the local structure needed for precise, temporally consistent editing. We therefore formulate depth and surface-normal prediction as image-form denoising targets, using these dense tasks as structured visual supervision within the same creation interface. Our framework decouples semantic interpretation from spatially aligned visual injection while sharing one multimodal diffusion transformer (MMDiT) backbone across all tasks. Mutual Context Attention (MCA), a paired-video data-construction procedure, and a progressive training curriculum then connect the learned structural cues to temporally localized editing and reference-conditioned creation. A single checkpoint obtains the highest overall score in the reported comparison of unified systems (4.15); adding dense supervision improves OpenVE Overall from 3.98 to 4.06 and Local Add from 3.92 to 4.18. These results support a deliberately bounded conclusion: perception-oriented dense supervision transfers useful structural knowledge to downstream creation, especially editing locality and preservation; we do not claim superiority as a standalone dense predictor.

## 1. 论文的核心问题与整体含义

- **研究动机**：统一的图像与视频生成/编辑系统（unified visual creation）需要同时支持多种任务（如文生图、文生视频、主体驱动生成、指令编辑、参考编辑、关键帧传播等），并在此过程中严格保持源图像/视频中的身份、几何结构、时间一致性等局部信息。然而，现有方法大多依赖语义级条件（如文本、图像 token）和“仅生成”的训练目标，缺乏对局部结构的显式监督，导致模型能够遵循指令却容易产生身份漂移、误改未编辑区域、几何扭曲或时间闪烁等问题。
- **核心问题**：如何在共享的生成骨干中显式地注入结构化视觉监督，使模型在完成多样化生成与编辑任务的同时，精确保持源内容和时间结构。
- **论文假设**：将深度和表面法线等密集预测任务作为图像形式的去噪目标，与生成任务共用同一训练目标，可以隐式地教会模型理解场景结构（边界、遮挡、深度顺序、表面朝向等），从而提升下游编辑的局部性和结构保持能力。这是一种“感知→生成”的迁移方向，而不是通常的“生成→感知”。

## 2. 论文提出的方法论

- **核心思想**：将密集预测（深度、法线）转化为图像/mask 形式的去噪目标，与图像/视频生成和编辑任务共享同一套条件封装和去噪损失，从而在统一的多模态扩散 Transformer（MMDiT）中施加结构化监督，无需额外感知头或推理时结构模块。
- **统一任务公式**：
  - 条件表示为 \( C = (p, x_{\text{src}}, R, \rho) \)，其中 \( p \) 为文本提示/编辑指令，\( x_{\text{src}} \) 为可选主输入，\( R \) 为参考/控制集合，\( \rho \) 为 token 角色标识。
  - 目标是输出 \( y \)，可以是图像、视频，也可以是深度/法线图（均表示为图像/视频形式）。
  - 任务的不同通过改变条件内容和目标类型实现，不改变模型接口。
- **双路径条件注入**：
  - **语义路径**：使用冻结的 Qwen2.5-VL、SigLIP、Glyph-ByT5 编码器，经轻量投影器得到语义 token，负责理解指令意图和跨模态关系。
  - **视觉路径**：使用冻结 VAE 将源图像/视频、参考和结构化控制编码为与目标相同空间布局的干净 latent，保持空间对齐的视觉证据，可被注意力机制直接检索。

- **共享 MMDiT 去噪**：
  - 目标 latent 按扩散前向过程加噪，损失为 \( \mathcal{L}_{\text{denoise}} = \mathbb{E}_{t,\epsilon} [\| \epsilon - \epsilon_\theta(z_t, C, t) \|_2^2] \)。
  - 仅对目标 token 计算损失，源/参考/语义 token 仅作条件。
  - 推理时目标 token 从噪声开始迭代去噪，任务切换仅改变条件包和 token 角色。

- **结构化监督的具体实现**：
  - 深度图归一化为 RGB 图像，表面法线为三通道方向图，用冻结 VAE 编码后作为去噪目标。
  - 输入为源图像/视频 + 指令（如“转换为深度图”），与生成任务使用完全相同的条件包和损失。
  - 训练时密集任务与生成任务混合采样，推理时不需要任何深度/法线输入。

- **MCA（Mutual Context Attention）配对视频构造**：
  - 用于自动生成高质量的源-目标视频编辑对。
  - 两个分支（源和 target）在同一 DiT 中联合去噪，通过跨分支 Key/Value 交互（CONCAT K、CONCAT KV、SWAP K、SWAP KV）控制耦合强度。
  - 按任务类型设定不同耦合策略（如对象插入用 SWAP KV → CONCAT KV → self-attention 的渐进释放），早期强耦合对齐场景结构，中期保留可编辑性，后期避免纹理复制。
  - 完整流程：LLM 扩展 prompt → MCA 生成源/目标视频 → 过滤 → VLM 生成编辑指令 → 多轮 VQA 校验，得到约 300K 三元组（源视频、目标视频、指令）。

- **渐进式训练课程**：
  - Stage I：生成 + VLM 重建 + 一致性保持（比例 7:2:1），对齐条件并保留预训练先验。
  - Stage II：指令编辑 + 深度/法线 + MCA 对 + 生成回放，图像:视频默认 4:1。
  - Stage III：主体/参考生成、参考编辑、关键帧传播、多参考组合，保持密集监督作为正则。

## 7. 优点

- **问题定位清晰**：明确指出现有统一生成系统在精确局部编辑上的结构性缺陷，并提出针对性的监督范式。
- **方法设计统一且优雅**：将密集预测转化为图像形式去噪，与生成任务共用同一个条件包、目标和骨干，无需额外模块，训练后推理图不变。
- **语义与空间解耦**：避免将像素级结构压缩进抽象语义 token，让视觉路径保留空间对齐证据，更利于保持身份和几何。
- **MCA 数据构造具有原创性**：通过双分支注意力交互生成对齐的源-目标视频对，可自然支持非首帧开始的局部编辑，弥补了传统首帧传播数据构造的偏差。
- **实验设计有层次**：从统一总榜到专项编辑基准，再到精确控制的数据审计和消融，形成了“系统级 → 能力级 → 机制级”的证据链。
- **结论谨慎**：明确限定迁移主张的范围，不夸大密集预测本身的能力，体现了学术诚实。

## 8. 不足与局限

- **缺乏独立感知性能评估**：论文不报告深度/法线预测的准确率或 benchmark，无法验证密集监督任务本身的质量，也限制了“迁移机制”的直接可解释性。
- **消融缺乏等量数据对照**：添加密集监督的消融没有使用相等数量的通用图像/视频数据作为对照组，因此无法区分“额外数据”和“目标语义”各自的作用。
- **基准规模较小且依赖 VLM 评估**：InsEdit-Bench 仅 82 例，主要依赖 Qwen3-VL 作为裁判，缺少人类评测，可能与人类偏好存在偏差。
- **分辨率局限**：训练和评估主要在 480p 视频、720p 图像下进行，高分辨率下的编辑局部性未测试。
- **覆盖面局限**：并非所有编辑类型均领先（如背景替换、全局风格、字幕、相机移动），统一模型的长尾能力仍需增强。
- **已知失败模式**：长视频身份漂移、小物体编辑精度不足、多参考相似主体时绑定冲突。
- **算力信息缺失**：未报告 GPU 数量、训练时长和总计算量，不利于复现和资源比较。
- **图像编辑能力相对有限**：在 GEdit 上语义一致性（6.98）和总体分（6.72）低于部分专用模型，仅图像质量（7.77）较高，说明其图像编辑竞争力弱于视频编辑竞争力。
