## 摘要
图像恢复中的知识蒸馏通常将教师网络与学生网络之间的中间特征或关系矩阵作为静态目标对齐，忽略了知识转移过程的动态结构。本文提出了关系流形上的流映射蒸馏（FoRM），将基于关系的知识转移重新表述为关系流形上的连续流映射问题。FoRM不是回归学生和教师关系状态之间的常速度场，而是学习一个流映射算子\(\mathcal{F}_\theta(\mathbf{z}, t, s)\)，该算子根据时间\(t\)的当前状态直接预测任意目标时间\(s\)的关系状态，从而提供更丰富的轨迹级监督。为确保所学流映射的全局自一致性，我们引入了安全半群一致性约束，利用真实桥接状态强制组合一致性，消除了幻影状态误差累积。端点锚定损失进一步防止算子偏离教师目标。在包括超分辨率、去雨、去噪、去模糊和低光增强在内的五个图像恢复任务上的大量实验表明，与多个骨干架构上的最先进蒸馏基线相比，FoRM取得了一致的性能提升，与朴素流匹配蒸馏相比，训练方差减少了约50%，同时实现了更优的恢复质量。

## Abstract
Knowledge distillation for image restoration typically aligns intermediate features or relation matrices between teacher and student networks as static targets, ignoring the dynamic structure of the knowledge transfer process. In this paper, we propose Flow-Map Distillation on Relation Manifolds (FoRM), which reformulates relation-based knowledge transfer as a continuous flow mapping problem on the relation manifold. Rather than regressing a constant velocity field between student and teacher relation states, FoRM learns a flow map operator $\mathcal{F}_θ(\mathbf{z}, t, s)$ that directly predicts the relation state at any target time $s$ given the current state at time $t$, enabling richer trajectory-level supervision. To ensure global self-consistency of the learned flow map, we introduce a safe semigroup consistency constraint that enforces compositional agreement using ground-truth bridge states, eliminating phantom-state error accumulation. An endpoint anchoring loss further prevents the operator from drifting away from the teacher target. Extensive experiments on five image restoration tasks, including super-resolution, deraining, denoising, deblurring, and low-light enhancement, demonstrate consistent gains over state-of-the-art distillation baselines across multiple backbone architectures, reducing training variance by approximately 50\% compared to naive flow matching distillation while achieving superior restoration quality.

## 论文总结：Flow-Map Distillation on Relation Manifolds for Image Restoration (FoRM)

### 1. 核心问题与研究动机

- 论文聚焦于图像恢复（超分辨率、去雨、去噪、去模糊、低光增强）中的**知识蒸馏（Knowledge Distillation, KD）**问题。
- 现有 KD 方法大多把教师网络的特征、关系矩阵或注意力图当作**静态目标**，让学生网络在逐层上用 L1/L2 损失直接逼近。这种“一次性端点对齐”忽略了学生向教师收敛的**动态轨迹**，容易引发：
  - 训练后期指标振荡；
  - 过早进入平台期；
  - 当教师表示距离学生能力边界较远时，压制细节恢复。
- 作者因此提出：蒸馏不仅要回答“学生应该到达哪里”，还要回答“学生应该如何到达那里”，即需要**过程感知的动态监督**。
- 流匹配（Flow Matching）提供了一种连续时间框架，但朴素地把它用于 KD 只回归常速度场 \(\mathbf{u}^* = \mathbf{z}_1 - \mathbf{z}_0\)，不能刻画不同桥接点的组合结构，也不满足全局自一致性；若直接用模型预测状态递归代入，则会产生**幻影状态误差累积**（phantom-state error accumulation）。

### 2. 方法论：FoRM 框架

#### 核心思想
- 将关系型知识蒸馏重新定义为**关系流形上的连续流映射问题**，用流映射算子 \(\mathcal{F}_\theta(\mathbf{z}, t, s)\) 直接预测从时间 \(t\) 的当前状态到任意目标时间 \(s\) 的关系状态，从而提供**轨迹级监督**。

#### 关键技术细节
- **关系状态构造**
  - 选择蒸馏层 \(L=\{2,5,8\}\)，分别覆盖约 20%、50%、80% 网络深度。
  - 教师和学生特征经 \(1\times1\) 卷积 + BN + ReLU 投影到共享通道，再自适应池化到 \(p\times p=8\times8\)，得到 \(N=64\) 个 token。
  - 对通道维度做 L2 归一化后，计算 softmax 归一化的 token 亲和矩阵：
    \[
    R^\ell = \operatorname{softmax}\left(\frac{\tilde{X}^\ell(\tilde{X}^\ell)^\top}{\tau}\right),\quad \tau=0.07
    \]
  - 关系状态定义为 \(z^\ell_0=\operatorname{vec}(R^\ell_s)\)（学生）和 \(z^\ell_1=\operatorname{sg}(\operatorname{vec}(R^\ell_t))\)（教师）。
- **关系流形**
  - 每个关系矩阵的行位于概率单纯形 \(\Delta^{N-1}\)，因此状态空间是 \((N-1)^N\) 的乘积单纯形；由于单纯形是凸的，线性插值仍保持在流形内，因此训练中的中间状态都是合法关系配置。
- **真实桥与时间采样**
  - 所有中间状态来自学生与教师之间的真实线性桥：
    \[
    z_t = (1-t)z_0 + t z_1,\quad z_s = (1-s)z_0 + s z_1
    \]
  - 采样 \(t\sim U[0,0.8]\)、\(\delta\sim U[0,1-t]\)，保证 \(t<s\le 1\)。
- **流映射算子**
  - 输入为 \([z_t \| e_t \| e_s \| e_\ell]\)，其中 \(e_t,e_s\) 是正弦时间嵌入（64 维），\(e_\ell\) 是层身份嵌入。
  - 使用 3 层 MLP（SiLU，隐层 256），总参数量 <0.5M；所有蒸馏层共享同一算子，用层嵌入做条件化。
- **三项结构损失**
  - 映射蒸馏损失：\(\mathcal{L}_{\mathrm{map}}=\|\mathcal{F}_\theta(z_t,t,s,\ell)-z_s\|_2^2\)，提供稠密轨迹监督。
  - 端点锚定损失：\(\mathcal{L}_{\mathrm{bd}}=\|\mathcal{F}_\theta(z_t,t,1,\ell)-z_1\|_2^2\)，防止轨迹偏离教师目标。
  - 安全半群一致性损失（safe semigroup consistency）：
    \[
    \mathcal{L}_{\mathrm{sg}}=\|\mathcal{F}_\theta(z_t,t,1,\ell)-\operatorname{sg}(\mathcal{F}_\theta(z_s,s,1,\ell))\|_1
    \]
    两条分支都使用**真实桥状态**而非模型预测状态，并在右分支加 stop-gradient，从而避免幻影状态误差累积。
- **训练总损失**
  - \( \mathcal{L} = \mathcal{L}_{\mathrm{rec}} + \lambda_{\mathrm{KD}} \mathcal{L}_{\mathrm{KD}}\)，其中 \(\mathcal{L}_{\mathrm{KD}}\) 由三个损失按层平均，并加随训练进度衰减的调度权重 \(w(\rho)\)（在 \(\rho_0=0.6\) 后从 1 线性衰减至 0.1，且只衰减 \(\mathcal{L}_{\mathrm{map}}\)，结构约束保持全权重）。
  - 超参数：\(\lambda_{\mathrm{map}}=1.0,\ \lambda_{\mathrm{bd}}=0.5,\ \lambda_{\mathrm{sg}}=0.1,\ \lambda_{\mathrm{KD}}=100\)。

### 6. 主要结论

- FoRM 在五个图像恢复任务上普遍优于 SOTA 蒸馏基线：
  - All-in-one：平均 27.34 dB，超过 DCKD（27.29 dB）。
  - 超分辨率：在 SwinIR、RCAN、EDSR 和跨架构设置中均取得第一，Urban100 上优势最明显。
  - 低光增强：PSNR 28.93 dB / SSIM 0.9082，优于 MiPKD 和 DCKD。
- 训练稳定性显著提升：
  - \(\sigma_{\mathrm{late}}\) 相对 Static Rel. KD 降低 52%，相对 Naive FM 降低 78%；
  - 跨种子 PSNR 标准差从 0.0241 降到 0.0112。
- 关系对齐分析证明：FoRM 在三个蒸馏层上的 CKA 均系统性高于静态 KD（Wilcoxon 检验 \(p<0.001\)），说明质量提升源于关系结构对齐的改善，而非个别图像的偶然收益。
- 安全半群设计是核心：使用真实桥状态 + stop-gradient 比递归使用模型预测状态高 0.19–0.26 dB，且 \(\sigma_{\mathrm{late}}\) 降低 2.3–3.2 倍。

### 7. 优点

- **范式创新**：从静态端点对齐转向动态轨迹级蒸馏，为图像恢复 KD 提供新视角。
- **安全半群约束设计巧妙**：用真实桥状态避免幻影误差累积，既保持了半群结构的自一致性，又防止了训练不稳定。
- **流形表示具有理论合理性**：softmax 关系矩阵位于凸单纯形乘积流形上，线性桥天然保持合法性，跨架构鲁棒性好。
- **即插即用、开销可控**：共享流映射头只增加 <0.5M 参数和 +4–5% 训练时间，推理零开销。
- **实验覆盖全面**：包含多任务、多骨干、跨架构、复合退化、消融、稳定性、关系对齐分析，证据链完整。
