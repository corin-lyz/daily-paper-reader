## 摘要
移动图像去噪要求同时具备良好的恢复质量和较低的计算成本。此外，收集大规模低质量-真实干净图像对也很繁琐。为此，我们提出了LiteKD-Net，一种用于移动图像去噪的轻量级知识蒸馏网络。首先，与应用于相机的流水线相比，物理引导的噪声模拟流水线通过添加像素串扰来生成成对的训练数据。其次，我们将Real-ESRGAN适配为同分辨率去噪，并使用基于深度可分离卷积的Lite-RRDB块构建轻量级学生网络。第三，应用特征级知识蒸馏，在不引入额外推理成本的情况下，将教师网络的恢复能力迁移到学生网络。在真实世界数据集上的实验表明，我们的模型在保持良好的恢复质量的同时，大幅减少了运行时间并提高了推理速率。与SwinIR相比，我们的模型在所有指标上也达到了最佳效果。这些结果表明，LiteKD-Net在恢复质量和计算效率之间提供了很好的权衡。

## Abstract
Mobile image denoising requires both good restoration quality and low computational cost. In addition, it's annoying to collect large-scale LQ-GT clean pairs. As a result, we propose LiteKD-Net, a lightweight knowledge-distilled network for mobile image denoising. First, a physics-guided noise simulation pipeline generates paired training data by adding pixel crosstalk compared with pipelines applied to cameras. Next, we adapt the Real-ESRGAN to identity-resolution denoising and construct a lightweight Student using Lite-RRDB blocks based on depthwise separable convolutions. Third, feature-level knowledge distillation is applied to transfer the Teacher's restoration capability to the Student without introducing additional inference cost. Experiments on real-world datasets show that our model reaches great reduction in runtime and increase in the inference rate with good restoration quality. Our model also reaches the best in all metrics compared with SwinIR. These results indicate that LiteKD-Net provides a great trade-off between restoration quality and computational efficiency.

### 一、核心问题与整体含义（研究动机与背景）

- **移动端去噪的核心矛盾**：手机相机因传感器尺寸小、单像素面积小，导致捕获光子少、信噪比天然偏低；而现有高性能去噪网络（如基于 RRDB 或 Transformer 的模型）参数量往往达数千万、FLOPs 达数十亿，在移动硬件上存在高延迟、高能耗、内存占用过大的问题。云端处理虽能减轻本地计算负担，但引入了通信延迟、带宽成本和隐私风险。
- **训练数据瓶颈**：获取严格对齐的真实噪声/干净图像对十分困难——同一场景拍摄两次难免存在物体运动、光照变化和机内处理导致的错位。传统的高斯白噪声仿真又不足以刻画真实 CMOS 传感器噪声的信号依赖性和结构性（如像素串扰、行噪声等）。
- **论文的整体定位**：面向移动端部署，设计一个同时兼顾恢复质量、计算效率和数据可行性的统一去噪框架——LiteKD-Net。核心思路是"物理仿真造数据 + 轻量架构降复杂度 + 知识蒸馏补质量"三位一体。

### 二、方法论：核心思想、关键技术细节与公式

#### 1. 噪声模拟流水线（Noise Simulation Pipeline, NSP）

- **设计动机**：真实 CMOS 噪声远比高斯白噪声复杂，且收集严格对齐的成对数据困难，因此采用物理引导的合成噪声方案。
- **流程概述**（详见图 1）：
  1. **线性化**：将干净 sRGB 图像通过 gamma 展开（γ=2.2）近似转换到线性 RGB 域。
  2. **光子散粒噪声**：通过泊松分布建模，信号相关，方差正比于信号强度（Var = K·y₀）。
  3. **Tukey–Lambda 读出噪声**：使用 Tukey–Lambda 分布建模重尾分布的电子读出噪声。
  4. **行噪声**：逐行采样高斯偏移量，模拟传感器行读出产生的水平带状噪声。
  5. **像素串扰（核心贡献）**：与 Wei et al. 的原始模型不同，NSP 显式引入局部空间相关的像素串扰，采用 3×3 卷积核：
     ```
     κ_c = [[c/4,  c,  c/4],
            [c,   1-5c, c],
            [c/4,  c,  c/4]]
     ```
     核权重和为 1，近似保持局部亮度；默认 ρ=0.03，即 15% 的权重分配到邻域像素，产生温和的空间相关性。实验证明该操作引入的是结构化噪声而非独立噪声。
  6. **量化噪声**：均匀分布，B=14 bit。
  7. **裁剪并逆 gamma 变换** 转回 sRGB。
- **完整的 NSP 公式**：
  ```
  x̂_s = Γ⁻¹( clip( C_ρ( K·Poisson(Γ(y_s)/K) + n_read + n_row ) + n_q, 0, 1 ) )
  ```
- **与 Wei et al. 模型的区别**：无需相机特定标定，参数固定（如表 III 所示），属于"物理引导的 RGB 噪声近似"，目标是生成配对的训练数据而非精确模拟传感器。
- **生成的数据对特点**：严格像素级对齐，因为噪声是通过同一张干净图像在计算机内仿真得到的。

#### 2. 轻量级网络架构（Lite-RRDB）

- **教师网络（Heavy Teacher）**：从 Real-ESRGAN 改造而来，去掉所有上采样模块，保持 H×W→H×W 同分辨率去噪；backbone 含 23 个 RRDB，每个 RRDB 含 3 个 RDB，每个 RDB 有 5 个标准 3×3 卷积，采用密集连接。
- **学生网络（Lite-RRDB Student）**：将每个 RRDB 替换为 Lite-RRDB：
  - **移除密集连接**：原始 RDB 中 5 个 3×3 卷积通过 dense concatenation 连接；Lite-RDB 改为顺序执行，特征宽度固定在 64 通道。
  - **深度可分离卷积**：每个标准卷积替换为 DSConv = PWConv₁ₓ₁(DWConv₃ₓ₃(·))：
    - 参数量对比：P_std = k²·C_in·C_out，P_DS = k²·C_in + C_in·C_out，大幅降低参数量。
  - **保留残差结构**：Lite-RDB 内部保留残差缩放因子 0.2 的局部残差连接；Lite-RRDB 外部保留跨三个 Lite-RDB 的外层残差连接——即保留"残差中的残差"训练结构。

#### 3. 噪声知识蒸馏（Noise-KD）

- **动机**：架构压缩降低了表征能力，需要从教师迁移恢复能力。
- **实现方式**：
  - 教师网络先在配对数据上训练至收敛，**冻结所有参数**。
  - 训练学生时，同一噪声图像分别输入教师和学生网络，获取各自 body 卷积后的中间特征 F_T(x) 和 F_S(x)。
  - 最小化特征级均方误差：
    ```
    L_KD = (1/CHW) · ||F_S(x) − F_T(x)||₂²
    ```
  - 总体学生训练损失：
    ```
    L_total = L_rec + λ_per·L_per + λ_KD·L_KD
    ```
    其中 L_rec = L1 像素重建损失，L_per = LPIPS 感知损失。
- **关键优势**：教师仅在训练阶段使用，推理时完全丢弃，**不增加任何推理期参数量和计算量**。

### 六、主要结论与发现

1. **效率大幅提升**：与 Heavy Teacher 相比，LiteKD-Net 模型规模缩小约 10 倍（16.70M → 1.67M），MACs 和 FLOPs 降低约 4 倍，推理速度提升约 2 倍（148.70ms → 83.47ms，FPS 从 6.72 提升至 11.98）。
2. **质量损失很小**：虽然指标略低于教师网络（如 PSNR 38.1400 → 37.9102，SSIM 0.9007 → 0.8975），但差距微小，且完全优于 SwinIR（PSNR 34.7282、SSIM 0.8242）——在所有图像质量指标上超过 SwinIR。
3. **知识蒸馏有效**：消融实验证明 Noise-KD 显著弥合了轻量学生与重教师之间的质量差距，特别是在 LPIPS（0.1257 → 0.0987）和 DISTS（0.0938 → 0.0837）等感知指标上改进明显。
4. **总体定位**：LiteKD-Net 在移动端去噪任务中实现了恢复质量与计算效率的良好平衡，适合真实移动场景部署。

### 七、优点与亮点

1. **问题定位清晰**：同时应对移动端去噪的两大痛点——计算资源受限和成对数据缺乏，具有实际工程价值。
2. **物理引导的数据仿真**：在已有 RAW 噪声模型基础上创新性地引入**像素串扰**，使合成噪声更接近真实 CMOS 传感器的空间相关特性；并用消融式可视化（图 2）验证了串扰核确实引入了结构化噪声而非独立噪声。
3. **架构设计简洁有效**：
   - 移除密集连接降低内存和计算量，同时保留关键残差结构（残差缩放 0.2 + 残差中的残差），避免训练不稳定；
   - 深度可分离卷积的参数压缩比有明确公式支撑。
4. **知识蒸馏不增加推理成本**：特征级蒸馏的设计巧妙，教师仅在训练阶段使用，推理时完全去除——这是方法上最亮眼的工程权衡。
5. **评估维度全面**：同时报告了参考指标、感知/无参考指标和效率指标的完整矩阵，覆盖了从像素精度到主观感知再到部署性能的多层次评估。
6. **性能优势明显**：与 SwinIR 相比，在更小的模型（1.67M vs 11.46M）和更快速度下，所有质量指标全面胜出，证明了方案的可信度。

### 八、不足与局限

1. **仿真与真实成像的差距**：
   - 在近似线性化的 sRGB 上操作而非真实 RAW 数据，无法建模完整的相机 ISP 流程（去马赛克、白平衡、色彩校正、色调映射等）；
   - NSP 参数固定，未做相机特定标定，"物理引导"的精确度有限，作者也承认这是一种近似方案。
2. **对比方法数量不足**：仅与 Real-ESRGAN 和 SwinIR 对比，缺少与同量级轻量去噪模型（如 LPIENet、MOFA）以及经典去噪网络（DnCNN、CBDNet、RIDNet）的直接比较，说服力受到一定限制。
3. **消融实验不够深入**：
   - 仅 3 组配置，未独立验证 NSP 中像素串扰对最终性能的增益；
   - 未对关键超参数（λ_KD、λ_per、串扰强度 ρ、噪声参数 K/σ_TL/σ_r）进行敏感性分析。
4. **训练/推理细节披露不完整**：未报告训练时长、能耗、具体部署平台（Android/iOS/NPU/GPU）和端侧实测延迟——仅报告了数据中心的 RTX 3090 上的运行时间，与真实移动设备场景仍有差距。
5. **泛化性与实验覆盖**：仅在单一真实测试集上评估，未在 SIDD、DND 等公开标准 benchmark 上验证跨域泛化能力；数据集的规模也偏小。
6. **指标细节存疑**：CLIP-IQA 在消融表中 Lite-RRDB + KD 反而比 Lite-RRDB 更差（0.3607 vs 0.3590，仅提高 0.0017），与论文"KD 显著提升"的论点不完全一致，需要更多解释。
7. **应用局限**：模型以单帧图像去噪为目标，未考虑视频去噪、突发多帧去噪等移动端常见场景；也未讨论模型在不同噪声水平下的鲁棒性。
