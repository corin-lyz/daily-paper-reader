## 摘要
用于驾驶、机器人和增强现实的立体深度估计必须在严格的延迟预算下以高分辨率运行，然而在基于Transformer的匹配器中，聚合场景上下文的全局自注意力随像素数量呈二次方增长，并逐渐主导运行时。我们表明，立体Transformer的联合自注意力阶段——其作用是在两个视图之间传播上下文——可以被一种数据无关的Walsh-Hadamard令牌混合器所取代，该混合器在对数线性成本下在变换域中全局混合令牌，而执行左右对应关系的数据相关的交叉注意力得以保留。在合成驾驶数据上，该混合器在端点误差上与注意力基线相当，同时将模型计算量减少2.46倍，单图像推理延迟减少2.65倍。复杂度分析表明，这种收益由序列长度与通道宽度的比率决定，这解释了为什么高分辨率立体匹配是一个特别有利的场景，而分类Transformer则不然；我们在非立体长序列基准上证实了这种令牌到通道的缩放规律。此外，我们引入了一种混合对数视差损失函数，旨在为对应于远距离对象的小视差像素赋予更高权重。这种方法在不产生任何额外计算开销的情况下减少了远处对象的误差。

## Abstract
Stereo depth estimation for driving, robotics and augmented reality must run at high resolution under tight latency budgets, yet in transformer-based matchers the global self-attention that aggregates scene context grows quadratically with the number of pixels and comes to dominate runtime. We show that the joint self-attention stage of a stereo transformer, whose role is to spread context across both views, can be replaced by a data-independent Walsh-Hadamard token mixer that mixes tokens globally in the transform domain at log-linear cost, while the data-dependent cross-attention that performs left-right correspondence is retained. On synthetic driving data the mixer matches the attention baseline in end-point error while reducing model compute by a factor of 2.46 and single-image inference latency by a factor of 2.65. A complexity analysis shows the benefit is governed by the ratio of sequence length to channel width, which explains why high-resolution stereo matching is a particularly favorable setting and why classification transformers are not; we confirm this token-to-channel scaling on non-stereo long-sequence benchmarks. Furthermore, we introduce a hybrid log-disparity loss function designed to up-weight small-disparity pixels corresponding to long-range objects. This approach reduces the error on distant objects without incurring any additional computational overhead.

## 1. 核心问题与研究动机

- 立体深度估计在自动驾驶、机器人和增强现实等场景中要求**高分辨率**与**低延迟**，但基于 Transformer 的立体匹配模型（如 STTR）存在关键瓶颈：
  - 全局自注意力用于聚合场景上下文，其计算复杂度为 **O(N²)**，随像素/令牌数量二次增长，在高分辨率输入下成为运行时主要开销。
- 论文指出，立体 Transformer 中的注意力实际承担两种不同角色：
  - **联合自注意力**：在左右两视图之间传播全局上下文，本质上只是上下文聚合，不依赖具体内容；
  - **交叉注意力**：真正执行左-右像素的对应关系匹配，必须依赖图像内容。
- 核心洞察：既然只有交叉注意力需要数据依赖，联合自注意力可以被**数据无关的固定全局算子**替代，从而在保持精度的同时大幅降低计算量。

## 2. 方法论

### 2.1 核心思想

- 提出 **WHTMix**：用 **Walsh-Hadamard 变换（WHT）** 作为数据无关的全局令牌混合器，替代联合自注意力；保留数据相关的交叉注意力用于左右匹配。
- WHT 是正交、实数、无乘法（仅加法）的变换，可通过蝶形算法在 **O(N log N)** 时间内计算。

### 2.2 WHTMix 模块结构

- 输入：联合左右视图的令牌序列 X ∈ R^{N×C}，其中 N 为令牌数，C 为通道宽度。
- 计算流程：

  ```
  Z = X · W_in
  Z ← H_C^{-1}( g_c ⊙ H_C(Z) )   # 通道维 WHT，逐频率可学习增益
  Z ← H_N^{-1}( g_t ⊙ H_N(Z) )   # 令牌维 WHT，逐频率可学习增益
  Y = Z · W_out
  ```

- 说明：
  - H_C、H_N 分别沿通道维和令牌维做正交 WHT；
  - g_c、g_t 为可学习的对数域逐频率增益，初始化为 0（即单位增益）；
  - 令牌维度先零填充到最近的 2 的幂；
  - 两个变换均为正交、保幅的，因此层堆叠稳定；
  - WHTMix 是线性模块，非线性由后续的前馈网络提供；
  - 它完全兼容原自注意力的调用签名，可即插即用，无需改动其余结构。

### 2.3 混合对数视差损失（Hybrid Log-Disparity Loss）

- 问题：标准掩码 ℓ1 损失被大视差（近处物体）主导，小视差（远处物体）监督不足。
- 方案：对每个有效像素 p 赋予权重

  ```
  w_p = clip( τ / d_p, 1, w_max )
  ```

  其中 d_p 为真值视差，τ = 16，w_max = 32。

- 损失形式：加权 ℓ1，即

  ```
  (1 / Σ w_p) Σ w_p |d_p − d̂_p|
  ```

- 优点：在不增加任何推理计算开销的情况下，提高远距离物体的训练权重。

### 2.4 复杂度分析

- 自注意力块开销（MACs）：
  - 投影：4NC²
  - 二次核心：2N²C
- WHTMix 开销：
  - 两个投影：约 2NC²（WHT 蝶形仅加法，不计 MACs）
- 模块级加速比：

  ```
  S_mod = (4NC² + 2N²C) / (2NC²) = 2 + N/C
  ```

  - 交叉点：N = 2C。当 N << 2C 时，自注意力由投影主导，替换收益小；当 N >> 2C 时，二次核心主导，收益随 N/C 线性增长。
- 端到端加速比（考虑保留交叉注意力和前馈网络）：

  ```
  S_e2e = (16NC² + 3N²C) / (14NC² + N²C) = (16C + 3N) / (14C + N) → 3 (当 N→∞)
  ```

  - 即端到端加速比存在约 3× 的理论上限，原因在于真正的匹配（交叉注意力）不可被固定算子替代。

## 6. 主要结论与发现

- **效率显著提升**：在 CARLA 上，WHTMix 相比注意力基线，计算量降低 **2.46×**，单图推理延迟降低 **2.65×**，而 EPE 基本持平（2.27 vs 2.29）。
- **复杂度规律明确**：加速比由 N/C 决定，N >> 2C 时收益显著，N < C 时无益；该规律不仅在立体任务中成立，也在 LRA 的非立体长序列任务中得到验证（N/C=16 时 FLOPs 降 4.3×，N/C=64 时降 13.8×，且精度差距从 6.9 点缩小到 1.6 点）。
- **端到端加速比有上限**：约 3×，且随分辨率增大趋于该上限（896×1792 时实测 2.85×，预测 2.97×）。
- **log 损失有效**：在 2–4 px 和 4–8 px 视差区间（对应远距离物体）EPE 约降低一半（3.29→1.60，3.36→1.94），且无额外延迟成本。
- **真实数据存在精度损失**：在 KITTI 上，固定混合器比自适应注意力的适配能力差，说明数据无关算子在小规模真实数据微调场景下处于劣势，但效率优势依然保持。

## 7. 优点

- **动机清晰、洞察深刻**：将注意力拆分为“上下文聚合”和“内容匹配”两类，准确识别出前者可被固定算子替代，后者必须保留，这为后续工作提供了很好的思路。
- **方法简洁、即插即用**：WHTMix 完全兼容原模块接口，可直接替换；WHT 无乘法、正交、保幅，实现轻量且层叠稳定。
- **复杂度分析闭环**：给出从模块级到端到端的闭式加速比公式，并能精确预测测量结果（如 512×1024 处预测 2.90× vs 实测 2.65×），指导性很强。
- **跨任务验证**：将 N/C 规律推广到非立体的 LRA 任务，增强了结论的普适性，而不仅仅局限于立体匹配。
- **诚实报告缺陷**：如实披露 KITTI 上的精度下降和单 seed 限制，不回避不利结果。
- **附加贡献无开销**：混合对数视差损失不增加推理成本，即可显著改善远处物体误差，实用价值高。

## 8. 不足与局限

- **真实数据适配能力弱**：在 KITTI 上 WHTMix 的 EPE 明显高于注意力基线（2.670 vs 2.204），说明固定算子在小规模真实数据微调时缺乏自适应调整能力，实用部署前需要更大规模真实预训练。
- **基准覆盖有限**：未在 Scene Flow、KITTI 官方测试集、ETH3D 等标准立体基准上与主流方法（RAFT-Stereo、IGEV-Stereo、FoundationStereo）进行比较，缺乏在更全面数据上的竞争力证据。
- **实验统计性不足**：LRA 实验为单 seed，缺少多次运行的平均值和方差；主实验也未报告多次重复的波动范围。
- **数据规模小**：合成数据仅约 2,200 帧，真实数据仅 200 帧，可能不足以充分验证模型泛化能力。
- **架构适用范围有限**：只在 STTR 风格的 backbone 上验证，对当前更主流的成本体积网络（如 IGEV-Stereo）或其他 Transformer 变体（如 HART）没有直接测试。
- **训练资源信息缺失**：未说明训练耗时、GPU 卡数等，不利于复现和成本评估。
- **端到端加速比上限约 3×**：由于必须保留交叉注意力，加速收益存在天花板，无法通过进一步替换获得更大加速。
- **远距离物体精度改善伴随整体精度的轻微回退**：log 损失在远区间显著改善，但中近距离（16–32、32–64、64–128 px）E PE 有所上升，整体 EPE 略高于 L1 版本，需要权衡。
