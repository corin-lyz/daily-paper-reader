## 摘要
后训练量化（PTQ）已成为在资源受限设备上部署视觉Transformer（ViTs）的有效解决方案。然而，现有的PTQ方法通常对Transformer组件采用统一的位宽，忽略了它们对量化的异构敏感性，导致精度分配效率低下。本文提出MixFrag，一种面向视觉Transformer的脆弱性引导混合精度PTQ框架。MixFrag首先通过使用小型校准集测量全精度与隔离量化输出分布之间的Kullback--Leibler（KL）散度来估计组件级别的量化脆弱性。然后，它将位分配形式化为多选背包问题（MCKP），从而在目标位预算下实现自适应的逐层精度分配。在多个视觉Transformer架构上进行的ImageNet-1K广泛实验表明，MixFrag在实际混合精度设置下取得了有竞争力的分类性能。此外，在COCO目标检测和实例分割上的评估表明，MixFrag在现有混合精度PTQ方法中取得了最先进的性能，在具有挑战性的MP3/MP3设置下，比之前的最佳方法提高了高达9.6 AP。额外分析验证了所提出的脆弱性度量，并展示了其与学习到的位分配的强相关性。这些结果确立了MixFrag作为视觉Transformer混合精度后训练量化的有效框架。

## Abstract
Post-training quantization (PTQ) has emerged as an effective solution for deploying Vision Transformers (ViTs) on resource-constrained devices. However, existing PTQ methods typically employ uniform bit-widths across transformer components, overlooking their heterogeneous sensitivity to quantization and leading to inefficient precision allocation. In this paper, we propose {MixFrag, a fragility-guided mixed-precision PTQ framework for Vision Transformers. MixFrag first estimates component-level quantization fragility by measuring the Kullback--Leibler (KL) divergence between full-precision and isolated quantized output distributions using a small calibration set. It then formulates bit allocation as a Multiple-Choice Knapsack Problem (MCKP), enabling adaptive layer-wise precision assignment under a target bit budget. Extensive experiments on ImageNet-1K across multiple Vision Transformer architectures demonstrate that MixFrag achieves competitive classification performance under practical mixed-precision settings. Furthermore, evaluations on COCO object detection and instance segmentation show that MixFrag achieves state-of-the-art performance among existing mixed-precision PTQ methods, improving the previous best method by up to 9.6 AP under the challenging MP3/MP3 setting. Additional analyses validate the proposed fragility metric and demonstrate its strong correlation with the learned bit allocation. These results establish MixFrag as an effective framework for mixed-precision post-training quantization of Vision Transformers.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：Vision Transformers（ViTs）在图像分类、目标检测、语义分割等视觉任务上取得了优异性能，但其高计算复杂度与大内存占用严重制约了在移动设备、边缘系统等资源受限平台上的部署。
- **现有方法的问题**：后训练量化（Post-Training Quantization, PTQ）是降低ViT部署成本的高效手段，仅需少量无标签校准数据。然而，现有PTQ方法大多对所有Transformer组件采用**统一位宽**，忽略了不同组件（如自注意力中的线性投影、MLP层、LayerNorm等）对量化误差的敏感度存在显著差异，导致精度分配低效——脆弱组件精度不足，鲁棒组件则浪费位预算。
- **核心解决思路**：将混合精度量化引入ViT的PTQ流程，先直接度量每个组件的“量化脆弱性”，再在给定平均位宽预算下进行全局最优的位分配，从而提升量化模型的精度与部署效率。

## 2. 论文提出的方法论

MixFrag 是一个三阶段、与量化后端解耦的混合精度PTQ框架：

1. **量化脆弱性估计（Fragility Estimation）**
   - 对每个可量化组件（自注意力和前馈模块中的线性投影层）**独立**进行量化，其余组件保持全精度，使观测到的性能下降仅源于目标组件本身。
   - 用校准集上的**KL散度**度量全精度模型与部分量化模型的输出分布（softmax后logits）差异，作为脆弱性分数：
     Ω(c, b) = (1/N) Σ_{x∈D} D_KL( σ(z_fp(x)/T) ∥ σ(z_{c,b}(x)/T) )
   - 对所有组件和候选位宽重复该过程，得到脆弱性矩阵 Ω ∈ R^{C×B}。

2. **MCKP位分配（Mixed-Precision Bit Allocation）**
   - 将位分配形式化为**多选背包问题（Multiple-Choice Knapsack Problem, MCKP）**：每个组件为一组互斥选项（候选位宽），脆弱性分数作为成本，总位宽受预算约束。
   - 优化目标：min Σ Ω_{i,j} x_{i,j}，约束：每个组件恰好选一个位宽、总位宽 ≤ 目标平均位宽预算。
   - 采用**动态规划（DP）**求解，在多项式时间内获得全局最优分配，避免穷举。

3. **AdaLog量化后端生成混合精度模型**
   - 将优化得到的逐组件位宽配置输入AdaLog PTQ框架：FPCS优化对数底与缩放因子，自适应对数量化器处理Softmax/GELU后的激活，配合偏置重参数化。
   - LayerNorm、残差连接等对数值精度极敏感的操作保留浮点精度。
   - 框架与具体PTQ后端解耦，只要后端支持异构精度即可替换。

## 6. 论文的主要结论与发现

- **量化脆弱性是高度异构的**：少量组件（尤其是网络浅层、注意力模块）贡献了不成比例的量化误差，统一位宽分配本质上低效。
- **MCKP全局优化有效**：在相同KL脆弱性度量下，MCKP分配一致优于随机分配和贪心分配（表6），尽管相对贪心的增益有限。
- **下游任务表现突出**：在COCO上，MixFrag在MP3/MP3设置下平均AP达40.9，较此前最佳混合精度方法LRP-AQViT（31.3 AP）提升**9.6 AP**；MP4/MP4设置下也以45.2 AP略超LRP-AQViT（45.0 AP）。
- **脆弱性指标与位分配强相关**：在W3/A3和W4/A4下，Pearson/Spearman相关系数约0.5–0.57，说明KL散度能有效指导精度分配；W6/A6下相关性自然衰减（位预算充裕时无需选择性分配）。
- **边际细化迭代有害**：重新估计脆弱性并二次求解MCKP反而降低精度（W3/A3下下降超过2%），故采用单次优化设计。
- **ImageNet分类精度不等于下游泛化能力**：尽管MixFrag分类精度不如FIMA-Q等，却在下游检测/分割上全面领先，说明保留关键中间表征对密集预测任务更重要。

## 7. 优点

- **直接度量脆弱性**：不同于Hessian近似、LRP相关性分数等间接代理指标，KL散度直接量化组件量化对模型输出的影响，更直观、可解释。
- **全局最优位分配**：MCKP + 动态规划在目标位预算下获得数学上最优的分配，避免贪心算法的局部最优问题。
- **轻量高效**：单次前向传播即可估计脆弱性，无需重训练或迭代细化，适合实际部署场景。
- **后端无关**：位分配层与量化后端解耦，可灵活适配不同PTQ方法。
- **下游泛化验证充分**：在检测与分割任务上展现了显著优势，超越了已有混合精度PTQ方法，为该领域提供了新的评估视角（超越ImageNet top-1）。

## 8. 不足与局限

- **隔离评估忽略交互**：脆弱性估计假设组件间量化误差独立可加，未建模多个组件同时量化时的协同/抵消效应，可能导致分配次优。
- **分类任务竞争力有限**：在ImageNet上低于FIMA-Q等优化密集型方法，尤其3-bit下差距很大，限制了其在极端低比特场景的适用性。
- **固定校准集偏差**：仅用1,024张ImageNet / 256张COCO图像估计脆弱性，校准集的分布偏差可能影响指标可靠性（论文未做校准集规模敏感性分析）。
- **硬件意识不足**：MCKP仅考虑位宽预算，未引入不同位宽的实际硬件延迟/能耗成本，实际部署收益需要硬件协同设计验证。
- **缺乏系统性效率对比**：论文虽强调“轻量”，但未量化脆弱性估计的总耗时、DP求解时间、相对优化型PTQ方法的端到端加速比。

- **模型覆盖面有限**：未涉及ViT-L/Huge、基础模型（如SAM、DINOv2）或更大规模的Swin变体，结论的泛化性有一定局限。
