## 摘要
视觉Transformer在高分辨率密集预测中面临显著的计算开销，原因是自注意力的二次复杂度。线性注意力提供了效率，但牺牲了局部上下文建模。我们提出了**HSMLA（分层Softmax多尺度线性注意力）**，它结合了基于ReLU的线性注意力用于全局上下文、选择性Softmax细化用于关键局部特征，以及通过深度可分离卷积实现的多尺度令牌表示。HSMLA实现了优越的准确率-效率权衡：在密集预测任务中推理速度最高提升$4.2\times$，在CT器官分割中Dice达到$87.3\%$且速度提升$3.2\times$，在病理WSI中AUC达到$94.2\%$且速度提升$4.1\times$。

## Abstract
Vision transformers face significant computational overheads in high-resolution dense prediction due to the quadratic complexity of self-attention. Linear attention offers efficiency but sacrifices local context modeling. We propose \textbf{HSMLA (Hierarchical Softmax Multi-scale Linear Attention)}, which combines ReLU-based linear attention for global context, selective softmax refinement for critical local features, and multi-scale token representations via depthwise convolutions. HSMLA achieves superior accuracy-efficiency trade-offs: up to $4.2\times$ inference-time speedup across dense prediction tasks, $87.3%$ Dice with $3.2\times$ speedup on CT organ segmentation, and $94.2%$ AUC with $4.1\times$ speedup on pathology WSI.

## 2. 方法论：HSMLA 架构

### 核心思想
HSMLA（Hierarchical Softmax Multi-scale Linear Attention）采用“**全局 + 局部 + 多尺度**”三路互补策略：
- 用 **ReLU 线性注意力**捕获全局上下文依赖（线性复杂度，高效）；
- 用**选择性 Softmax 细化**机制对关键局部特征进行精炼（弥补线性注意力局部建模不足）；
- 用**深度可分离卷积（Depthwise Convolution）**构建多尺度 token 表示（增强对不同粒度结构的感知）。

### 关键技术细节
- **ReLU 线性注意力**：将 softmax 替换为 ReLU 激活函数，利用核技巧将注意力计算转化为线性复杂度形式，高效建模全局关系。
- **选择性 Softmax 细化**：并非对所有 token 都执行高成本的 softmax 注意力，而是**选择性地**对局部关键区域或高频信息区域应用 softmax 注意力，以精确捕捉边界、纹理等细节特征，同时控制额外开销。
- **多尺度 token 表示**：通过不同感受野的深度卷积生成多尺度 token 特征，使得注意力能够在不同粒度下聚合信息，提升对多尺度目标的适应能力。
- **层级化设计（Hierarchical）**：在网络的多个阶段或不同尺度上组合上述机制，形成分层结构，兼顾高层语义与低层细节。

### 算法流程（文字说明）
1. 输入图像被划分为 patch/token 序列。
2. 每个 HSMLA 块内：
   - 对输入 token 应用深度可分离卷积生成多尺度特征；
   - 一路使用 ReLU 线性注意力计算全局上下文；
   - 另一路通过门控/选择机制识别关键局部区域，并使用 softmax 注意力进行细化；
   - 将两路输出融合，经前馈网络后输出。
3. 通过层级堆叠多个 HSMLA 块，形成完整编码器，用于后续密集预测任务。
