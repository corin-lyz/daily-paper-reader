## 摘要
遥感图像指代分割（RRSIS）旨在描绘遥感图像中由自然语言表达所指定的目标。现有方法主要遵循联合融合分割（JFS）或解耦提示分割（DPS）。JFS效率高，但往往因指代定位和掩膜描绘在统一目标下优化而精度受限；而DPS利用空间提示和基础分割器将定位与掩膜生成分离，却以更高的内存消耗和推理延迟为代价。为弥合这一差距，我们提出了DiCoR，一种基于高效JFS流程的解耦指代消解与轮廓重校准框架。DiCoR解决了两个关键挑战：从模糊候选对象中区分正确指代，以及定位后细化粗糙掩膜。一种消歧感知的定位引导策略利用自适应语言线索对显著候选区域进行排序，并将所得定位先验注入融合特征。一个轻量级轮廓重校准模块进一步在局部轮廓监督下预测粗糙逻辑的残差修正，以有限的计算开销提升掩膜质量。在RefSegRS、RRSIS-D和RISBench上的实验表明，DiCoR在所有三个基准上均取得了最佳分割精度。在RefSegRS上，相较于有竞争力的JFS方法，其mIoU和gIoU分别提升了5.28%和2.87%，同时比具有代表性的DPS方法运行速度快4.7%，展现了良好的精度-效率权衡。代码可在https://github.com/zyGao1126/DiCoR获取。

## Abstract
Referring remote sensing image segmentation (RRSIS) aims to delineate targets specified by natural language expressions in remote sensing imagery. Existing methods mainly follow joint fusion segmentation (JFS) or decoupled prompt segmentation (DPS). JFS is efficient but often suffers from limited accuracy because referent localization and mask delineation are optimized under a unified objective, whereas DPS separates localization from mask generation using spatial prompts and foundation segmenters at the cost of higher memory consumption and inference latency. To bridge this gap, we propose DiCoR, a decoupled referent disambiguation and contour recalibration framework built on an efficient JFS pipeline. DiCoR addresses two key challenges: distinguishing the correct referent from ambiguous candidates and refining coarse masks after localization. A disambiguation-aware localization guidance strategy ranks salient candidate regions with adaptive linguistic cues and injects the resulting localization prior into fused features. A lightweight contour recalibration module further predicts residual corrections to coarse logits under localized contour supervision, improving mask quality with limited computational overhead. Experiments on RefSegRS, RRSIS-D, and RISBench show that DiCoR achieves the best segmentation accuracy across all three benchmarks. On RefSegRS, it improves mIoU and gIoU by 5.28% and 2.87% over a competitive JFS method while running 4.7% faster than a representative DPS method, demonstrating a favorable accuracy-efficiency trade-off. Code is available at https://github.com/zyGao1126/DiCoR.

## 1. 论文的核心问题与整体含义

遥感图像指代分割（RRSIS）旨在根据自然语言描述在遥感影像中定位并分割指定目标，是视觉-语言理解与对地观测结合的重要方向。现有方法可分为两大范式：

- **联合融合分割（JFS）**：通过骨干网络中的跨模态融合将语言特征注入视觉特征，端到端联合学习目标定位与掩膜生成。优势是单次前向即可得到掩膜、推理效率高；**缺点是**定位与分割在统一像素级目标下优化，模型容易偏向优化对损失贡献更大的粗定位误差，对定位完成后的边界细节修正不足。在遥感场景中，小目标密集、语义边界敏感，这一缺陷更为突出。
- **解耦提示分割（DPS）**：先用视觉-语言模型生成空间提示（如框、点），再交由SAM等基础分割模型生成最终掩膜。优点是定位与掩膜生成职责清晰、边界质量高；**缺点是**引入大型基础模型导致内存占用和推理延迟大幅上升，且对遥感域的传感器差异、复杂背景等分布偏移敏感。

**核心研究问题**：能否在保持 JFS 高效推理的同时，获得 DPS 所具备的可靠目标定位与精细轮廓能力？为此，论文提出 DiCoR——一个解耦指代消解与轮廓重校准框架，以轻量模块和任务专用监督在高效流程内实现"近似DPS的解耦效果"，无需在推理阶段依赖重型基础模型。

## 2. 方法论

DiCoR 基于高效的 JFS 流程构建，围绕两个核心挑战设计了两个解耦模块：

**（1）消歧感知定位引导（DLG）**

- **动机**：特征图 X₃ 往往同时激活真实目标和多个混淆干扰目标，标准像素级监督无法显式解决同一图像内多个候选实例间的竞争。
- **核心思想**：将指代目标定位重构为**候选级竞争**问题。
- **工作流程**：
  1. **稠密响应估计器**：从第三级融合特征 X₃ 预测响应图 R（两个轻量Conv-Norm-GELU块 + Sigmoid）；
  2. **候选生成器**：从 R 中通过局部极大值选取、NMS 抑制冗余、保留 Top-K 峰值构建候选集；每个峰值经高斯门控响应聚合形成候选支撑区，再池化出视觉特征 Fᵥ 和几何特征 F꜀（归一化中心、有效面积、空间离散度）；
  3. **候选排序器**：每个候选的视觉+几何嵌入与语言特征交互，通过路由网络生成候选自适应的 token 权重，进而得到候选特定文本表征；最终按语义相似度与几何一致性加权得分选出最优候选；
  4. **空间重校准**：将获胜候选支撑区作为定位先验注入 X₃（`X̃₃ = X₃ ⊙ (1 + αCᵢ*)`），引导后续解码聚焦真实目标。
- **监督策略**：响应监督（将响应空间划分为目标正区、干净背景、SAM3 离线挖掘的困难实例背景） + 排名监督（交叉熵损失强制正确候选胜出）。

**（2）轻量轮廓重校准（LCR）**

- **动机**：标准像素级监督下，目标大致定位后，边界偏差产生的梯度远弱于残余定位误差，导致轮廓优化不足。
- **核心思想**：将粗糙掩膜的轮廓修正显式解耦为**残差校正**问题。
- **实现**：以输入图像 I 和粗预测 P = σ(Z) 为输入，轻量编解码器（带镜像跳跃连接）预测 logit 域的残差修正 ΔZ，最终预测 `Z̃ = Z + ΔZ`。
- **监督**：区域感知损失——构造权重图 W(u)，对预测轮廓附近像素赋予更高权重、对置信度高区域赋予更低权重，以加权交叉熵 + Dice 联合优化。
- **训练数据构造**：从多个中间检查点收集粗预测，保留 IoU ∈ [0.5, 0.95) 的可靠定位样本，并通过形态学膨胀/腐蚀扰动扩充边界偏差分布。

**（3）解耦训练策略**：先训练 JFS 基线，再分别预训练 DLG（提取第三层特征）和 LCR（收集粗解码 logits），最后对 DLG 进行联合精调使其与分割监督协同，LCR 则直接插入。

## 7. 优点

1. **问题定位精准**：准确识别了 JFS 范式存在的两个核心瓶颈——候选指代歧义和轮廓优化信号不足，并分别设计解耦机制应对，逻辑清晰。
2. **设计轻量高效**：DLG 和 LCR 均为轻量模块，不引入基础模型，推理开销增量极小，在精度显著提升的同时保持 JFS 的效率优势，实现了"鱼与熊掌兼得"。
3. **创新性地引入候选竞争机制**：将指代定位从隐式像素分类重构为显式候选排序问题，并配合 SAM3 离线挖掘的困难负实例进行结构化监督，方法新颖且有效。
4. **残差轮廓重校准思路巧妙**：LCR 并非从零重新分割，而是以粗预测为条件学习局部残差，配合区域感知加权损失，以极低成本集中在边界不确定区域进行修正。
5. **数据构造策略细致**：多检查点采样 + 定位质量过滤 + 形态学扰动，使 LCR 面对更真实的粗预测分布，提升了鲁棒性。
6. **实验体系完整**：三个基准、多组消融、效率评估和可视化分析的组合，使得结论具有较强的说服力。

## 8. 不足与局限

1. **对初始响应图的依赖**：DLG 的候选生成完全依赖响应图 R 的质量；若响应估计器未能在真实目标附近激活，后续候选生成与排序将无法恢复正确目标。论文也承认空间先验注入存在性能上限，未直接优化早期特征提取与跨模态融合。
2. **大目标轮廓修正能力有限**：LCR 的局部残差校正对小型目标效果明显（其粗掩膜常表现为局部缺失或边界侵蚀），但大目标的边界误差通常涉及较长轮廓和更广泛的结构性不一致，难以仅靠局部残差修正，需要更强全局边界建模。
3. **训练流程较复杂**：DLG 和 LCR 需分别预训练（依赖多检查点收集粗预测），再联合精调，阶段较多，工程实现和调参成本较高。
4. **算力信息不透明**：未报告 GPU 数量、总训练时长等关键资源信息，对实际部署和复现成本评估造成困难。
5. **对 SAM3 离线挖掘的依赖**：DLG 的硬负样本来自冻结 SAM3 模型，这一依赖是否在模型不可用或遥感域适配不佳时引入偏差，值得进一步评估。
6. **评估范围的局限**：所有实验均在公开 RRSIS 数据集上进行，未涉及实时部署场景下的端到端延迟、内存占用峰值等更贴近实际应用的指标；方法在更多模态（如多光谱、SAR）上的泛化能力尚不明确。
