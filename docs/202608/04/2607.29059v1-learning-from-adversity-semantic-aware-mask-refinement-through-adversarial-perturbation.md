## 摘要
尽管图像分割取得了显著进展，即使是顶尖的模型也会产生具有不完美边界、语义不一致和结构错误的掩码。掩码细化旨在解决这些局限性，但当前的方法依赖于过于简单的合成噪声，无法捕捉真实分割模型的复杂错误模式。我们提出了Phoenix，一个新颖的框架，利用对抗学习生成具有语义意义的噪声模式，并利用对比学习来建模细化关系。我们的方法包含两个关键创新：（1）对抗性掩码扰动，采用嵌入攻击来创建模拟真实分割错误的语义感知噪声；（2）对比性掩码细化学习，建立一个三向框架，确保语义区域内的特征一致性，同时保持类别间的分离。实验表明，Phoenix在各种任务上显著优于现有方法，并持续提升最先进的分割模型，带来实质性改进。我们的代码和项目页面可在 https://phoenix-eccv26.github.io 公开获取。

## Abstract
Despite significant advances in image segmentation, even state-of-the-art models produce masks with imperfect boundaries, semantic inconsistencies, and structural errors. Mask refinement addresses these limitations, yet current approaches rely on simplistic synthetic noise that fails to capture the complex error patterns of real segmentation models. We introduce Phoenix, a novel framework that leverages adversarial learning to generate semantically meaningful noise patterns and contrastive learning to model refinement relationships. Our approach consists of two key innovations: (1) Adversarial Mask Perturbation, which employs embedding attacks to create semantic-aware noise that mimics real segmentation errors, and (2) Contrastive Mask Refinement Learning, which establishes a tri-directional framework that ensures feature consistency within semantic regions while maintaining separation between classes. Experiments demonstrate that Phoenix significantly outperforms existing methods across diverse tasks, while consistently enhancing state-of-the-art segmentation models with substantial improvements. Our code and project page are publicly available at https://phoenix-eccv26.github.io.

### 1. 核心问题与研究动机

- **问题背景**：尽管图像分割模型（如 SAM、Mask2Former、SegFormer 等）已达到很高精度，但生成的掩码仍普遍存在三类缺陷：
  - 复杂轮廓处边界不精确；
  - 相似物体间语义混淆；
  - 违反物体完整性的结构错误（如孔洞、断裂、误分割）。
- **核心局限**：掩码细化（Mask Refinement）旨在不重训原始模型的情况下修正上述错误，但现有方法存在根本性缺陷：
  - 依赖形态学操作（腐蚀/膨胀）生成合成噪声，产生**简单、随机、非语义**的扰动模式；
  - 无法模拟真实分割模型产生的**结构化、上下文相关**的错误；
  - 噪声模式多样性不足，无法覆盖真实模型多样的失败模式。
- **本文意义**：针对上述空白，论文提出将**对抗扰动从破坏性测试工具重新构建为建设性数据增强机制**，使细化模型在训练时面对"真实且有意义的困难"，从而获得更强的细化能力。论文将这一思想命名为"Phoenix"（凤凰涅槃）。

### 2. 方法论：Phoenix框架

Phoenix 建立在预训练 SAM（ViT-H）之上，冻结 637M 参数的编码器，仅微调 4M 参数的轻量级解码器。框架由两大核心创新组成。

#### （1）对抗性掩码扰动（AMP：Adversarial Mask Perturbation）

- **核心思想**：从目标掩码 Mt 出发，将可学习的扰动嵌入 Ep 注入冻结的解码器输入端（与视觉提示嵌入拼接），通过 FGSM 在嵌入空间迭代更新扰动，使解码器输出产生偏离目标掩码的噪声掩码。
- **更新公式**：Ep ← Ep + α · sign(∇Ep Ladv)，其中 Ladv 为对抗目标（默认 Dice Loss），α 控制扰动强度。
- **语义感知的特性来源**：在冻结解码器上，梯度的空间分布与模型的预测不确定性成正比（∝ -log p(y|·)），因此在模型最不确定的边界和语义模糊区域产生更强扰动，从而使噪声掩码在语义上更接近真实分割错误。
- **可控噪声生成**：通过"引导掩码 Mg"控制错误的语义方向：
  - 膨胀引导（Mg=1）：产生假阳性（过分割）；
  - 收缩引导（Mg=0）：产生假阴性（欠分割）；
  - 反转引导（Mg=1-Mt）：两种错误平衡分布。
- **自适应强度校准**（Algorithm 1）：通过 IoU 阈值 τ 自动调整扰动强度，使生成噪声的 IoU 落在 [τ, τ+ϵ] 区间内；τ 在训练时从 U(0.3, 0.9) 随机采样，以覆盖从轻度到重度噪声的范围。
- **语义相关性验证**：在 LVIS 数据集上计算噪声分布与边缘/纹理特征的 Pearson 相关性，对抗噪声的相关性范围横跨 [-0.6, 0.8]（正负均有，表示既能对齐语义结构也能覆盖均匀区域），而形态学噪声仅集中在 0 附近，证明 AMP 比形态学噪声更真实多样。

#### （2）对比掩码细化学习（CMRL：Contrastive Mask Refinement Learning）

- **核心思想**：在特征空间中显式建模"目标掩码 Mt、噪声掩码 Mn、当前预测掩码 Mr"三者之间的关系，优于逐像素独立分类的传统方法。
- **六区域划分**：根据三掩码在每像素的分类组合，将像素划分为六个互斥区域：
  - T_fg / T_bg：三者一致正确（真前景/真背景）；
  - S_fg / S_bg：噪声中错误但被成功修正（成功区）；
  - F_fg / F_bg：噪声中错误且未被修正（失败区）。
- **三向损失组件**（总损失 LCMRL = λintra·Lintra + λinter·Linter + λself·Lself，默认 0.4/0.4/0.2）：
  - **类内一致性**（Lintra）：将失败区特征拉向同类的正确区特征（InfoNCE 形式），确保同一语义区域内特征一致；
  - **类间对比**（Linter）：将前景失败特征推离所有背景特征（双向），强化类间分离，建立清晰决策边界；
  - **自改进正则**（Lself）：将当前失败区特征拉向同一图像内已被成功修正的区域特征，利用自身成功经验引导持续改进（bootstrap 机制）。
- **训练总目标**：L = LSAM + λCMRL·LCMRL（λCMRL=1×10⁻³），LSAM 为 Focal 与 Dice 损失 20:1 的组合。

### 6. 主要结论与发现

1. **AMP 显著优于形态学噪声**：对抗生成的语义感知噪声更贴近真实分割模型的错误分布（Pearson 相关性分布验证），使细化模型学会处理真正的"困难区域"。
2. **CMRL 的三向对比框架有效**：类内一致性、类间对比与自改进正化的组合在实例和细粒度分割上均带来一致增益。
3. **AMP 与 CMRL 存在协同效应**：两者结合超越各自贡献之和（IoU 增益 +10.4% vs. 单独 +6.2% 与 +2.5%），因为真实噪声模式使三向对比关系蕴含更丰富的信息。
4. **Phoenix 具有强泛化能力**：仅用 LVIS 训练即可零样本迁移到 Cityscapes 和 ISIC2018 医学图像；对 COCO 人工标注也能有效修正。
5. **高计算效率**：冻结编码器 + 微调 4M 参数，10 小时完成训练，实现精度与效率的良好平衡。

### 8. 不足与局限

- **失败场景边界明确**：
  - 完全错位的输入掩码（与真实目标无空间重叠）无法修复——细化方法本质依赖初始掩码质量；
  - 目标物体本身模糊（如遮挡、多对象纠缠）时细化的任务定义本身变得不明确；
  - 类不可知设计导致**无法修正语义分类错误**（如将帆船错分为人），缺少类别条件推理能力。
- **实验覆盖的潜在偏差**：
  - 核心训练数据以 LVIS（长尾自然图像）为主，虽然零样本验证了迁移能力，但未覆盖所有类型（如视频、3D、航空影像等）；
  - 自监督设置依赖 SAM 的零样本能力，在 SAM 本身较弱的细粒度任务上效果明显下降（AP 完整监督 28.7 vs. 自监督 27.4；IoU 75.7 vs. 58.0）；
  - 对形态学噪声的替代实验仅在 SegRefiner 和 Phoenix 两种架构上进行，基线更广时的结论有待验证。
- **应用限制**：
  - 对抗扰动生成的噪声虽然近似真实，但并非对任意分割模型都能精确匹配错误类型（论文也承认"真实错误"并没有统一定义）；
  - 引入额外的扰动嵌入与对比投影器增加了训练流程的复杂度，对工程实现有一定门槛；
  - 需要可区分的解码器参与扰动计算，对纯黑盒模型不直接适用。
