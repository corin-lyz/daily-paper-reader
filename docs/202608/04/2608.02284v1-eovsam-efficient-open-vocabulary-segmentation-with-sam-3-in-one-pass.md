## 摘要
开放词汇分割旨在从任意文本描述中识别并分割目标。SAM 3支持名词短语引导的分割，并通过穷举词汇遍历取得了具有竞争力的开放词汇性能，但随着目标类别规模的扩大，其计算开销变得难以承受。本文提出了一种基于SAM 3的高效开放词汇分割框架（EOVSAM），将SAM 3适配为单遍预测。EOVSAM移除提示条件，将SAM 3转变为高效的掩码生成器，并引入新的注意力聚合策略以端到端优化开放词汇分类。该形式避免了现有方法常用的多阶段流程和后处理启发式方法，同时缓解了直接优化分类时可能出现的闭集坍缩问题。EOVSAM在所有评估数据集上均比原始SAM 3持续提升分割精度，并将推理加速高达338倍。此外，EOVSAM在较低分辨率下仍保持高精度，同时实现了更显著的推理速度。在标准语义分割和全景分割基准上的实验表明，EOVSAM在具有竞争力或最先进的精度的同时，相比现有开放词汇分割模型拥有显著的速度优势。代码和模型可在 https://github.com/hustvl/EOVSAM 获取。

## Abstract
Open-vocabulary segmentation identifies and segments objects from arbitrary textual descriptions. SAM 3 supports noun-phrase-guided segmentation and achieves competitive open-vocabulary performance through exhaustive vocabulary traversal, yet suffers from prohibitive computational overhead as target categories scale. In this paper, we propose an Efficient Open-Vocabulary segmentation framework with SAM 3 (EOVSAM), which adapts SAM 3 for single-pass prediction. EOVSAM removes prompt conditioning to turn SAM 3 into an efficient mask generator and introduces a new Attentional Aggregation strategy to optimize open-vocabulary classification end-to-end. This formulation avoids the multi-stage pipelines and post-processing heuristics commonly used by existing methods, while mitigating the closed-set collapse that can arise when classification is optimized directly. EOVSAM consistently improves segmentation accuracy over vanilla SAM 3 on all evaluated datasets and accelerates inference by up to 338$\times$. Furthermore, EOVSAM maintains high accuracy at lower resolutions while achieving even more remarkable inference speeds. Experiments on standard semantic and panoptic segmentation benchmarks show that EOVSAM combines competitive or state-of-the-art accuracy with a substantial speed advantage over existing open-vocabulary segmentation models. Code and models are available at https://github.com/hustvl/EOVSAM.

## 一、核心问题与整体含义（研究动机与背景）

开放词汇分割（Open-Vocabulary Segmentation, OVS）旨在根据任意文本描述来识别并分割图像中的目标，其核心挑战在于模型需要泛化到训练时未见过（unseen）的类别。传统分割方法受限于固定的训练类别集合，而密集像素级标注成本高昂，导致数据集语义覆盖范围有限，难以应对真实世界开放场景。

**关键背景与矛盾：**

- **SAM 3的能力与瓶颈**：SAM 3原生支持名词短语引导的概念分割，通过穷举词汇遍历（对每个类别执行一次前向传播）可实现开放词汇分割，精度表现良好；但其推理开销随目标类别数量**线性/急剧增长**，当词汇表规模较大时计算成本变得“难以承受”（prohibitive）。
- **现有适配方法的不足**：已有工作或通过特征融合（如EBSeg、FrozenSeg）将SAM特征注入现有开放词汇流程但增益有限，或通过生成伪提示（prompt）驱动SAM逐一处理，由于每个提示独立处理而引入大量额外计算。
- **核心研究问题**：如何在保留SAM 3强大定位能力的同时，消除其多遍推理（multi-pass inference）的计算瓶颈，实现**单遍（single-pass）**的开放词汇分割，并在效率和精度之间取得更优平衡。

## 二、方法论：核心思想与关键技术

### 2.1 核心思想

将SAM 3从“提示条件化（prompt-conditioned）的概念分割模型”改造为“**无提示（prompt-free）的掩码生成器**”，使其在一次前向传播中同时完成掩码定位与开放词汇识别，从而消除多遍推理的计算冗余。

### 2.2 架构与关键设计

论文提出的EOVSAM架构改造包括以下核心组件：

1. **视觉骨干网络：C-RADIOv4**
   - 采用聚合式视觉基础模型C-RADIOv4（从SigLIP 2、DINOv3、SAM 3三个教师模型蒸馏而来）作为视觉骨干。
   - 其配备两个轻量适配器头，并行提取两组特征：面向SAM 3的`F_sam`和面向SigLIP 2的`F_siglip`，避免使用多个独立视觉编码器带来的计算负担。

2. **移除提示条件（Prompt Conditioning Removal）**
   - 删除SAM 3融合编码器（fusion encoder）和检测器解码器中的**文本交叉注意力层**，使模型不再依赖文本提示即可生成掩码，同时减少计算冗余。
   - 这一设计使得“无提示架构”不仅消除了计算瓶颈，还在消融实验中显示精度略有提升。

3. **双分类器设计**
   - **SigLIP 2文本编码器**编码完整类别词汇，生成SigLIP分类器`T_siglip`（用于开放词汇识别）。
   - **SAM 3文本编码器**编码预定义词汇并附加一个可学习背景token，形成SAM分类器`T_sam`（用于目标存在性判定和辅助分类）。
   - 推理时对两个分类器的输出进行**几何集成（geometric ensembling）**，统一设置α=0.7（可见类别）、β=1.0（不可见类别）。

4. **注意力聚合（Attentional Aggregation）**
   - 检测器解码器包含6层transformer层和200个可学习对象查询（object queries）。
   - 引入一组可学习的每注意力头权重系数，将多头注意力图池化为分类导向的注意力图`A ∈ R^{N×h×w}`。
   - 由于对象查询与增强特征在所有层中持续交互，注意力图与SigLIP视觉特征`F_siglip`保持精确的点对点空间对应关系。
   - 最终通过软注意力图对SigLIP特征进行动态聚合，得到区域特定的对象嵌入`O ∈ R^{N×C}`。

5. **单遍联合优化**
   - 掩码预测：`M = E_mask × F_seg`（掩码嵌入与高分辨率特征图点积）。
   - 分类预测：对象嵌入与SigLIP文本嵌入的余弦相似度经softmax得到分类概率。
   - 同时通过掩码池化对`F_seg`生成的特征与`E_mask`相加，用于与SAM分类器计算目标性分数。

### 2.3 关键公式

- **注意力聚合**：`o_i = Σ_(u,v) A(i,u,v) · F_siglip(:,u,v)`——利用软注意力图对视觉特征进行空间加权聚合。
- **分类概率**：`P_(i,k) = exp(cos(o_i, t_k)/τ) / Σ_j exp(cos(o_i, t_j)/τ)`——基于余弦相似度的softmax分类。

### 2.4 训练目标

总损失函数为多任务加权和：

`L_total = λ_ce·L_ce + λ_bce·L_bce + λ_dice·L_dice + λ_cls·L_cls + λ_L1·L_L1 + λ_giou·L_giou`

其中`L_ce`（分类损失）主要监督目标存在性（泛化能力有限），`L_cls`专门用于开放词汇识别，`L_bce`和`L_dice`为掩码损失，`L_L1`和`L_giou`为边界框回归损失。权重系数分别设为3、5、5、1、5、2。

## 六、主要结论与发现

1. **精度全面超越SAM 3**：EOVSAM在全部5个语义分割基准上相较原始SAM 3均有提升（A-150 +1.2、A-847 +2.6、PC-59 +2.6、PC-459 +2.1、PAS-20 +0.7 mIoU）。

2. **推理速度大幅提升**：相比SAM 3的多遍推断，EOVSAM在完整分辨率下实现最高**338×加速**；在较低分辨率（512）下进一步加速，同时仍保持较好精度（A-150 mIoU 37.0、A-847 mIoU 15.4）。

3. **开放词汇全景分割SOTA**：在ADE20K上达到PQ 30.9、RQ 37.3，创下开放词汇全景分割的新纪录（相比此前最优GBA的29.6 PQ提升+1.3）。

4. **单遍设计的有效性验证**：
   - 加载SAM 3预训练权重至关重要（去除后A-150 mIoU从39.0降至35.2，PQ从30.9降至24.2）。
   - 注意力聚合是模型实现开放词汇泛化的关键组件（去除后复杂场景下mIoU暴跌至22.6/5.1，PQ降至19.8）。
   - 辅助框监督提供有效的显式空间指导（各数据集均有正向贡献）。
   - 移除文本交叉注意力不仅消除计算瓶颈，还微弱提升精度。

5. **低分辨率可扩展性**：单一检查点可在不同分辨率下推理而无需重新训练，提供灵活的延迟-性能权衡选项。

## 七、方法或实验设计的优点

1. **方法创新性突出**：将SAM 3从逐概念分割模型改造为单遍掩码生成器，是首个端到端单遍适配SAM 3的开放词汇分割框架，有效解决计算瓶颈。

2. **注意力聚合设计巧妙**：利用可学习权重系数池化多头注意力图，构造与SigLIP特征精确对齐的软注意力图，在保持端到端可微性的同时避免非可微二值掩码导致的梯度截断问题（对比Mask Pooling和Mask-Adapter的局限）。

3. **双分类器集成策略**：结合SAM 3分类器（定位能力强，闭集）和SigLIP 2分类器（泛化能力强，开放集）的几何集成，兼顾目标存在性判断和开放词汇识别，并有效缓解闭集坍缩。

4. **充分利用已有预训练资源**：完全冻结视觉骨干和两个文本编码器，仅训练解码器部分，参数效率高；继承SAM 3的定位先验和C-RADIOv4的多功能特征。

5. **灵活的部署适配性**：支持任意分辨率输入而无需针对特定分辨率微调，适应延迟敏感和资源受限场景。

6. **实验对比严谨**：在同一GPU上测速、使用相同类别列表和预计算文本特征，标注复现结果，公平性较好。
