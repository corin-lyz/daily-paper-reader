## 摘要
用于驾驶、机器人和增强现实的立体深度估计必须在严格的延迟预算下以高分辨率运行，然而在基于Transformer的匹配器中，聚合场景上下文的全局自注意力随像素数量呈二次方增长，并逐渐主导运行时间。我们表明，立体Transformer的联合自注意力阶段（其作用是在两个视图之间传播上下文）可以被一种数据无关的Walsh-Hadamard令牌混合器所替代，该混合器在对数线性成本下在变换域中全局混合令牌，同时保留执行左右对应关系的数据相关的交叉注意力。在合成驾驶数据上，该混合器在端点误差方面与注意力基线相当，同时将模型计算量减少了2.46倍，单图像推理延迟减少了2.65倍。复杂度分析表明，其收益由序列长度与通道宽度的比率决定，这解释了为什么高分辨率立体匹配是一个特别有利的设置，而分类Transformer则不是；我们在非立体的长序列基准上确认了这种令牌到通道的扩展性。此外，我们引入了一种混合对数视差损失函数，旨在对对应远距离物体的小视差像素赋予更高权重。该方法在不增加任何额外计算开销的情况下，减少了远处物体的误差。

## Abstract
Stereo depth estimation for driving, robotics and augmented reality must run at high resolution under tight latency budgets, yet in transformer-based matchers the global self-attention that aggregates scene context grows quadratically with the number of pixels and comes to dominate runtime. We show that the joint self-attention stage of a stereo transformer, whose role is to spread context across both views, can be replaced by a data-independent Walsh-Hadamard token mixer that mixes tokens globally in the transform domain at log-linear cost, while the data-dependent cross-attention that performs left-right correspondence is retained. On synthetic driving data the mixer matches the attention baseline in end-point error while reducing model compute by a factor of 2.46 and single-image inference latency by a factor of 2.65. A complexity analysis shows the benefit is governed by the ratio of sequence length to channel width, which explains why high-resolution stereo matching is a particularly favorable setting and why classification transformers are not; we confirm this token-to-channel scaling on non-stereo long-sequence benchmarks. Furthermore, we introduce a hybrid log-disparity loss function designed to up-weight small-disparity pixels corresponding to long-range objects. This approach reduces the error on distant objects without incurring any additional computational overhead.

## 论文总结：WHTMix: Efficient Stereo Depth Estimation via Walsh-Hadamard Token Mixing

### 1. 论文的核心问题与整体含义

- **背景与动机**：立体深度估计（stereo depth estimation）是自动驾驶、机器人和增强现实等应用中的核心技术，需要在高分辨率下以低延迟运行。基于Transformer的立体匹配方法（如STTR）通过注意力机制替代固定视差搜索，取得了较高的精度。
- **核心问题**：Transformer中的全局自注意力（global self-attention）计算复杂度为O(N²)，随像素数量呈二次增长，在高分辨率场景下成为推理延迟的主要瓶颈，难以满足实时应用需求。
- **核心洞察**：在立体Transformer中，注意力承担两个不同的角色：
  - **联合自注意力（joint self-attention）**：在两个视图内和视图间传播全局上下文，本质上只做上下文聚合，不一定需要内容自适应。
  - **交叉注意力（cross-attention）**：执行左右视图的逐像素对应匹配，必须依赖内容比较。
- **论文主张**：上下文聚合可以由**数据无关（data-independent）的固定算子**完成，而匹配仍保留内容相关的交叉注意力。据此提出将联合自注意力替换为Walsh-Hadamard变换（WHT）域中的高效令牌混合器，从而将全局上下文传播的计算成本从二次降为对数线性。

### 2. 论文提出的方法论

**核心思想**：以Walsh-Hadamard变换为基础的轻量令牌混合器（WHTMix）替代Transformer中的联合自注意力模块，只需按相同接口替换即可，无需修改网络其他部分。

**WHTMix模块结构**（以公式形式描述）：

设输入令牌序列为 X ∈ R^(N×C)，其中N为令牌数、C为通道宽度，WHTMix的计算流程为：

1. 输入投影：Z = X·W_in
2. 通道维度WHT：对Z沿通道轴做Walsh-Hadamard变换，乘以可学习的逐频增益g_c（频域滤波），再逆变换回原域：Z ← H_C⁻¹(g_c ⊙ H_C(Z))
3. 令牌维度WHT：对Z沿令牌轴做Walsh-Hadamard变换，乘以可学习的逐频增益g_t，再逆变换：Z ← H_N⁻¹(g_t ⊙ H_N(Z))
4. 输出投影：Y = Z·W_out

**关键技术细节**：

- 使用**正交归一化的Sylvester-Hadamard矩阵**，变换本身**无需乘法**，由蝴蝶算法在O(N log N)内完成。
- 令牌轴在变换前**零填充到2的幂**以适配WHT。
- 可学习增益g_c、g_t初始化为零（即初始为单位增益），保证训练稳定性。
- WHT为正交变换，**保持幅值**，因此多层堆叠稳定；模块是线性的，非线性由后续的FFN提供。
- WHTMix与注意力模块的调用签名相同，是**即插即用**的替代模块。

**混合对数视差损失（Hybrid Log-Disparity Loss）**：

- 标准掩码L1损失被大视差（近处物体）主导，导致小视差（远处物体）监督不足。
- 对每个有效像素p赋予权重：w_p = clip(τ/d_p, 1, w_max)，其中d_p为真值视差。
- 实验中设τ=16像素、w_max=32，即对视差小于16px的远处像素最多放大32倍权重。
- 最终损失为加权掩码L1损失，不增加任何推理计算开销。

**复杂度分析**：

- 自注意力模块MACs：4NC²（投影）+ 2N²C（二次核心）
- WHTMix模块MACs：约2NC²（两个投影；WHT蝶形运算仅加法，不产生MAC）
- 模块级加速比：**S_mod = 2 + N/C**，交叉点位于N = 2C
- 端到端加速上限：**S_e2e = (16C + 3N) / (14C + N) → 3**（当N→∞时），因为保留的交叉注意力和FFN在两种模型中共享。

1. **在合成数据上，WHTMix在精度上匹配注意力基线**：CARLA EPE为2.27 vs 2.29（在运行噪声范围内），同时**计算量减少2.46倍、延迟降低2.65倍**。

4. **N/C比率决定收益**：高分辨率、低通道宽度的立体匹配（N/C=256）是该方法的理想场景；而分类Transformer（N/C≈0.26）不在受益区间。
5. **LRA跨任务验证**：在长文本任务（N/C=64）上WHTMix几乎匹配注意力精度（0.617 vs 0.632）且计算减13.8倍；在短图像任务（N/C=16）上加速4.3倍但精度差距较大（0.314 vs 0.383），进一步确认N/C是决定性因素而非任务类型。
