## 摘要
移动图像去噪既需要良好的恢复质量，也需要较低的计算成本。此外，收集大规模的低质量-真实（LQ-GT）干净图像对也很繁琐。因此，我们提出了LiteKD-Net，一种用于移动图像去噪的轻量级知识蒸馏网络。首先，通过物理引导的噪声模拟流程生成成对训练数据，与相机中应用的流程相比，增加了像素串扰。其次，我们将Real-ESRGAN适配到恒分辨率去噪任务，并使用基于深度可分离卷积的Lite-RRDB块构建轻量级学生网络。第三，应用特征级知识蒸馏将教师网络的恢复能力迁移到学生网络，且不引入额外的推理成本。在真实世界数据集上的实验表明，我们的模型在保持良好恢复质量的同时，大幅减少了运行时间并提高了推理速度。与SwinIR相比，我们的模型在所有指标上也达到了最优。这些结果表明，LiteKD-Net在恢复质量与计算效率之间提供了良好的权衡。

## Abstract
Mobile image denoising requires both good restoration quality and low computational cost. In addition, it's annoying to collect large-scale LQ-GT clean pairs. As a result, we propose LiteKD-Net, a lightweight knowledge-distilled network for mobile image denoising. First, a physics-guided noise simulation pipeline generates paired training data by adding pixel crosstalk compared with pipelines applied to cameras. Next, we adapt the Real-ESRGAN to identity-resolution denoising and construct a lightweight Student using Lite-RRDB blocks based on depthwise separable convolutions. Third, feature-level knowledge distillation is applied to transfer the Teacher's restoration capability to the Student without introducing additional inference cost. Experiments on real-world datasets show that our model reaches great reduction in runtime and increase in the inference rate with good restoration quality. Our model also reaches the best in all metrics compared with SwinIR. These results indicate that LiteKD-Net provides a great trade-off between restoration quality and computational efficiency.

### 一、核心问题与整体含义（研究动机与背景）

- **核心问题**：移动设备图像去噪面临三方面挑战：
  1. **质量与效率矛盾**：高性能去噪网络（如RRDB、Transformer类模型）动辄数千万参数、数十亿浮点运算量，在移动端部署时存在高延迟、高能耗和内存占用过大等问题。
  2. **真实噪声数据难以获取**：由于场景运动、光照变化和相机内处理管线不同，采集严格对齐的真实噪声-干净图像对（LQ-GT pairs）非常困难。而纯合成高斯噪声无法真实刻画CMOS传感器中的信号相关性和结构化噪声。
  3. **移动端专用方案不足**：大多数去噪研究面向专业相机，针对手机成像的噪声仿真管线研究较少。
- **整体含义**：论文提出一个统一框架 LiteKD-Net，旨在同时解决上述问题——通过物理引导的噪声仿真生成训练数据，通过轻量化架构降低计算成本，再通过知识蒸馏恢复轻量模型因压缩导致的质量损失，最终实现在移动端部署时兼顾恢复质量与推理效率。

### 二、方法论：核心思想、关键技术细节与公式

#### 2.1 整体技术路线（三个核心组件）

论文提出三阶段Pipeline：

1. **NSP（Noise Simulation Pipeline，噪声仿真管线）**：生成完美对齐的训练对。
2. **Lite-RRDB**：基于深度可分离卷积构建轻量学生网络，大幅减少参数量和计算量。
3. **Noise-KD（特征级知识蒸馏）**：将冻结的 Heavy Teacher（高容量网络）的恢复能力迁移至轻量 Student，且不增加任何推理成本。

#### 2.2 噪声仿真管线（NSP）关键细节

- **基础框架**：改编自 Wei et al. [2] 的物理RAW噪声模型，在近似线性RGB域中依次模拟：
  - **光子散粒噪声**（Poisson分布，信号相关）
  - **Tukey–Lambda重尾读出噪声**
  - **行噪声**（每行一个高斯偏移）
  - **量化噪声**（均匀分布，B=14位）
- **主要创新**：显式建模 **像素串扰（Pixel Crosstalk）**，即相邻像素间的信号泄漏，使噪声从空间独立变为局部相关。
  - 串扰核为 3×3 核（默认 ρ=0.03，中心权重 0.85，邻域合计 15%）：

  ```
  κc = [[ρ/4, ρ, ρ/4],
        [ρ, 1-5ρ, ρ],
        [ρ/4, ρ, ρ/4]]
  ```

  - 核权重和为1，保持局部亮度，通过 **分组卷积** 作用于各通道，不混合 RGB 通道。
- **完整公式**：

  ```
  x̂s = Γ⁻¹( clip( Cρ(K·Poisson(Γ(ys)/K) + n_read + n_row) + n_q, 0, 1 ) )
  ```

  其中 Γ 为 gamma 展开（γ=2.2），Cρ 为通道级串扰卷积。

#### 2.3 Lite-RRDB 架构细节

- **Teacher 构建**：将 Real-ESRGAN [4] 从超分任务改为恒分辨率去噪，移除所有上采样模块，骨干保留 23 个 RRDB（每个 RRDB 含 3 个 RDB）。
- **Lite-RRDB 改进**（相比原始 RDB）：
  - **移除密集拼接**：原始 RDB 中 5 层标准 3×3 卷积通过密集连接逐层拼接；Lite-RDB 中改为 5 个顺序执行的 DSConv 层，特征宽度固定为 64 通道。
  - **深度可分离卷积替换标准卷积**：

  ```
  DSConv(z) = PWConv_1×1(DWConv_3×3(z))
  ```

  - 参数量对比（k 为核尺寸）：标准卷积 P_std = k²·C_in·C_out；深度可分离 P_DS = k²·C_in + C_in·C_out，大幅降低。
  - **保留残差结构**：Lite-RDB 内保留局部残差连接（缩放因子 0.2），Lite-RRDB 保留残差中的残差（residual-in-residual）外层连接。

#### 2.4 Noise-KD 特征蒸馏

- **蒸馏方式**：将同一张噪声图像分别输入冻结的 Teacher 和可训练的 Student，对两者 **主干卷积（body convolution）产生的特征图** 计算均方差损失：

  ```
  L_KD = (1/C·H·W) · || F_S(x) − F_T(x) ||²
  ```

- **总损失**：

  ```
  L_total = L_rec + λ_per·L_per + λ_KD·L_KD
  ```

  其中 L_rec 为像素 L1 损失，L_per 为 LPIPS 感知损失。Teacher 仅训练时存在，推理时丢弃。

### 六、主要结论与发现

- **效率优势显著**：相比基线 Teacher（Real-ESRGAN）：
  - 参数量减少 **约 10 倍**（16.70M → 1.67M）
  - MACs 和 FLOPs 减少 **约 4 倍**（1.17T → 108.28G；2.35T → 216.55G）
  - 推理速度提升 **约 2 倍**（148.70ms → 83.47ms；FPS 6.72 → 11.98）
- **质量保持良好**：PSNR 38.14 → 37.91（仅降 0.23dB），SSIM、LPIPS、DISTS 等指标与基线非常接近。
- **优于 SwinIR**：所有图像质量指标（PSNR、SSIM、LPIPS、DISTS、MUSIQ）均全面超过 SwinIR，同时参数量远小于 SwinIR（1.67M vs 11.46M），推理速度快约 5 倍（83.47ms vs 410.70ms）。
- **消融结论**：Lite-RRDB 大幅提升效率但小幅降低质量；Noise-KD 能有效恢复质量（PSNR 提升 0.67dB；LPIPS 从 0.1257 降至 0.0987），几乎追平基线且推理时零额外开销。
- **整体价值**：LiteKD-Net 在恢复质量与计算效率之间取得了出色的平衡，适合移动端部署。

### 七、优点与亮点

1. **问题定位准确**：同时应对移动端去噪的两个真实痛点（效率、数据），而不是仅关注单一维度。
2. **物理引导的噪声仿真（NSP）**：在 sRGB 域引入像素串扰建模是对现有 RAW 噪声模型的有效补充，使合成噪声更接近真实手机传感器的空间相关特性；可视化验证（图2）清晰证明串扰核确实引入空间相关性而非独立噪声。
3. **知识蒸馏设计高效**：在特征级进行蒸馏，充分利用 Teacher 中丰富的中间表示，且推理时完全丢弃 Teacher，不产生任何额外开销；蒸馏收益在消融中非常明显（LPIPS 大幅改善）。
4. **架构设计合理**：Lite-RRDB 在去除密集连接时保留了两层残差结构，避免过度简化导致退化；深度可分离卷积参数量优势通过公式给出清晰论证。
5. **效率评估全面**：同时报告参数量、MACs、FLOPs、运行时、FPS 和峰值内存，覆盖部署所需的关键指标。

### 八、不足与局限

1. **噪声仿真的硬件近似性**：
   - NSP 在近似线性化 sRGB 而非真实 RAW 域工作，未建模去马赛克、白平衡、色彩校正、色调映射、相机特定非线性处理等完整成像流程。论文在 Limitations 中已明确承认。
   - 噪声参数（K、σ_TL、σ_r 等）为人工固定的经验值，未按特定手机传感器进行校准（对比 Wei et al. [2] 的逐相机标定方法），泛化到不同手机品牌/型号的能力存疑。
2. **实验覆盖范围有限**：
   - 训练集仅 2400 张合成对，规模偏小。
   - 对比基线仅两个，未与更多轻量级方法或 SOTA 去噪模型比较。
   - 无大规模真实数据集（如 SIDD 全量）上的严格评测。
   - 测试集图像数量与场景构成未明确报告。
3. **指标结果的偏差风险**：
   - CLIP-IQA 指标在消融中出现反直觉现象（Lite-RRDB 为 0.3590，加入 KD 后仅 0.3607，增益极小，远小于其他指标提升），说明蒸馏对某些感知指标改善有限或存在该指标不敏感的情况。
   - 所有结果报告的是单次运行值，未提供方差或多轮验证。
4. **计算环境限制**：仅用单张 RTX 3090 训练，没有报告真实移动端硬件（如 Qualcomm/Apple 芯片）上的实测延迟，使用 GPU 测得的运行时仅供参考。
5. **应用边界**：论文处理的是恒分辨率去噪（无超分），对超分与去噪联合任务不适用；串扰核为对称静态核，可能不适用于所有传感器类型。
