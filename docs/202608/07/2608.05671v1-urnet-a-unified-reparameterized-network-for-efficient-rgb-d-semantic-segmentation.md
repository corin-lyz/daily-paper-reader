## 摘要
以往的RGB-D语义分割方法通常采用双编码器分别处理RGB和深度输入，并随后使用专门的模块进行跨模态特征融合。然而，这类设计往往无法充分捕获深度表示，从而限制了有效的跨模态交互，同时额外的编码器分支引入了冗余计算，阻碍了轻量化执行。为应对这些挑战，我们提出了URNet，一种统一的重参数化RGB-D网络，在单一编码器内同时进行多模态特征提取和跨模态融合。具体而言，我们采用重参数化策略来压缩网络架构并促进快速推理。在每个重参数化块（RepBlock）中，引入了线性门控注意力（LGA）模块，以充分利用不同特征尺度下的互补RGB和深度线索。此外，考虑到现有RGB-D分割模型中对解码器设计的探索相对不足，我们开发了一个简洁而有效的通用解码器，称为金字塔合并解码器（PMD）。在多个RGB-D分割基准上的大量实验表明，URNet在保持高效率的同时实现了最先进的性能。代码将在https://github.com/Wild-Stephen/URNet上提供。

## Abstract
Previous RGB-D semantic segmentation methods commonly employ dual encoders to separately process RGB and depth inputs, followed by dedicated modules for cross-modal feature fusion. However, such designs often inadequately capture depth representations and consequently limit effective cross-modal interaction, while the additional encoder branch introduces redundant computation that hinders lightweight execution. To tackle these challenges, we propose URNet, a Unified Reparameterized RGB-D Network that performs simultaneous multi-modal feature extraction and cross-modal fusion within a single encoder. Specifically, we adopt a reparameterization strategy to compact the network architecture and facilitate fast inference. Within each Reparameterized Block (RepBlock), a Linear Gated Attention (LGA) module is introduced to fully exploit complementary RGB and depth cues across different feature scales. Furthermore, considering that decoder design has been relatively underexplored in existing RGB-D segmentation models, we develop a concise yet effective universal decoder, termed the Pyramid Merging Decoder (PMD). Extensive experiments on multiple RGB-D segmentation benchmarks demonstrate that URNet achieves state-of-the-art performance while maintaining high efficiency. Code will be available at https://github.com/Wild-Stephen/URNet.

## 1. 核心问题与研究动机

- **现有方法的缺陷**：主流RGB-D语义分割方法普遍采用**双编码器架构**（一个处理RGB、一个处理深度），存在三大突出问题：
  - **深度特征建模不足**：深度分支通常由RGB预训练模型初始化，导致对深度几何信息的表征能力较弱；
  - **跨模态交互不充分**：融合模块往往只被部署在少数几个编码器阶段，限制了RGB与深度之间的信息互补；
  - **计算冗余**：额外的深度编码器分支带来了大量重复计算，阻碍了轻量化部署。
- **核心目标**：设计一种既能高效融合RGB与深度信息、又能满足实时/资源受限场景需求的统一轻量级网络架构。

## 2. 方法论：URNet的核心思想与技术细节

### 2.1 总体架构

- URNet采用**编码器-解码器**结构，遵循**两阶段训练范式**：
  - **阶段一**：在RGB-D ImageNet-1K（配对RGB图像+深度图像）上进行大规模预训练；
  - **阶段二**：在RGB-D语义分割基准（NYUDepth V2、SUN-RGBD）上进行微调。
- 编码器采用**统一RGB-D编码器**：不同于双编码器设计，URNet在单一编码器内同时完成多模态特征提取与跨模态融合。

### 2.2 层次化编码器与RepBlock

- 编码器分为四个层级（L1~L4），各层级由堆叠的**重参数化块（RepBlock）**组成；
- **RepBlock的Token Mixer设计**：采用并行的多分支结构，包含：
  - 3×3 深度可分离卷积；
  - 1×1 深度可分离卷积；
  - 分解的 1×7 + 7×1 深度可分离卷积；
  - 加上残差连接。
- 该设计相比RepViT额外引入了7×7的感受野，能够聚合更丰富的空间信息；借助重参数化技术，训练时的跳连和复杂分支可在推理时合并压缩，消除额外开销，提升推理速度。

### 2.3 线性门控注意力（LGA）模块

- LGA位于RepBlock中间，用于高效实现RGB与深度特征的跨模态融合，流程如下：
  1. 分别对RGB特征 $x_i^{rgb}$ 和深度特征 $x_i^d$ 执行池化 + 3×3卷积，生成模态感知描述符；
  2. 经sigmoid激活生成门控信号：
     - $g_i^{rgb} = \sigma(Conv_{3\times3}(Pool(x_i^{rgb})))$
     - $g_i^d = \sigma(Conv_{3\times3}(Pool(x_i^d)))$
  3. 通过元素级乘法实现对另一模态的选择性调制：
     - $\hat{x}_i^{rgb} = x_i^{rgb} + g_i^d \odot x_i^{rgb}$
     - $\hat{x}_i^d = x_i^d + g_i^{rgb} \odot x_i^d$
  4. 各自经SE模块进行通道重标定后拼接，得到最终融合特征：
     - $m_i = Concat(SE(\hat{x}_i^{rgb}), SE(\hat{x}_i^d))$
- **优势**：LGA采用线性元素级操作而非二次复杂度的注意力机制，计算开销极低；对称的交叉门控设计使双模态能够相互引导，且在每个编码器块内均进行融合，实现了**全密集的跨模态交互**。

### 2.4 金字塔合并解码器（PMD）

- PMD是作者提出的轻量级通用解码器，用于多尺度特征聚合：
  - 对编码器输出的四个不同分辨率特征图（m1~m4）进行**自顶向下的金字塔式渐进合并**；
  - 通过下采样、上采样、元素级加和及池化操作逐级融合；
  - 最后引入**金字塔池化（P-Pooling）**模块捕获多感受野上下文信息，并与聚合特征做残差融合。
- 公式化描述：
  - $t_k = m_k^c + Ds(t_{k-1})$（下采样融合），$g_k = Us(t_k)$（上采样传播）；
  - $s_k = Pool(s_{k-1} + g_k)$（逐级池化合并）；
  - $y = m_f + PPool(m_f)$（残差金字塔池化输出）。
- **优势**：仅由上采样、池化和加和等简单操作构成，参数开销极小，却显著提升了分割精度。
