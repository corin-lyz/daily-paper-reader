## 摘要
深度学习系统主要针对单图像领域在2D空间内运行，并将面部作为单一维度表示，从而忽略了绵羊的3D解剖结构以及跨地标空间关系，而这些关系是临床上已证实的绵羊疼痛面部表情量表（SPFES）所固有的。本文提出了3D绵羊疼痛面部表情系统（3D-SPFES），这是一种新颖的、基于单目深度感知的几何图神经网络系统，通过使用VideoDepthAnything从单个RGB相机估计的3D欧几里得空间，整合每个SPFES面部地标（如耳朵、眼睛和鼻子），从而无需专门的深度硬件。每个地标节点包含一个特征向量，其中包括其3D空间坐标、估计的表面法线和面部属性类别嵌入。与节点相连的边根据综合欧几里得距离和3D空间表面共面性的聚合指标来分配权重。加权几何图神经网络（WG-GNN）通过$\mathcal{K} = 3$层几何感知消息传递层研究该图，并通过缩放点积注意力方法增强，选择性地强化解剖学相关的跨地标消息。所得的节点嵌入被组合成$\mathcal{O} = 3$个疼痛级别簇，并集成到归一化疼痛评分（NPS）中，范围在$[0, 100%]$之间，这是一种置信度加权、源自SPFES的评分方法。

## Abstract
Deep learning systems perform mainly within the 2D for a single image domain and take the face as a single-dimension representation, losing sight of the 3D anatomy of sheep and cross-landmark spatial relationships that are intrinsic to the clinically proven Sheep Pain Facial Expression Scale (SPFES). This paper presents the \textbf{3D Sheep Pain Facial Expression System (3D-SPFES)}, a novel, monocular depth-aware geometric graph neural network system that integrates each SPFES facial landmark, such as the ears, eyes, and nose, into 3D Euclidean space estimated from a single RGB camera by using VideoDepthAnything, thus preventing the need for specialized depth hardware. Each landmark node includes a feature vector containing its 3D spatial coordinates, estimated surface normal, and facial attribute class embedding. Edges linked to nodes are assigned weights based on an aggregate metric that combines both Euclidean distance and surface co-planarity in a 3D space. A Weighted Geometric Graph Neural Network (WG-GNN) studies this graph using $\mathcal{K} = 3$ geometry-aware message-passing layers enhanced by a scaled dot-product attention method that selectively enhances anatomically relevant inter-landmark messages. The resultant node embeddings are combined into $\mathcal{O} = 3$ pain-level clusters and integrated into a Normalized Pain Score (NPS) within the range of $[0, 100%]$ a confidence-weighted, SPFES-derived scoring method.

- **背景**：在畜牧业中，定期监测动物健康、进行非侵入性疼痛评估至关重要。绵羊疼痛面部表情量表（SPFES）是经过临床验证的协议，通过评估耳朵位置、眼睛表情和鼻子形状三个双侧面部区域的九种面部表情来判断疼痛强度。
- **现有方法缺陷**：现有基于深度学习的自动评估方法存在两大根本局限：
  - **2D平面局限**：所有方法都在2D图像平面中运行，忽略绵羊面部的3D解剖结构，无法区分在投影中相似但空间朝向不同的面部结构。
  - **整体特征缺陷**：将面部视为单一输入，未利用不同面部关键点之间的空间与语义关联，不符合SPFES要求对单个关键点分别打分后综合评价的临床路径。
- **本论文目标**：提出3D-SPFES系统，通过单目深度估计将面部关键点嵌入3D欧几里得空间，构建加权几何图神经网络来实现符合临床SPFES标准的疼痛评估，且无需专用深度传感器硬件。

## 2. 方法论（核心思想、关键技术细节与算法流程）

### 核心思想

利用单目深度估计网络（VideoDepthAnything）从普通RGB图像获取深度信息，将SPFES面部关键点（耳朵、眼睛、鼻子等9个面部部位）提升到3D空间，构建图结构，并通过几何感知的消息传递与注意力机制学习节点间的疼痛相关性，最终输出疼痛聚类和标准化疼痛评分。

### 技术细节与算法流程

- **3D图构建**：定义图 $G = (N, E, O, X)$，其中 $N$ 为9个面部表情节点，$E$ 为有向边（编码空间与疼痛关系），$O$ 为疼痛簇输出标签，$X \in \mathbb{R}^{|N|\times 3}$ 为3D坐标矩阵。
- **单目深度估计与反投影**：利用VideoDepthAnything生成深度图，通过相机内参矩阵 $K$ 将2D像素坐标反投影到3D空间，公式为 $x_i = z_i \cdot K^{-1}[u_i, v_i, 1]^\top$，其中 $z_i$ 为深度值。
- **3D节点特征初始化**：每个节点的初始特征向量 $\psi_i^{(0)} = [p_i, \text{FPT}_i, x_i^\top, d_i^\top] \in \mathbb{R}^{1+C+6}$，包含：疼痛强度 $p_i \in \{0,1,2\}$、面部部位类别的one-hot编码、3D空间坐标、单位表面法线向量。
- **3D边构建与几何加权**：两个节点之间形成边需同时满足两个条件：① 欧氏距离阈值 $\delta_{nw} \le \tau$（空间邻近性）；② 疼痛等级相似性 $|p_n - p_w| \le \epsilon$。边的权重为：
  $$\omega_{nw} = \underbrace{\exp\left(-\frac{\delta_{nw}^2}{2\sigma^2}\right)}_{\text{空间邻近项}} \cdot \underbrace{\frac{d_n^\top d_w + 1}{2}}_{\text{法线共面项}}$$
  同时衡量3D空间邻近性与表面共面性，有效防止跨越解剖边界的错误连接。
- **几何消息传递与注意力机制**：经过 $K=3$ 层消息传递，每层计算几何感知消息 $m_{ij}^{(k)} = \omega_{ij} \cdot \phi_m(\psi_i^{(k-1)}, \psi_j^{(k-1)}, \delta_{ij}, d_i^\top d_j)$，其中 $\phi_m$ 为MLP边缘网络；通过缩放点积注意力计算注意力系数 $\alpha_{ij}^{(k)} = \text{softmax}_j\left(\frac{(W_q \psi_i)^\top (W_k \psi_j)}{\sqrt{d_h}}\right)$，最后聚合消息并更新节点特征。
- **损失函数设计**：联合损失 $L = L_{\text{CE}} + \lambda L_{\text{geo}}$，其中 $L_{\text{CE}}$ 为聚类分类交叉熵，$L_{\text{geo}}$ 为几何正则化项（使高权重边连接的节点在嵌入空间中相似）。
- **标准化疼痛评分（NPS）**：将节点嵌入聚为 $\mathcal{O}=3$ 个疼痛簇，每簇计算加权疼痛得分 $S_j$（考虑SPFES影响权重和深度置信权重），最终归一化到 $[0, 100\%]$ 区间。
- **双侧检测平均（Bilateral Detection Averaging）**：将左右对称的面部特征（左/右耳、左/右眼）合并为SPFES一致的单一代表性节点，取双侧疼痛最高分。

## 6. 主要结论与发现

- **全局模型性能显著更优**：5局部到全局的模型集成方法在测试集上达到78.33%的准确率，Cohen's κ从0.180提升至0.473（相对提升163%），MCC达0.486，且无需额外训练。
