## 摘要
立体深度估计在驾驶、机器人和增强现实中必须在严格的延迟预算下以高分辨率运行，然而在基于变换器的匹配器中，聚合场景上下文的全局自注意力随像素数量呈二次增长，并主导运行时间。我们表明，立体变换器中的联合自注意力阶段（其作用是在两个视图之间传播上下文）可以被一个数据无关的Walsh-Hadamard令牌混合器替代，该混合器在变换域中以对数线性代价全局混合令牌，而执行左右对应性的数据相关交叉注意力则被保留。在合成驾驶数据上，该混合器在端点误差上与注意力基线匹配，同时将模型计算量减少2.46倍，单图像推理延迟减少2.65倍。复杂度分析表明，优势由序列长度与通道宽度的比率决定，这解释了为什么高分辨率立体匹配是一个特别有利的设置，而分类变换器则不是；我们在非立体长序列基准上证实了这种令牌到通道的缩放关系。此外，我们引入了一种混合对数视差损失函数，旨在增强对应于远处物体的小视差像素的权重。这种方法在不增加任何额外计算开销的情况下减少了远处物体的误差。

## Abstract
Stereo depth estimation for driving, robotics and augmented reality must run at high resolution under tight latency budgets, yet in transformer-based matchers the global self-attention that aggregates scene context grows quadratically with the number of pixels and comes to dominate runtime. We show that the joint self-attention stage of a stereo transformer, whose role is to spread context across both views, can be replaced by a data-independent Walsh-Hadamard token mixer that mixes tokens globally in the transform domain at log-linear cost, while the data-dependent cross-attention that performs left-right correspondence is retained. On synthetic driving data the mixer matches the attention baseline in end-point error while reducing model compute by a factor of 2.46 and single-image inference latency by a factor of 2.65. A complexity analysis shows the benefit is governed by the ratio of sequence length to channel width, which explains why high-resolution stereo matching is a particularly favorable setting and why classification transformers are not; we confirm this token-to-channel scaling on non-stereo long-sequence benchmarks. Furthermore, we introduce a hybrid log-disparity loss function designed to up-weight small-disparity pixels corresponding to long-range objects. This approach reduces the error on distant objects without incurring any additional computational overhead.

## 2. 方法论：核心思想、关键技术细节与算法流程
- **核心思想**：立体Transformer中注意力扮演两个角色：联合自注意力（左右视图间上下文传播）和交叉注意力（左右对应匹配）。只有后者需要数据依赖；前者可用固定算子替代。本文使用Walsh-Hadamard变换（WHT）实现数据无关的全局令牌混合，计算复杂度为O(N log N)。
- **WHTMix模块（替代联合自注意力）**：
  1. 输入X ∈ R^(N×C)经过线性投影W_in → Z。
  2. 对通道轴应用WHT（1D），乘以可学习的对数域每频增益g_c，再逆变换。
  3. 对令牌轴应用WHT（需填充到2的幂），乘以可学习增益g_t，再逆变换。
  4. 再经线性投影W_out输出Y。
  5. 整个模块是线性的，非线性由后续FFN提供；WHT正交归一化，保持信号幅度，层堆叠稳定。
- **混合对数视差损失**：对每个有效像素p，赋予权重w_p = clip(τ/d_p, 1, w_max)，其中d_p为真值视差，τ=16, w_max=32。加权后的L1损失：`(1/∑w_p) ∑ w_p |d_p - ˆd_p|`。目的是增强小视差（远处物体）的监督。
- **复杂度分析**：
  - 自注意力块MACs: 4NC² (投影) + 2N²C (注意力核心)
  - WHTMix MACs: 约2NC² (两个投影，WHT无乘法)
  - 混合器加速比：S_mod = 2 + N/C，当N >> C时近似线性增长。
  - 端到端加速比上限：S_e2e → 3 (当N→∞)，因为保留的交叉注意力和FFN共享。

## 6. 论文的主要结论与发现
- **WHTMix在合成数据上匹配注意力精度**（EPE 2.27 vs 2.29，属于噪声水平），同时降低计算量2.46×、延迟2.65×。
- **混合对数视差损失显著降低远处物体误差**（0–2px bin: 0.64→0.56；2–4px: 2.96→1.60；4–8px: 3.04→1.94），且无额外计算开销。
- **加速比受N/C比率支配**：当N >> C时，如高分辨率立体匹配（N/C=256），加速明显；当N < C时（如分类ViT，N/C≈0.26），无收益。该结论在非立体LRA任务中得到验证（文本任务N/C=64，加速13.8×；图像任务N/C=16，加速4.3×）。
- **端到端加速存在上限~3×**，因保留的交叉注意力、FFN成为瓶颈。
- **在真实数据KITTI上精度下降**（EPE 2.204→2.670），表明数据无关的混合器在真实域中适应性弱于注意力，需更大规模真实数据预训练。

## 7. 优点
- **方法简洁高效**：WHTMix是“drop-in”替换，无需改变网络结构，直接替代自注意力模块，实现对数线性复杂度。
- **理论分析精准**：推导出闭环加速比公式S_mod = 2 + N/C，并预测了端到端上限，与实测高度吻合。
- **损失函数零开销**：混合对数损失仅改变训练时的权重，推理时不增加计算。
- **跨任务验证**：不仅在立体匹配任务，还在LRA两个非立体任务中验证了N/C比率决定加速效果，增强了结论泛化性。
- **实验设计细致**：同时报告了端到端和模块级延迟，分离出不同组件的贡献；分辨率扫描覆盖了从低到高的完整区间。

## 8. 不足与局限
- **对真实数据适应性差**：KITTI上精度显著下降（EPE +0.47px），可能由于真实数据量少、域差距大，而固定混合器缺乏自适应的场景上下文建模。
- **基线对比不够广泛**：仅与STTR风格的注意力基线对比，未与当前最先进的立体匹配方法（如RAFT-Stereo、IGEV-Stereo、FoundationStereo等）比较，也在LRA上仅对比注意力，未对比其他高效注意力机制（如Linformer、Performer等）。
- **实验统计不足**：所有结果均为单次运行（single-seed），缺乏多次运行的标准差，难以判断统计显著性。
- **WHT的2的幂限制**：序列长度需填充到2的幂，可能引入填充开销，但在立体匹配中常见分辨率可以近似满足。
- **资源细节缺失**：未报告训练总时长、GPU数量、模型收敛所需要的迭代次数，限制了可复现性。
- **损失函数设计可进一步分析**：未给出τ和w_max选择的依据，也未做敏感性分析。
- **适用范围有限**：方法优势仅当N >> C时成立，不适用于通道数很大的深层Transformer（如ViT-Large等）。同时仅替换了联合自注意力，交叉注意力仍为二次复杂度，限制了整体加速（上限3×）。
