## 摘要
视觉基础模型越来越多地被重用为下游视觉识别的冻结骨干网络，这使得参数高效的适配成为一个核心问题。基于提示的适配方法（包括视觉提示微调VPT）提供了一种轻量级的方式来专门化这些模型，但其逐层行为仍未被充分理解：性能对提示深度、位置和任务分布敏感，在标准域内基准上的提升并不总能转化为鲁棒的泛化能力。我们认为，这一限制不仅是优化问题，更是逐层信息分配问题：现有的基于提示的方法缺乏对提示条件化表示在深度方向上应保留、抑制和传播的内容的原则性控制。受信息瓶颈原则启发，我们提出了提示信息瓶颈（PIB）框架，该框架正则化逐层的压缩-充分性权衡，并促进更连贯的跨层信息路径。关键思想是有效的适配应当最小化但充分，在早期层保留任务相关的局部证据，同时在更深层逐步丢弃干扰因素和冗余细节。大量实验表明，PIB在34个数据集上取得了强劲性能，在FGVC上达到92.1%，在HTA上达到93.01%，在VTAB-1k上达到77.33%，同时在主要设置上平均仅微调0.35%的参数。除了基准准确率，PIB有助于解释提示容量缩放的非单调行为，减少捷径依赖，并在分布偏移和细粒度识别设置下提高鲁棒性。这些结果将PIB定位为适配冻结视觉基础模型的实用方法和信息分配视角。我们的代码可在 https://github.com/itsnotacie/MM-26-PIB 获取。

## Abstract
Vision foundation models are increasingly reused as frozen backbones for downstream visual recognition, making parameter-efficient adaptation a central problem. Prompt-based adaptation, including Visual Prompt Tuning (VPT), provides a lightweight way to specialize these models, but its layer-wise behavior remains poorly understood: performance is sensitive to prompt depth, placement, and task distribution, and gains on standard in-domain benchmarks do not always translate into robust generalization. We argue that this limitation is not solely an optimization issue, but a layer-wise information allocation issue: existing prompt-based methods lack principled control over what prompt-conditioned representations should preserve, suppress, and propagate across depth. Inspired by the Information Bottleneck principle, we introduce Prompted Information Bottlenecks (PIB), a framework that regularizes layer-wise compression-sufficiency trade-offs and promotes a more coherent cross-layer information path. The key idea is that effective adaptation should be minimal yet sufficient, retaining task-relevant local evidence in earlier layers while progressively discarding nuisance factors and redundant details in deeper layers. Extensive experiments show that PIB achieves strong performance across 34 datasets, reaching 92.1% on FGVC, 93.01% on HTA, and 77.33% on VTAB-1k, while tuning only 0.35% parameters on average across the main settings. Beyond benchmark accuracy, PIB helps explain the non-monotonic behavior of prompt capacity scaling, reduces shortcut reliance, and improves robustness under distribution shift and fine-grained recognition settings. These results position PIB as both a practical method and an information-allocation perspective for adapting frozen vision foundation models. Our code is available at https://github.com/itsnotacie/MM-26-PIB

## 1. 核心问题与整体含义（研究动机与背景）

- **对象**：视觉基础模型（VFM），特别是视觉变换器（ViT）的冻结骨干适配。
- **问题**：现有基于提示的适配方法（如 Visual Prompt Tuning, VPT）虽然轻量，但性能对提示深度、长度、插入位置非常敏感，且在标准域内基准上提升并不能保证跨分布泛化。论文指出，这一限制**不仅是优化问题，而是逐层信息分配（layer-wise information allocation）问题**：缺乏对提示条件化表示应保留、抑制和传播的内容的原则性控制。
- **整体含义**：有效的适配应遵循“最小但足够”（minimal-yet-sufficient）原则，早期层保留局部任务证据，深层逐步丢弃冗余和干扰因素。基于此，论文提出 **Prompted Information Bottleneck (PIB)** 框架，从信息瓶颈（IB）视角规范逐层压缩-充分性权衡，提升适配性能和鲁棒性。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 将提示微调视为**逐层信息分配过程**，受信息瓶颈（IB）原则启发：最小化表示与输入之间的互信息（压缩），同时最大化与标签的互信息（充分性）。
- 在冻结变换器的每一层，通过正则化实现“压缩-充分性”平衡，并引入**跨层最小-足够路径**约束。

### 关键技术细节

1. **压缩项（Compression）**：避免提示传播过多冗余或干扰信息。
   - 使用归一化隐藏表示的相关系数矩阵的**离对角Frobenius范数**作为代理：
     \[
     \mathcal{L}^{(l)}_{\text{comp}} = \|\mathbf{C}_l - \mathbf{I}_d\|^2_{F, \text{off}}
     \]
   - 鼓励维度间的低冗余。

2. **充分性项（Sufficiency）**：避免过度压缩丢失判别信息。
   - 基于类内/类间散布比：
     \[
     \mathcal{L}^{(l)}_{\text{suff}} = \frac{S^{(l)}_{\text{intra}}}{S^{(l)}_{\text{inter}} + \epsilon}
     \]
   - 类内越紧凑、类间越分离，损失越小。

3. **跨层路径正则化（Path Regularization）**：
   - 定义层质量分数 \( q_l = \mathcal{L}^{(l)}_{\text{comp}} + \alpha_l \mathcal{L}^{(l)}_{\text{suff}} \)。
   - 正则化相邻层质量分数的变化：
     \[
     \mathcal{L}_{\text{path}} = \sum_{l=1}^{L-1} \max(0, q_{l+1} - q_l - \delta_l)
     \]
   - 促进平稳过渡，防止突然恶化。

4. **可选层感知路由（Layer-aware Routing）**：
   - 学习门控 \( r_l \in [0,1] \)，自适应调整每层压缩与充分性的权重：
     \[
     \mathcal{L}^{\text{route}}_{\text{PIB}} = \sum_l \left[ r_l \lambda_l \mathcal{L}^{(l)}_{\text{comp}} + (1 - r_l) \gamma_l \mathcal{L}^{(l)}_{\text{suff}} \right]
     \]

5. **最终目标函数**：
   \[
   \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{task}} + \mathcal{L}_{\text{PIB}} + \eta \mathcal{L}_{\text{path}}
   \]
   - 仅优化提示参数、分类头和路由变量，冻结骨干。

- PIB在34个数据集上，以平均仅0.35%可调参数（ViT-B/16设置下）取得强性能：

- **产生了更有序的逐层信息分配**：PIB的跨层信息轨迹更连贯、冗余抑制更稳定、类可分离性更强、路径分数更平滑。

## 7. 优点

- **理论视角新颖**：将信息瓶颈原则引入提示适配，将问题从“如何设计更好提示”转移到“如何规范信息流分配”。
- **方法轻量有效**：仅添加少量训练计算（约10%额外FLOPs），推理无额外开销；仅调优0.35%参数达到SOTA。
