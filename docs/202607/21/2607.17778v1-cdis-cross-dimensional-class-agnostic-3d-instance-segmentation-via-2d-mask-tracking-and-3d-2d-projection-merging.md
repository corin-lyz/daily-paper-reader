## 摘要
类别无关的3D实例分割对于在未知环境中运行的机器人系统至关重要，使其能够感知之前未见过的物体，以实现可靠的操控和导航。现有方法通常将每帧的2D实例掩码投影到3D并合并，但这往往会破坏物体在时间上的身份一致性，导致3D实例碎片化。我们提出了跨维类别无关3D实例分割（CDIS），一个零样本框架，它显式地跨帧跟踪2D实例掩码，并将其与3D超点关联，建立2D和3D之间的反馈循环。这种跨维推理将时间稳定的2D轨迹与空间连贯的3D区域连接起来，无需任何3D特定训练即可生成全局一致的3D实例标签。在基准数据集上的实验表明，CDIS相比最先进的零样本方法实现了更高的准确性和一致性，同时保持高效且可扩展到多样化的真实世界环境。

## Abstract
Class-agnostic 3D instance segmentation is critical for robotic systems operating in unknown environments, enabling perception of previously unseen objects for reliable manipulation and navigation. Existing approaches typically project per-frame 2D instance masks into 3D and merge them, which often breaks object identities across time and yields fragmented 3D instances. We introduce Cross-Dimensional Class-Agnostic 3D Instance Segmentation (CDIS), a zero-shot framework that explicitly tracks 2D instance masks across frames and associates them with 3D superpoints, creating a feedback loop between 2D and 3D. This cross-dimensional reasoning links temporally stable 2D tracks with spatially coherent 3D regions, producing globally consistent 3D instance labels without any 3D-specific training. Experiments on benchmark datasets demonstrate that CDIS achieves higher accuracy and consistency than state-of-the-art zero-shot methods, while remaining efficient and scalable to diverse real-world environments.

## 1. 核心问题与整体含义（研究动机和背景）

- 类别无关的3D实例分割对机器人在未知环境中的感知至关重要，但现有方法多依赖标注3D数据集，泛化性差。
- 近年主流思路是将2D实例分割模型（如SAM）的掩码通过深度图投影到3D空间并合并，但这些投影-合并方法存在两大缺陷：

- 现有方法缺乏跨帧的显式掩码跟踪，无法充分利用时序信息。
- 论文提出CDIS（Cross-Dimensional Class-Agnostic 3D Instance Segmentation），通过2D掩码跟踪与3D超点反馈循环，实现零样本、无需3D训练的全局一致3D实例分割。

## 2. 提出的方法论

### 核心思想
- **跨维度推理（Cross-Dimensional Reasoning）**：建立2D与3D之间的双向反馈循环，利用2D跟踪的时序稳定性纠正短时分割错误，同时利用3D超点的几何结构解决空间歧义并防止长期漂移。

### 关键技术细节（三阶段流程）

#### 阶段1: 2D实例跟踪（2D Instance Tracking）
- 对每帧RGB-D输入，使用2D分割模型（SAM/CropFormer）生成实例掩码。
- 利用深度图将当前帧掩码投影为3D点云，并存储最近`q_max=5`帧的队列。
- **帧变形（Frame Warping）**：通过相机相对变换将历史帧3D点投影到当前帧2D空间，得到变形掩码。
- **掩码匹配（Mask Matching）**：对当前帧掩码与变形掩码逐实例计算IoU，若IoU>τ_IoU2D=0.8则赋予相同ID，否则创建新ID。通过引用多帧（如t-2）防止单帧错误传播。

#### 阶段2: 3D引导的2D实例合并（3D-Guided 2D Instance Merging）
- 使用Felzenszwalb算法[26]预先计算整个场景的3D超点。
- 将每个超点投影到所有帧，得到2D足迹，并关联到最大重叠的2D实例标签（公式5）。
- 基于超点分配集合，计算相邻帧实例间的3D IoU（公式6），若>τ_IoU3D=0.6则合并，迭代至得到全局一致的2D实例ID。

#### 阶段3: 3D实例整合（3D Instance Consolidation）
- **重叠检测**：对实例对(u,v)计算3D IoMin（交集面积/较小实例面积），若>τ_IoMin3D=0.8则进一步分析。
- **时间共现分析**：计算实例对共现帧数比率CO，若>τ_co=0.5则认为两者为不同物体（重叠由噪声引起），从较大实例中移除重叠超点；否则视为同一物体并合并。
- **迭代精化**：重复上述过程直至无超过阈值对。
- **最终赋值**：投票机制为每个超点分配出现频率最高的实例ID。

**整体流程无需任何3D训练，仅依赖2D预训练模型和几何规则。**
