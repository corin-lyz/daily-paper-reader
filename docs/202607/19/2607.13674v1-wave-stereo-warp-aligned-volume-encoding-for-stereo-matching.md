## 摘要
现有的迭代立体匹配方法主要采用两种对应表示方式：通过相关体积进行显式匹配搜索和通过扭曲特征进行局部残差细化，但这两种方式仍然分别建模。我们提出WAVE-Stereo，基于一个核心洞察：相关体积和特征扭曲提供了互补的匹配线索。\textbf{GeoWarp对应编码器（GWCE）}在ConvGRU输入处并行编码匹配搜索、残差对齐和视差先验。为了减轻无纹理区域的匹配退化，我们提出\textbf{周期全局上下文传播（PGCP）}，它以周期性方式传播全局空间信息。在五个真实世界基准——Middlebury、ETH3D、KITTI 2012、KITTI 2015和Booster上，WAVE-Stereo在没有任何外部基础模型先验的情况下取得了有竞争力的零样本泛化精度，在KITTI 2015上达到3.18% D1-all，在Booster上达到4.42% Bad-2.0，并且实时推理时间为66ms，在精度和效率之间取得了良好的平衡。我们的代码可在https://github.com/yamanoko-do/WAVE-Stereo获取。

## Abstract
Existing iterative stereo matching methods primarily adopt two types of correspondence representation: explicit matching search via correlation volumes and local residual refinement via warped features, yet the two remain separately modeled. We propose WAVE-Stereo, built on a core insight: correlation volumes and feature warping provide complementary matching cues. \textbf{GeoWarp Correspondence Encoder (GWCE)} encodes matching search, residual alignment, and disparity prior in parallel at the ConvGRU input. To mitigate matching degradation in textureless regions, we propose \textbf{Periodic Global Context Propagation (PGCP)}, which propagates global spatial information in a periodic manner. On five real-world benchmarks -- Middlebury, ETH3D, KITTI 2012, KITTI 2015, and Booster -- WAVE-Stereo achieves competitive zero-shot generalization accuracy without any external foundation model prior, achieving 3.18\% D1-all on KITTI 2015, 4.42\% Bad-2.0 on Booster, and 66ms real-time inference, striking a favorable balance between accuracy and efficiency. Our code is available at https://github.com/yamanoko-do/WAVE-Stereo.

# WAVE-Stereo 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

立体匹配的核心挑战在于无纹理区域、重复结构、镜面高光、透明表面及遮挡区域的匹配歧义。当前主流的迭代立体匹配方法存在两种范式：

- **显式匹配搜索**：通过预计算的相关体积（correlation volume）检索局部匹配代价，保留候选视差间的歧义信息（如 RAFT-Stereo、IGEV-Stereo）。
- **局部残差细化**：基于当前视差估计对右图特征进行扭曲（warping），转化为残差校正问题（如 WAFT-Stereo）。

然而，现有方法均只采用其中之一，未能利用二者的互补性。WAVE-Stereo 的核心洞察是：**相关体积保留了候选匹配的歧义信息，特征扭曲提供了当前估计下的跨视图对齐信号，二者互补**。此外，迭代更新的 ConvGRU 具有局部感受野，在无纹理区域缺乏全局空间约束。因此，论文提出统一两种表示并注入周期性全局上下文，在**零样本泛化**和**实时推理**之间达到良好平衡，且无需依赖任何外部单目深度基础模型。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 整体架构
输入：已校正的双目图像对 (I_L, I_R)。输出：稠密视差图。

- **特征提取**：共享权重的 MobileNetV2 轻量骨干网络提取多尺度特征，经 FPN 融合后得到四尺度特征，其中 1/4 分辨率特征 f_L, f_R (C=24) 用于后续操作。
- **初始视差**：计算全对相关（通道点积均值），构建 3D 代价体积 C ∈ R^{D×H/4×W/4}；使用轻量 2D 聚合模块（MobileNetV2 逆残差块 + 三层 UNet）正则化；soft-argmin 回归得到初始视差 d_0。
- **迭代更新**：由 GWCE 和 ConvGRU 构成，共 N 次迭代（训练 12 次，推理默认 8 次）。每 K 次迭代执行 PGCP 注入全局上下文。
- **上采样**：RAFT 风格的凸上采样（Context Upsampling）恢复至全分辨率。

### 2.2 GeoWarp 对应编码器（GWCE）
GWCE 在 ConvGRU 输入处并行编码三种互补信号：

1. **相关分支**：从几何编码体积中检索局部相关特征，经 1×1 压缩 + 3×3 卷积得到 x_c，保留匹配歧义分布。
2. **视差先验分支**：当前视差估计 d 经 7×7 大核卷积 + ReLU + 3×3 卷积得到 x_d，提供几何状态信息。
3. **交叉视图扭曲对齐分支**：用当前视差将右图特征扭曲到左图坐标系，得到 ˜f_R，与 f_L 拼接后经两个 3×3 卷积 (ReLU) 得到 x_w，直接观察跨视图差异。

三路输出先融合（Fusion），再与当前视差拼接形成运动特征 m_t，输入 ConvGRU。

**公式表示**：
- ˜f_R = Warp(f_R, d)
- x_w = Enc_w([f_L, ˜f_R])
- m_t = [Fusion([x_c, x_d, x_w]), d]

### 2.3 周期性全局上下文传播（PGCP）
PGCP 旨在以极低开销为局部迭代提供长程约束。

- 每 K 次迭代（默认 K=3）执行一次。
- 将运动特征 m_t 通过 8× 平均池化降至 1/32 分辨率，经 1×1 卷积投影至 Transformer 隐层维度 D_tf=128，展平为 tokens。
- 经过 3 层 Transformer（4 头注意力、MLP 膨胀率 3），取第 1 层和第 3 层输出，输入简化 DPT 模块（自底向上融合，双线性上采样）。
- 输出全局特征 g_t 通过可学习门控参数 α（初始 -0.1）加到 GRU 隐藏状态：h_t = h_t + α · g_t。

无需每次迭代都执行，且工作在极低分辨率，附加开销仅约 3.2ms。

### 2.4 损失函数
L_stereo = λ_0 · SmoothL1(d_0 - d_gt) + Σ_{i=1}^{N} γ^{N-i} ||d_i - d_gt||_1
- λ_0=0.5，γ=0.9（指数衰减，后期迭代权重更高）。
