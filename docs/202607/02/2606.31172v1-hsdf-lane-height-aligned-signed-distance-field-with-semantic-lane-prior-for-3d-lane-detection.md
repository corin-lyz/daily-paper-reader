## 摘要
单眼3D车道检测在自动驾驶中至关重要，但由于固有的深度模糊性，从单张图像恢复可靠的3D几何仍然具有挑战性。先前的方法在平坦地面假设下将图像特征投影到鸟瞰图（BEV）空间，导致真实道路上的几何失真。最近的方法则预测显式高度图以捕捉非平面表面，但仍依赖稀疏的基于锚点的回归，并且仅将恢复的几何用于空间变换而非语义理解。为了克服这些限制，我们提出了HSDF-Lane，它在密集采样的3D特征体上隐式地将道路表面建模为高度对齐的有符号距离场（HSDF）。通过可微渲染，HSDF联合生成准确的高度图和表面对齐的特征。我们进一步引入了车道感知语义位置编码（LSPE），它将从表面对齐特征中导出的车道存在先验注入到transformer查询中，将几何结构与语义引导相结合。在OpenLane基准上的大量实验表明，HSDF-Lane在3D车道检测和高度图估计方面均达到了最先进的性能。

## Abstract
Monocular 3D lane detection plays a critical role in autonomous driving, yet recovering reliable 3D geometry from a single image remains challenging due to inherent depth ambiguity. Prior methods project image features into Bird's-Eye-View (BEV) space under a flat-ground assumption, causing geometric distortion on real-world roads. Recent methods instead predict explicit height maps to capture non-planar surfaces, but still rely on sparse anchor-based regression and exploit the recovered geometry merely for spatial transformation rather than semantic understanding. To overcome these limitations, we propose HSDF-Lane, which implicitly models the road surface as a Height-aligned Signed Distance Field (HSDF) over a densely sampled 3D feature volume. Through differentiable rendering, the HSDF jointly produces an accurate height map and surface-aligned features. We further introduce Lane-aware Semantic Positional Encoding (LSPE), which injects a lane-existence prior derived from the surface-aligned features into the transformer queries, coupling geometric structure with semantic guidance. Extensive experiments on the OpenLane benchmark show that HSDF-Lane achieves state-of-the-art performance in both 3D lane detection and height map estimation.

# HSDF-Lane 论文详细总结

## 1. 论文核心问题与整体含义

- **研究动机与背景**：3D车道检测是自动驾驶的关键感知任务。相较于昂贵的LiDAR方案，单目相机方案更具成本优势。然而，从单张2D图像准确恢复3D几何信息极具挑战。
    - **现有方法局限**：
        1.  **平面假设失真**：早期方法（如基于IPM）假设地面是平坦的，导致在非平面（如上下坡）道路上产生严重的几何失真。
        2.  **稀疏锚点缺陷**：近期方法（如HeightLane, SC-Lane）通过预测高度图来捕捉非平面道路，但仍依赖预定义的稀疏“坡度锚点”进行直接高度回归。这种稀疏、离散的锚点在远处区域会扩大空间间隔，难以准确预测绝对高度，且引入了平面近似假设。
        3.  **语义利用不足**：这些方法将恢复的几何信息（高度图）仅用于空间变换，而忽略了其蕴含的丰富语义信息（如车道位置先验）。

- **核心问题**：如何克服稀疏锚点回归和平面假设的限制，更精确、连续地建模复杂道路表面，并有效利用几何信息中的语义先验来提升3D车道检测性能。

## 2. 论文提出的方法论

- **核心思想**：HSDF-Lane 提出一种新颖的框架，通过**隐式神经表示**和**可微渲染**来替代稀疏锚点回归，并利用渲染出的特征去**引导语义理解**。
- **关键技术细节**：
    1.  **密集3D采样**：
        - 在BEV网格的每个单元上，沿垂直（z轴）方向进行**密集**采样。采样范围$[z_{min}, z_{max}]$ 根据纵向距离$x_i$和最大坡度角$\theta$自适应确定。
        - 引入**自适应采样策略**，保证垂直间距不超过预设分辨率$\delta_z$，从而实现近处稀疏、远处密集的采样，以在计算量和远距离细节间取得平衡。
    2.  **高度对齐的有符号距离场（HSDF）**：
        - 将所有采样点的图像特征（从2D骨干网络投影得到）堆叠，形成一个**密集的3D特征体**。
        - 在该特征体上，使用MLP预测一个**高度对齐的符号距离场（HSDF）**。其真值定义为：$s(x, y, z) = z - H_{GT}(x, y)$，其中$H_{GT}$是真实路面高度。$s=0$表示路面。
        - 此HSDF是轴对齐的，专门为高度估计设计，直接可解释。
    3.  **可微渲染**：
        - **高度图渲染**：对于每个BEV单元，通过Softmax操作将预测的HSDF值转换为采样点的权重$w_k$。然后，使用权重对校正后的采样点坐标进行加权求和，得到连续的粗略高度图$\tilde{\mathbf{H}}$，再通过零初始化的残差卷积进行平滑细化，得到最终的高度图$\mathbf{H}$。
        - **特征渲染**：使用相同的权重$w_k$对3D特征体进行加权求和，得到**表面对齐的特征图**$\mathbf{F}_{hsdf}$。这确保了该特征图与路面几何高度一致。
        - **高度方向Eikonal正则化**：为了稳定HSDF学习，引入了仅在垂直方向上的Eikonal约束（$\partial s/\partial z = 1$），鼓励网络学习物理有意义的距离场。
    4.  **车道感知语义位置编码（LSPE）**：
        - 首先，从渲染出的表面对齐特征$\mathbf{F}_{hsdf}$中预测一个**车道存在热力图** $\mathbf{M}$。
        - 该热力图通过一个可学习的向量$v$进行调制，生成**语义嵌入** $\mathbf{p}_{sem}$。
        - 将$\mathbf{p}_{sem}$与源自高度图$\mathbf{H}$的**几何位置编码** $\mathbf{p}_{geo}$相加，形成最终的**车道感知语义位置编码** $\mathbf{p}_{bev}$，注入到Transformer的查询（queries）中。
        - 这个语义先验指导Transformer的注意力机制更聚焦于可能存在车道的区域，从而提升检测性能。

- **算法流程**：
    1.  输入图像 -> 2D骨干网络提取特征。
    2.  对BEV网格进行密集垂直采样，投影到2D特征上，构建3D特征体。
    3.  使用MLP预测每个采样点的HSDF值。
    4.  通过可微渲染，同时生成高度图$\mathbf{H}$和表面对齐特征$\mathbf{F}_{hsdf}$。
    5.  从$\mathbf{F}_{hsdf}$预测车道热力图$\mathbf{M}$，并结合$\mathbf{H}$计算LSPE ($\mathbf{p}_{bev}$)。
    6.  $\mathbf{p}_{bev}$ 与$\mathbf{H}$一起被用于增强BEV queries，通过可变形交叉注意力（Deformable Cross-Attention）进行特征交互。
    7.  更新后的queries被送入3D车道预测头，输出最终的车道分割、偏移和嵌入。

## 8. 不足与局限

1.  **标签依赖**：训练需要**密集的LiDAR衍生的高度图**作为监督，这可能限制了其在无LiDAR数据或数据质量不佳的场景下的应用。虽然附录展示了伪标签的可能性，但性能仍有差距。
2.  **固定BEV网格**：高度图是在一个**固定的BEV网格**上预测的，没有识别出可行驶区域，这意味着其预测范围可能包括非路面部分。
3.  **传感器模态限制**：实验仅局限于**单目**设置，没有扩展到多视图、时序或多模态（如LiDAR+相机）配置。这限制了方法在更复杂和冗余的自动驾驶系统中的潜力。
4.  **Z-error局限性**：论文承认，由于与直接对车道点进行Z-loss回传的方法（如GLane3D）在监督方式上存在差异，其Z-error指标可能不能进行公平比较。这提示了评估指标本身可能存在的偏向性。
5.  **滚动路面假设**：虽然比平面假设好，但HSDF本质上是将路面建模为**高度场（单值函数）**，即一个$(x， y)$位置只能对应一个$z$高度。这在面对像悬挂物或路洞等3D几何时可能失效，但这对自动驾驶场景影响不大。
6.  **远距离性能**：虽然远距离X-error表现最好，但Z-error在远距离上（虽然与其它方法不完全可比）并未达到最优（附录表S3显示HSDF-Lane的Z-error在部分情况高于HeightLane），远距离高度的精确估计仍然是挑战。
