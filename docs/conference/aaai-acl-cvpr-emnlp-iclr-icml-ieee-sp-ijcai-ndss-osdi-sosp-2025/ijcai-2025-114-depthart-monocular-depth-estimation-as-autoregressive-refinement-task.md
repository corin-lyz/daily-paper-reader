## DepthART：将单目深度估计视作自回归细化任务

### 1. 核心问题与整体含义

- **研究背景**：单目深度估计（MDE）旨在从单张图像恢复场景深度，是视觉感知、自动驾驶和机器人等领域的基础任务。传统判别式方法依赖领域特定的标注数据，泛化能力受限；近年来生成式方法（如扩散模型）借助互联网规模预训练先验显著提升了性能，但仍存在改进空间。
- **核心问题**：自回归生成模型（特别是视觉自回归建模，VAR）在条件图像生成上已展现优于扩散模型的效果和更快的推理速度，但其标准训练范式（teacher forcing）直接应用于深度估计时效果不佳——训练时使用真实 token 序列作为输入，推理时却要依赖模型自身预测，造成训练-推理不一致，模型无法学会修正自身累积误差。
- **整体含义**：本文引入一种全新的单目深度估计学习范式——将深度估计表述为“深度自回归细化任务”（DepthART），利用模型自身预测构造动态目标，使模型在训练中学会自我细化，弥合训练与推理之间的差距，从而提升深度估计的性能和泛化能力。

### 2. 方法论

**核心思想**：
- 将单目深度估计建模为**图像条件下的自回归生成问题**，利用预训练的 VQ-VAE 将深度图编码为多尺度 token 序列，由 VAR Transformer 逐尺度预测。
- 核心创新在于**训练目标的动态构造**：不再是预测 VQ-VAE 预分解的固定 token 图，而是基于模型自身输出计算残差目标，实现自细化学习。

**关键技术细节**：
- **VQ-VAE 预分解**：输入图像 I 通过 VQ-VAE 编码器得到 K 个尺度 token 图 {x₁, x₂, …, x_K}，作为模型输入的条件序列。各尺度 token 图按残差方式分解：rₖ = E(I) − Σηᵢ(xᵢ)（前 k−1 尺度累积贡献的残差），然后量化得到 xₖ = Q[S(rₖ, sₖ)]。
- **DepthART 训练流程**：
  1. 以图像 token 序列为条件，执行模型推理得到预测的深度 token 图 zₖ = VAR(z₁, …, z_{k−1}, x₁, …, x_K)；
  2. 用同一 VQ-VAE 编码器提取真实深度图 D 的连续特征 f_D（不经过量化）；
  3. 构造动态残差目标：δₖ = f_D − Σηᵢ(zᵢ)（前 k−1 个累积预测与真实特征的差），tₖ = Q[S(δₖ, sₖ)]；
  4. 计算交叉熵损失：L = Σ L_CE(zₖ, tₖ)；
  5. 每个训练步骤动态重新计算目标和输入，而非使用单一固定的 VQ-VAE 分解。
- **优势**：训练过程中模型始终面对自身预测，与推理过程一致；VQ-VAE 分解具有非唯一性，动态目标使模型探索更多分解轨迹，增强自我细化能力。

### 6. 主要结论与发现

- **DepthART 显著优于 teacher forcing**：在 ETH3D 上，相对重建误差降低约 70%（1.7 倍改进），且在各尺度均保持持续细化（图3）。
- **VAR+DepthART 取得最优综合性能**：在 4 个未见数据集上的平均排名（Rank ↓）达到 2.1，超越 MiDaS（3.5）、DPT（2.9）、DiT-depth（4.3）等方法。
- **关键指标表现**：在 IBIMS 平面区域误差（pe-fla=1.91，pe-ori=7.27）上优势明显，表明平面几何重建质量更优。
- **预训练至关重要**：无 ImageNet 预训练时，ETH3D 的 δ₁ 从 0.196 恶化至 0.392，AbsRel 从 0.177 恶化至 0.46，证实生成式预训练为模型提供了理解 VQ 空间的必要先验。

### 7. 优点

- **方法创新性强**：首次将 VAR 应用于单目深度估计，并提出基于模型自身预测构造动态目标的训练范式，从任务表述到训练策略均具有原创性。
- **有效解决训练-推理不一致**：动态残差目标使训练过程与推理过程天然对齐，赋予模型自细化能力，概念清晰且效果显著。
- **不同于单尺度预测的固有局限**：DepthART 利用 VQ-VAE 分解的非唯一性，使模型可以探索多路径分解，优于固定 teacher-forcing 轨迹。
- **实验对比公平**：所有基线与方法在相同数据集和相同条件下训练，评估在未见数据集上进行，能较客观反映泛化性能。
- **综合指标优异**：特别是在平面区域重建质量上具显著优势，点云重建可视化提供了极具说服力的直观证据。

### 8. 不足与局限

- **依赖组件质量**：VQ-VAE 和生成式预训练均来自原版 VAR，其 VQ-VAE 在相对较小的 OpenImages 数据集上以低分辨率训练，限制了深度重建的上限——图3显示端到端 VQ-VAE 重建误差本身即为硬性瓶颈。
- **量化误差风险**：VQ-VAE 的码本学习无法保证能准确量化任意残差尺度，可能导致训练目标不可达而使模型陷入局部最优。
- **预训练数据规模不足**：仅使用 ImageNet 的类别条件预训练，未利用更大规模的互联网图文数据（如 LAION-5B），无法充分发挥生成式先验的潜力（作者也指出这是重要改进方向）。
- **实验覆盖有限**：消融仅涵盖有无预训练一组，未系统研究 VQ-VAE 选择、码本尺寸、尺度数量等超参数的影响；训练数据和测试基准均限于常见室内外场景，未覆盖光照复杂、弱纹理等极端情况。
- **分辨率限制**：因 VQ-VAE 最大支持 256×256，方法目前无法直接扩展到高分辨率深度估计。
