## 摘要
我们提出了一种非学习框架的立体匹配方法，用于从严重噪声图像中估计视差。利用联合场（FoJ）方法，在代价体构建过程中保留严重噪声下稳定存在的粗粒度视觉特征，同时丢弃与光子噪声不可区分的细粒度纹理。由此产生的结构信息指导边界感知的半全局匹配（SGM），该算法动态调整平滑惩罚项以保持真实的视差不连续性。在广泛使用的基准数据集上，对于未遮挡像素，输出稀疏视差图的准确性优于近期立体匹配算法。

## Abstract
We present a non-learning stereo framework for disparity estimation from severely noisy images. Using the Field of Junctions (FoJ), it retains coarse visual features stable under severe noise for cost volume construction while discarding fine textures inseparable from photon noise. The resulting structural information guides boundary-aware Semi-Global Matching (SGM) that dynamically adapts smoothness penalties to preserve true disparity discontinuities. The output is a sparse disparity map more accurate than those of recent stereo algorithms over unmasked pixels on widely-used benchmark datasets.

### 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：利用 Field of Junctions (FoJ) 从噪声图像中提取出粗尺度结构（长边缘、大斑点等），这些结构在噪声下仍清晰可辨。基于这些结构构建代价体，并采用改进的边界感知半全局匹配 (SGM) 估计视差，最终输出高精度的稀疏视差图。
- **关键技术细节**：
    1. **FoJ 表示生成**：对左右噪声图像分别独立运行 FoJ 算法 [8]，得到各自的边界图 \(B(x)\) 和颜色图 \(C(x)\)。颜色图保留了主要结构，抑制了噪声。
    2. **代价体积构造**：提出对称双向代价函数，同时利用颜色图与原始噪声图进行匹配：
       \[
       C_{L/R}(x_i, d) = \|C_{L/R}(x_i) - P_{R/L}(x_i \pm [d,0])\|_2 + \|P_{L/R}(x_i) - C_{R/L}(x_i \pm [d,0])\|_2 + \lambda_r \|C_{L/R}(x_i) - C_{R/L}(x_i \pm [d,0])\|_2
       \]
       其中 \(C\) 为颜色图，\(P\) 为原始噪声图块。
    3. **边界感知 SGM**：在标准 SGM 能量最小化框架中，将平滑惩罚项 \(P_2\) 修改为根据边界强度动态调整：
       \[
       P_2(x) = \max(P_{2,base} \exp(-\alpha B(x)), P_{2,min})
       \]
       在边界附近（\(B(x)\approx1\)），\(P_2\) 变小，降低对不连续性的惩罚，从而保留真实视差断崖。
    4. **后处理**：上采样每块的视差，根据边界阈值 \(B_0\) 保留高置信度像素，再通过左右一致性检查滤除错误匹配，最终得到稀疏视差图。

### 优点

1. **无需训练数据**：完全非学习，避免了学习方法的域迁移问题，在未知噪声分布下依然有效。
2. **对噪声鲁棒**：通过 FoJ 显式分离粗结构与噪声，避免了去噪+立体管线中视图不一致伪影。
3. **边界保留**：创新地利用边界图动态调整 SGM 的平滑惩罚，显著改善了不连续处视差精度。
4. **计算透明**：全流程为传统优化，可重复性高。
5. **实验设计严谨**：窗口评估消解了边界定位误差影响；消融验证了各组件贡献。

### 不足与局限

1. **输出为稀疏视差**：覆盖率仅 2.5–2.8%，无法直接用于需要全图深度的应用（如自动驾驶）；下游密化增加额外复杂度和误差。
2. **评估偏差**：本方法仅对预测像素计算指标，而对比方法在全图有效像素上计算，使得对比不完全公平（本方法自动回避了低置信度/噪声密集区域）。
3. **计算开销**：FoJ 提取和基于块的 SGM 在大图像上需要重叠块处理，内存和耗时较高，实时性差。
4. **缺少真实低光数据验证**：仅使用合成噪声，未在真实低光/高噪声立体数据集（如带有真实噪声的 Middlebury 或 KITTI 低光）上测试，泛化性存疑。
