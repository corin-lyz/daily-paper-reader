## 摘要
现代视频目标分割（VOS）涉及跟踪和分割用户指定的目标。虽然最近的方法在单目标场景中取得了显著性能，但将其扩展到多目标设置通常涉及为每个单独目标复制单目标处理，导致帧率（FPS）下降且延迟随目标数量增加而无界增长。基于Segment Anything 2（SAM2），我们提出了SAM-MT，通过将模型转化为用于实时多目标视频分割的交互式框架来解决这一问题。SAM-MT使用显式查询来表示不同的单独目标，同时使用共享表示来获取全局上下文。它采用解耦的掩码注意力来保持个体身份免受跨目标干扰，并使用稀疏内存实现稳定的时间演化，以及专门处理遮挡和防止重叠的策略。SAM-MT成功地将延迟与目标数量解耦，实现了与单目标基线相当的实时速度（10个目标>36 FPS），同时保持SAM2鲁棒的视频分割性能。

## Abstract
Modern Video Object Segmentation (VOS) involves tracking and segmenting user-specified targets. While recent approaches have achieved remarkable performance in single-target scenarios, extending them to multi-target settings typically involves replicating the single-target processing for each individual object, resulting in reduced frame rates (FPS) with unbounded latency as target count increases. Built upon Segment Anything 2 (SAM2), we propose SAM-MT, which addresses this by transforming the model into an interactive framework for real-time Multi-Target video segmentation. SAM-MT uses explicit queries to represent different individual targets, in parallel with a shared representation for global context. It employs decoupled masked attention to keep individual identities distinct from cross-target interference, and sparse memory for stable temporal evolution, along with specialized strategies for occlusion handling and overlap prevention. SAM-MT successfully decouples latency from the number of targets, achieving real-time speed on par with single-target baselines (>36 FPS for 10 targets) while maintaining SAM2's robust video segmentation performance.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：现代视频目标分割（VOS）方法（如基于空间-时间-记忆范式的STM、SAM2等）在单目标场景中表现优异，但当扩展到多目标时，通常需要为每个目标重复执行单目标处理流程，导致计算量和内存随目标数量线性增长，帧率急剧下降，无法满足实时性要求。
- **研究动机**：自动驾驶、机器人、密集场景监控等实际应用需要同时跟踪和分割多个目标，且需保持每目标身份标识，同时维持实时速度。现有方法（包括SAM2）由于按对象独立处理，难以在目标数量增加时保持效率。
- **整体含义**：SAM-MT旨在填补“实时多目标交互式视频分割”的空白，通过框架级设计将延迟与目标数量解耦，实现接近单目标的效率，同时保持SAM2鲁棒的分割性能。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 将单目标处理修改为**共享全局上下文 + 并行显式目标查询**的架构，从而避免为每个目标重复计算图像特征和内存处理。
- 通过**解耦掩码注意力**防止目标间干扰，通过**查询稀疏内存**实现时间演化，并引入**跨步采样**和**重叠惩罚**增强鲁棒性。

### 关键技术细节
1. **可扩展目标查询（Scalable Target Queries）**：
   - 为用户指定的每个目标分配一个显式的ID感知查询（target query），而不是固定数量的通用查询，自然适应任意目标数量。
2. **解耦掩码注意力（Decoupled Masked Attention）**：
   - 在解码器的自注意力层中，不同目标的查询互相掩码（\(-\infty\)），不能相互关注；但所有目标查询都与全局查询（global queries）双向可见。这样既保持个体身份独立，又共享全局上下文。
   - 公式：\(\mathbf{Q}' = \text{softmax}(\mathbf{Q}\mathbf{K}^\top + \mathbf{M})\mathbf{V} + \mathbf{Q}\)，其中掩码\(\mathbf{M}\)按规则设置。
3. **查询合并（Query Consolidation，仅初始帧）**：
   - 初始帧中用户可为每个目标提供多个点，通过MLP权重头将多个点查询加权合并为一个目标查询，作为紧凑表示。
4. **基于查询的稀疏内存（Query-based Sparse Memory）**：
   - 保留SAM2的密集内存仅用于所有目标的合并掩码（全局上下文），而每个目标的演化历史存储为轻量级查询（每目标每帧仅一个token），构成FIFO稀疏内存（窗口大小T，默认16）。
5. **身份变换器（Identity Transformer）**：
   - 在后续帧中，上一帧的目标查询通过跨注意力与稀疏内存中对应的历史查询交互（使用身份感知掩码，只关注自身历史），从而更新当前帧的目标查询，保持身份一致性。
6. **训练策略**：
   - **两阶段训练**：第一阶段静态图像级预训练（实现多点单帧分割）；第二阶段视频序列训练（保持时间身份一致性）。
   - **跨步采样**：采8帧，结合相邻帧和4步长（跨度32帧），以捕获短期运动和长期遮挡/重现。
   - **点采样**：模拟用户交互，随机采样1-5正点和0-2负点，结合网格和随机采样。
   - **重叠损失**：惩罚不同目标预测掩码之间的重叠，鼓励像素级独占。
   - **损失函数**：个体掩码损失（Focal + Dice + 重叠损失）+ 全局掩码损失（Focal、Dice、IoU、目标分数损失）。

### 算法流程（文字描述）
1. 对初始帧：用户为每个目标提供若干点击点 → 编码为查询 → 经解耦掩码自注意力 + 交叉注意力与图像特征交互 → 合并为每目标一个目标查询 → 预测掩码并存入稀疏内存（连同密集内存中全局掩码）。
2. 对后续帧：从前一帧获取目标查询 → 经身份变换器从稀疏内存中访问自身历史 → 更新查询 → 再次通过解码器（解耦掩码注意力 + 交叉注意力） → 预测各目标掩码 → 更新稀疏内存。

## 7. 优点

- **框架级创新**：首次解决SAM系列的多目标瓶颈，实现延迟与目标数解耦，实用价值高。
- **高效且可扩展**：采用轻量查询代替密集内存，结合FIFO稀疏内存，使存储和计算几乎恒定。
- **交互友好**：支持点击输入，可任意指定目标数量，适合人机交互场景。
- **强鲁棒性**：在密集遮挡、长时消失重现、身份模糊场景下均表现出色（定性示例清晰）。
