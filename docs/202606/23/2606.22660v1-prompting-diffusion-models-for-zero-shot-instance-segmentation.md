## 摘要
近期计算机视觉领域涌现出若干颠覆性研究方向，包括在场景理解（甚至交互式场景理解）中实现前所未有零样本性能的基础模型，以及能够合成极其逼真图像的生成模型。后者因其丰富的先验知识，在场景理解任务中也显示出高效性。然而，对于可提示分割，基础模型在准确分割目标区域方面存在困难，导致误报和过分割。值得注意的是，早期利用生成先验的尝试仅在后期处理中使用提示，由于过程对用户输入不敏感，导致分割结果次优。本文针对这些局限性提出Prompt2Seg，一种基于扩散分割的空间条件框架。Prompt2Seg通过一个条件分支增强冻结的扩散分割模型。我们的方法将空间提示（表示为2D高斯分布或置信度图）作为显式输入信号，训练模型直接响应用户意图。在精心限制的对象类别集（来自Hypersim和Virtual KITTI 2）上微调后，Prompt2Seg零样本泛化到广泛未见过的对象类型和视觉领域。我们在七个数据集上评估，范围从标准基准到更具挑战性的领域，包括绘画、自我中心视图和X光数据。此外，我们证明Prompt2Seg在所有基准测试中始终优于底层的扩散分割骨干网络。我们的结果表明，生成式预训练中编码的丰富先验，结合原则性的空间条件，为在没有大规模掩码监督的情况下广泛泛化交互式分割提供了一条有前景的路径。

## Abstract
Several disruptive research directions have recently emerged in computer vision, including foundation models achieving previously unseen zero-shot performance in scene understanding, even interactively, and generative models that synthesize extremely realistic images. The latter have also been shown to be highly effective in scene understanding tasks thanks to their rich priors. However, for promptable segmentation, foundation models struggle with accurately segmenting an object's region, leading to false positives and over-segmentation. Notably, early attempts that leverage generative priors use prompts only during post-processing, yielding suboptimal segments because the process is agnostic to the user input. In this paper, we target these limitations with Prompt2Seg, a spatial conditioning framework for diffusion-based segmentation. Prompt2Seg augments a frozen diffusion segmentation model with a conditioning branch. Our approach takes spatial prompts, represented as 2D Gaussians or confidence maps, as explicit input signals, training the model to respond directly to user intent. Fine-tuned on a deliberately constrained set of object categories drawn from Hypersim and Virtual KITTI 2, Prompt2Seg generalizes zero-shot to a wide range of unseen object types and visual domains. We evaluate on seven datasets ranging from standard benchmarks to more challenging domains, including paintings, egocentric views, and X-ray data. Furthermore, we demonstrate that Prompt2Seg consistently outperforms the underlying diffusion segmentation backbone across all benchmarks. Our results suggest that the rich priors encoded in generative pretraining, combined with principled spatial conditioning, offer a compelling path toward broadly generalizing interactive segmentation without large-scale mask supervision.

整体含义：提出**Prompt2Seg**，它是**首个利用扩散模型进行交互式实例分割的方法**，通过在冻结的扩散分割骨干上增加一个轻量级空间条件分支（ControlNet），将2D高斯或置信度图作为输入信号，让模型学会直接预测受提示的目标区域。该方法仅在两个合成数据集（室内场景Hypersim和室外驾驶Virtual KITTI 2）上进行微调，但能零样本泛化到7个完全不同的域（自然图像、艺术绘画、X光、自我中心视图等），并在多个长期数据集上超越了监督模型SAM。

## 2. 方法论

### 核心思想
保持预训练扩散模型（Gen2Seg，基于Stable Diffusion）的参数**完全冻结**，仅训练一个额外的**ControlNet风格的条件分支**。该分支接收用户提供的空间提示（如点击坐标），将其转换为连续的空间图（双尺度高斯热图），然后向冻结U-Net的各层注入残差，引导其生成仅包含提示目标的实例着色图（RGB图，前景为某种颜色，背景为黑色）。

### 关键技术细节
1. **空间提示表示**：
   - 对于用户点击坐标 \( r_i = (u_i, v_i) \)，定义2D高斯热图：  
     \( G_\sigma(q; r_i) = \exp\left(-\frac{\|q - r_i\|_2^2}{2\sigma^2}\right) \)，其中 \(\sigma\) 控制空间范围。
   - 多点点击通过逐像素取最大值聚合：\( h_\sigma^+(q) = \max_{r_i \in P^+} G_\sigma(q; r_i) \)。
   - 采用双尺度编码：小尺度 \(\sigma_s=8\) 提供精确定位，大尺度 \(\sigma_l=16\) 提供邻域上下文。两者拼接为3通道条件张量 \( c = \Psi(h_{\sigma_s}^+, h_{\sigma_s}^+, h_{\sigma_l}^+) \in \mathbb{R}^{3 \times H \times W} \)。

2. **条件注入**：
   - 沿用ControlNet结构：复制U-Net的编码器生成可训练的分支，在冻结U-Net的每层添加残差 \(\Delta^{(l)}\)。
   - 扩散过程固定单一时间步 \( t^* \)（Gen2Seg的单步设定），输入图像通过VAE编码为 \( z_x \)，然后进行一步去噪，得到分割潜在码 \( \hat{z}_y \)，再解码为RGB实例着色图 \(\hat{y}\)。

3. **损失函数**：
   - 采用Gen2Seg的实例着色损失 \( \mathcal{L}_{IC} = \mathcal{L}_{var} + \lambda_{sep}\mathcal{L}_{sep} + \lambda_{mean}\mathcal{L}_{mean} \)。
   - **关键改动**：训练时，对于每张图像随机采样1-4个目标实例，仅将选中的实例保留为前景（分配随机颜色），其余所有像素（包括其他实例）设为背景黑色。这样监督信号强制模型只预测受提示的对象。

4. **推理**：
   - 输入图像和空间条件（由用户点击或置信度图构造），模型输出RGB图。
   - 通过阈值化像素到黑色（背景）的欧氏距离得到二值掩码：\(\hat{m}(q) = 1[ \| y_q - 0 \|_2 > \tau ]\)，阈值 \(\tau\) 在验证集上固定。

### 算法流程（文字说明）
1. 预训练阶段：使用Gen2Seg的稳定扩散检查点初始化所有参数（VAE、文本编码器、U-Net）。
2. 冻结上述所有参数，仅初始化ControlNet分支（从U-Net编码器复制权重）。
3. 训练循环：
   - 从Hypersim/Virtual KITTI 2中采样一张图像。
   - 从该图像的所有实例中随机选择4个目标实例（面积>300像素）。
   - 对每个目标实例，在其掩码内部通过距边界最远点采样一个点击位置。
   - 将该点击转换为双尺度高斯热图（3通道条件）。
   - 构建目标着色图：仅保留选中的实例，其余为黑色。
   - 模型前向：输入图像（VAE编码）和条件，一步扩散预测着色图。
   - 计算 \( \mathcal{L}_{IC} \)，更新ControlNet参数。
4. 推理：用户提供点击 → 构造热图 → 冻结的模型一步预测 → 阈值得到掩码。

## 6. 主要结论与发现

1. **空间条件注入显著优于后处理检索**：Prompt2Seg在所有7个数据集上全面超越Gen2Seg（最高提升约15个mIoU点），验证了将用户提示显式加入生成过程的必要性。
2. **生成先验对域偏移更强健**：在艺术画、X光等与训练数据差异极大的域中，Prompt2Seg超越了完全有监督的SAM，说明扩散模型在预训练中学到的视觉结构先验能有效弥补标注数据的缺乏。
3. **合成数据微调即可实现强泛化**：仅用两个合成数据集（室内+室外驾驶）微调ControlNet，模型就能零样本分割从未见过的类（如动物、自定义物品、X光中的手枪等），极大降低了数据收集成本。
4. **可作为任意密集图的精炼模块**：将模型输入从点击替换为其他模型的置信度/不确定性图，Prompt2Seg能有效抑制噪声、改善异常检测性能，表明其条件分支具有广泛适用性。
5. **小物体分割仍是瓶颈**：在COCO小物体上表现远低于SAM（12.1 vs 57.0），这一限制继承自底层扩散模型的空间压缩瓶颈，提示未来需要改进分辨率或采用多尺度策略。

## 7. 优点

- **方法新颖性**：首次将空间提示以ControlNet的方式直接注入扩散分割过程，改变了生成模型只在后处理利用交互的范式。
- **技术简洁高效**：仅需训练一个轻量ControlNet分支，冻结所有预训练参数，训练成本低（作者未给出具体，但理论上远低于全量微调）。
