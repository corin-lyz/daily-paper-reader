## 摘要
预训练的视觉基础模型（VFMs）因其强大的语义表示和泛化能力已成为现代计算机视觉的核心。然而，其分块化或池化输出本质上是低分辨率的，限制了它们在需要细粒度、像素级推理的任务中的效果。现有的特征上采样方法要么降低语义保真度，要么依赖于特定VFM的重新训练和沉重架构，阻碍了效率和可扩展性。为应对这些挑战，我们提出RaysUp，一个超轻量、任务无关且与VFM无关的特征上采样框架，可在任意分辨率下重建高分辨率特征图。与传统的2D插值或基于注意力的方案不同，RaysUp将特征重建提升到几何感知的光线域。具体来说，我们引入了空间解耦引导编码器用于方向感知的引导编码、任意分辨率交叉注意力机制用于灵活分辨率的重建，以及一种新颖的光线位置编码（RayPE），通过6D Plücker光线坐标注入隐式3D几何先验。最后，一个几何感知邻域注意力模块进一步确保内容自适应的双边聚合，同时保持几何一致性。在多种密集预测任务上的大量实验表明，RaysUp实现了最先进的性能，同时仅使用AnyUp 16%的参数，并提供约7倍更快的推理速度。这些结果凸显了大幅改进的精度-效率权衡，并将RaysUp确立为通用特征上采样的实用且可扩展的解决方案。代码可在https://github.com/MAP-RaysUp/RaysUp获取。

## Abstract
Pre-trained Vision Foundation Models (VFMs) have become central to modern computer vision due to their powerful semantic representations and strong generalization ability. However, their patchified or pooled outputs are inherently low-resolution, limiting their effectiveness in tasks requiring fine-grained, pixel-level reasoning. Existing feature upsampling approaches either degrade semantic fidelity or rely on VFM-specific retraining and heavy architectures, hindering efficiency and scalability. To address these challenges, we propose RaysUp, an ultra-lightweight, task-agnostic, and VFM-agnostic feature upsampling framework that reconstructs high-resolution feature maps at arbitrary resolutions. Unlike conventional 2D interpolation or attention-based schemes, RaysUp lifts feature reconstruction into a geometry-aware ray domain. Specifically, we introduce a Spatially Decoupled Guidance Encoder for direction-aware guidance encoding, an Any-Resolution Cross-Attention mechanism for resolution-flexible reconstruction, and a novel Ray Positional Encoding (RayPE) that injects implicit 3D geometric priors via 6D Plucker ray coordinates. Finally, a Geometry-Aware Neighborhood Attention module further ensures content-adaptive bilateral aggregation while preserving geometric consistency. Extensive experiments across diverse dense prediction tasks demonstrate that RaysUp achieves state-of-the-art performance while using only 16% of the parameters of AnyUp and delivering approximately 7x faster inference. These results highlight a substantially improved accuracy-efficiency trade-off and establish RaysUp as a practical and scalable solution for universal feature upsampling. Code is available at https://github.com/MAP-RaysUp/RaysUp.

## 2. 方法论

### 核心思想
将特征重建从传统2D网格提升到几何感知的射线域（ray domain），利用3D光线几何先验指导上采样，实现跨分辨率的几何一致特征聚合。

### 关键技术细节

1. **空间解耦引导编码器（Spatially Decoupled Guidance Encoder）**
   - 从输入RGB图像提取方向感知的引导特征。受JAFAR中3×3卷积核各向异性统计启发，将总通道Dg均匀分成四个分支：
     - 1×1卷积（中心建模）
     - 1×3卷积（水平方向）
     - 3×1卷积（垂直方向）
     - 2×2膨胀卷积（对角线方向）
   - 每个分支采用GroupNorm+SiLU+残差结构，最后将四分支输出沿通道拼接。
   - 相比标准3×3卷积降低约69.4%参数量，增强各向异性建模能力。

2. **任意分辨率交叉注意力机制（Any-Resolution Cross-Attention）**
   - 利用引导特征通过自适应平均池化生成：
     - 高分辨率查询（Qg）：尺寸为 (H_any, W_any)
     - 低分辨率键（Kg）：尺寸为 (H_lr, W_lr)
   - 值V直接取自VFM的低分辨率特征Flr。
   - 支持分辨率解耦，无需显式插值。

3. **射线位置编码（RayPE）**
   - 将每个像素与3D相机光线关联（原点o + 方向d），生成6D Plücker坐标。
   - 使用多频带对数间距谐波相位编码（N=5频带），将射线参数映射到旋转相位。
   - 对注意力头特征进行逐元素旋转调制（类似RoPE但从1D扩展到3D几何空间），注入隐式3D几何先验，使特征聚合沿射线流形对齐。

4. **几何感知邻域交叉注意力（Geometry-Aware Neighborhood Cross-Attention）**
   - 在高分辨率查询的低分辨率对应位置定义局部k×k邻域（k=6），通过膨胀因子适应分辨率比。
   - 在该邻域内执行缩放点积注意力，值来自原始VFM特征。
   - 保持局域性和几何一致性，同时将复杂度从全局O(H_anyW_any·H_lrW_lr)降至O(H_anyW_any·k²)。

5. **训练目标**
   - 结合余弦相似度损失和L2距离损失，监督重建特征与高分辨率目标特征的对齐。

## 7. 优点

1. **极轻量设计**：0.14M参数，GFLOPs低，内存占用小，推理速度快，接近实时。
2. **通用性**：任务无关、VFM无关、任意输入/输出分辨率，无需针对每种VFM重训练。
3. **几何先验注入**：开创性地将3D射线约束引入注意力模块（RayPE），提升了跨分辨率几何一致性，优于纯2D位置编码方法。
4. **理论洞察**：从全局到局部的复杂度降低，同时保持内容自适应，平衡了性能和效率。
5. **消融充分**：每个模块都得到验证，并可视化了解耦方向编码的优势。

## 8. 不足与局限

1. **相机参数依赖**：RayPE需要内参和外参，在无相机标定数据（如互联网图像、光场数据）的场景中无法直接适用；虽可通过身份矩阵近似，但对非透视投影（如鱼眼、全景）效果未知。
2. **极端低分辨率限制**：实验仅测试了最低16×16输入，更极低分辨率（如8×8）未探究，可能因信息过少导致语义漂移。
3. **训练数据单一**：仅在ImageNet上训练，未使用多视角或多分辨率配对数据（如FeatUp的多视角一致性损失），可能限制泛化到复杂真实场景（如视频序列中遮挡、运动模糊）。
4. **对比方法局限**：未与最新基于扩散模型或隐式神经表示的上采样方法（如某些NeRF变种）比较，且LoftUp因引入SAM掩码监督在某些语义分割任务上略优于RaysUp，表明没有免费午餐。

6. **实际部署考虑**：虽然推理快，但训练仍需要单卡约1小时（100k步），对于频繁更换VFM的场景可能仍有一定开销；且模型设计假设图像输入为规则网格，对不规则采样或点云特征不适用。
