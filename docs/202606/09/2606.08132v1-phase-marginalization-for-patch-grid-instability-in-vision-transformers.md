## 摘要
视觉Transformer在固定的块网格上运行，这可能会引入依赖相位的密集预测不稳定性：改变块分区会改变像素可用的令牌证据，尤其是在边界附近。我们将块网格相位形式化为一个干扰变量，并提出相位边缘化，一种事后边缘化方法，它评估结构化的块网格相位，逆对齐密集输出，并在原始图像坐标系中聚合它们。中央变体，即K=4的均匀相位边缘化，无需训练，并在测量的分割、深度和局部匹配设置上优于规范的K=1基线。在受控的Cityscapes实验中，均匀相位边缘化比基于通用移位的四次前向测试时增强（TTA）提供了适度的计算匹配优势（在最强测试通用行上+0.31平均交并比）。进一步扩展研究表明，K=4是一个实用的成本-精度权衡：K=8基本不变，K=16在更高延迟下几乎没有增加精度。这些结果将块网格相位定位为可测量的干扰变量，并将相位边缘化定位为密集ViT预测的简单诊断和事后边缘化基线。

## Abstract
Vision Transformers operate on fixed patch grids, which can introduce phase-dependent instability for dense prediction: changing the patch partition can change the token evidence available to a pixel, especially near boundaries. We formalize patch-grid phase as a nuisance variable and propose Phase Marginalization, a post-hoc marginalization method that evaluates structured patch-grid phases, inverse-aligns dense outputs, and aggregates them in the original image coordinate system. The central variant, Uniform Phase Marginalization with K = 4, is training-free and improves over the canonical K = 1 baseline across measured segmentation, depth, and local matching settings. In a controlled Cityscapes experiment, Uniform Phase Marginalization provides a modest compute-matched advantage over generic shift-based four-forward test-time augmentation (TTA) (+0.31 mean Intersection-over-Union over the strongest tested generic row). A scaling study further shows that K = 4 is a practical cost-accuracy trade-off: K = 8 is essentially unchanged and K = 16 adds little accuracy at much higher latency. These results position patch-grid phase as a measurable nuisance variable and Phase Marginalization as a simple diagnostic and post-hoc marginalization baseline for dense ViT prediction.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想

- 将块网格相位定义为干扰变量 $\phi = (dx, dy)$，其中 $dx, dy \in \{0, \ldots, P-1\}$，$P$ 为块大小。
- 构建一个离散的相位集合 $\Phi_K$（例如 $K=4$ 时取四个象限中心点），对每个相位分别进行前向推理，然后将各个相位的密集输出逆对齐到原始图像坐标系，最后通过平均 logits 进行聚合。
- 该方法无需训练，是训练后（post-hoc）的推理包装器。

### 关键技术细节

1. **相位偏移与逆对齐**：使用反射填充和裁剪对输入图像进行相位偏移 $S_\phi$，得到相位特定的输出 $z_\phi = h(f_\theta(S_\phi(x)))$。然后通过逆对齐算子 $A^{-1}_\phi$ 将 $z_\phi$ 映射回原始像素坐标（先reshape为网格、双线性上采样、裁剪）。
2. **聚合公式**：最终预测 $\bar{z}(p) = \frac{1}{K} \sum_{k=1}^K A^{-1}_{\phi_k}(z_{\phi_k})(p)$。
3. **默认相位集 $K=4$**：取 $\Phi_4 = \{(0,0), (0,P/2), (P/2,0), (P/2,P/2)\}$，即亚相位的四个象限中心。
4. **诊断工具**：定义逐像素相位方差 $\sigma^2(p)$ 来测量不同相位下表示的离散程度。

### 次要变体（可训练）

- **Learned Phase-Feature Attention Aggregation**：通过学习MLP为不同相位的空间位置分配注意力权重，但需要微调注意力模块。

- **Pre-Transformer Patch-Embedding Averaging**（失败设计）：在进入Transformer前平均不同相位的patch嵌入，导致性能严重下降。

## 6. 论文的主要结论与发现

1. **块网格相位是ViT密集预测中一个可测量的干扰变量**，不同相位下的输出在边界区域存在明显差异。
2. **Uniform Phase Marginalization（$K=4$）是一种简单有效的训练后基线**，在分割（mIoU提升0.75~1.39）、深度（RMSE降低0.0229）、局部匹配（匹配精度提升0.96~3.75）上一致优于$K=1$基线。
3. **在计算匹配条件下，结构化相位采样优于通用移位TTA**：在Cityscapes上，Uniform $K=4$ 比最强通用TTA（整数移位）高0.31 mIoU。
4. **$K=4$是实用成本-精度权衡点**：$K=8$与$K=4$精度几乎相同，$K=16$仅增加微弱提升但延迟翻倍。因此推荐$K=4$作为默认值。
5. **可学习变体不一定优于均匀聚合**：在某些任务上（如GTA5→Cityscapes、HPatches），学习注意力甚至导致性能下降；而Pre-Transformer嵌入平均是失败设计。
6. **相位边缘化**可作为诊断工具：通过计算逐像素相位方差，可定位模型对相位敏感的像素区域。
