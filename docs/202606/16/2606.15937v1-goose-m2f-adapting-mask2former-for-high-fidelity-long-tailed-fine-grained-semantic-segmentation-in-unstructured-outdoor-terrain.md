## 摘要
我们提出GOOSE-M2F，这是Mask2Former针对ICRA~2026 GOOSE 2D细粒度语义分割（FGSS）挑战赛的任务特定适配。GOOSE基准测试涵盖64个细粒度类别，分布在非结构化户外地形中，具有严重的长尾分布，其中稀有类别每张图像仅占据不到50个像素。我们通过三项针对性贡献扩展了Swin-Large Mask2Former基线：（1）200个对象查询，消除表示饱和；（2）特征精炼模块（FRM），结合ASPP-lite和CBAM双注意力机制；（3）辅助监督头，为稀有类别提供直接的逐像素梯度。多阶段训练策略结合了分布平衡损失、稀有类别复制-粘贴增强、动态IoU感知重加权和EMA。推理时，采用密集滑动窗口引擎，结合2D高斯核混合和4尺度TTA，提升了+10.57%。GOOSE-M2F达到70.08%官方综合mIoU（细粒度63.55%，粗粒度76.61%），在GOOSE 2D FGSS排行榜上排名第三。代码和训练好的模型公开于：\href{https://github.com/Aditya-Lingam-9000/GOOSE-M2F}{Github GOOSE-M2F代码}和\href{https://huggingface.co/XYZ9843/GOOSE-M2F}{Hugging Face GOOSE-M2F}。

## Abstract
We present GOOSE-M2F, a task-specific adaptation of Mask2Former for the GOOSE 2D Fine-Grained Semantic Segmentation (FGSS) Challenge at ICRA~2026. The GOOSE benchmark spans 64 fine-grained classes across unstructured outdoor terrain with a severely long-tailed distribution, where rare classes occupy fewer than 50 pixels per image. We extend the Swin-Large Mask2Former baseline with three targeted contributions: (1)200 Object Queries to eliminate representational saturation; (2)a Feature Refinement Module (FRM) combining ASPP-lite and CBAM dual-attention; and (3)an Auxiliary Supervision Head that delivers direct per-pixel gradients for rare classes. A multi-stage training strategy pairs Distribution-Balanced loss, Rare-Class Copy-Paste augmentation, dynamic IoU-aware re-weighting, and EMA. At inference, a dense sliding-window engine with 2D Gaussian kernel blending and 4-scale TTA adds +10.57\%. GOOSE-M2F achieves 70.08\% Official Composite mIoU (63.55\% fine, 76.61\% coarse), placing 3rd on the GOOSE 2D FGSS leaderboard. Code and trained models are publicly available at: \href{https://github.com/Aditya-Lingam-9000/GOOSE-M2F}{Github GOOSE-M2F Code} and \href{https://huggingface.co/XYZ9843/GOOSE-M2F}{Hugging Face GOOSE-M2F}.

- **问题背景**：非结构化户外地形的语义分割对于机器人（如四足机器人、野外导航、搜索救援）至关重要。与城市场景（Cityscapes、ADE20K）不同，户外地形分割面临**细粒度类别众多（64类）**、**严重长尾分布**（主导类别占>50%像素，稀有类别在<1%图像中出现且每幅图少于50像素）以及**无边界模糊、微小结构**（如电线、杆、锥桶）等挑战。
- **研究动机**：现有的Mask2Former（针对19类城市场景设计）在处理长尾细粒度分割时，100个对象查询表示饱和、像素解码器单尺度限制、稀有类别梯度消失。本文旨在通过**低成本、模块化的适配**解决上述问题，提升在GOOSE 2D FGSS挑战赛中的性能。
- **整体含义**：GOOSE-M2F通过扩展查询数量、引入特征精炼模块（FRM）和辅助监督头，结合精心设计的多阶段训练与推理策略，在长尾、细粒度、非结构化的户外场景语义分割中取得了显著改进，证明了**查询扩展与辅助监督**对这类问题的有效性。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：在预训练Swin-Large Mask2Former基础上，进行**三项针对性改进**来分别对抗三种失败模式：
  1. **查询饱和** → 扩展为200个对象查询。
  2. **像素解码器单尺度局限** → 特征精炼模块（FRM，ASPP-lite + CBAM）。
  3. **稀有类梯度消失** → 辅助逐像素监督头。

- **关键技术细节**：

  - **扩展对象查询**：将默认100查询翻倍至200。前100个查询保留预训练嵌入，后100个查询初始化为前100个加高斯扰动（σ=0.02）。公式：
    \[
    q_i = q_{i \bmod 100} + \epsilon_i,\quad \epsilon_i \sim \mathcal{N}(0, 0.02^2 I),\ i\ge 100.
    \]
    贡献+2-3%复合mIoU。

  - **特征精炼模块（FRM）**：位于像素解码器（输出B×256×H/4×W/4）与Transformer解码器之间。
    - **ASPP-lite**：四个并行空洞卷积（扩张率{1,3,6,12}，64通道）+全局池化，经1×1卷积融合：
      \[
      F_{\text{fused}} = \text{Conv}_{1\times1}(\text{Cat}[F_{d=1},F_{d=3},F_{d=6},F_{d=12},F_{\text{global}}]).
      \]
    - **CBAM**：依次应用通道注意力与空间注意力，残差连接保持梯度。贡献+3-4%对植被和地形类别。

  - **辅助监督头**：两个Conv2d层（256→256→64），在训练时对H/4分辨率特征图施加逐像素交叉熵损失，独立于查询匹配，直接为稀有类提供梯度。
    \[
    \mathcal{L}_{\text{aux}} = \text{CE}(\text{Up}(\hat{y}_{\text{aux}}), y; w_{\text{dyn}}),\quad \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{M2F}} + 0.4 \mathcal{L}_{\text{aux}}.
    \]
    推理时移除，贡献+5-8%对稀有类。

  - **多阶段训练策略**：
    - **分布平衡（DB）损失**：权重 \(w_c = (1-\beta)/(1-\beta^{n_c})\)，β=0.9999，稀有类上加权最高50倍，裁剪范围[0.1, 10]。
    - **动态IoU感知重加权**：每轮验证后基于EMA模型的当前IoU更新损失权重映射 \(w_c^{(dyn)} = f_{\text{tier}}(\text{IoU}_c)\)，性能差的类乘数高。
    - **稀有类复制-粘贴（RCCP）**：概率0.85，使用软高斯掩码混合，微小物体额外缩放1.2-2.5倍。
    - **类别感知重复采样（CAS）**：图像按其最稀有类再采样，最多3倍。
    - **EMA**：影子权重更新率0.9995，用于验证和提交，比原始权重+1.0-1.5%。
    - **三阶段计划**：热身阶段（阶段1-3，LR: 骨干1e-6/解码器5e-6，到55.6%）→加速阶段（阶段4，LR跳升10倍至骨干1e-5/解码器5e-5，打破平台，到56.4%；阶段5-7巩固到59.5%）→精炼阶段（阶段8，LR衰减至骨干5e-6/解码器2.5e-5）。
    - **其他设置**：AdamW（weight decay 0.03）、多项式LR衰减、1000步线性热身、梯度裁剪5.0、裁剪尺寸576×1152、有效batch 16（1样本×16梯度累积）、标签平滑0.10、FP16混合精度。

  - **推理引擎（贡献+10.57%）**：
    - **密集滑动窗口**：896×896重叠裁剪，步长384（57%重叠），每个像素被多个裁剪覆盖。
    - **2D高斯核混合**：每个裁剪的logits乘以2D高斯核（σ=0.5×crop边长），中心权重高，消除拼接伪影。
    - **4尺度×2翻转TTA**：尺度{0.5, 0.75, 1.0, 1.5}，水平翻转，共8视图，logits均值池化后取argmax。1.5×上采样对微小类尤其有效。
    - **EMA权重**用于最后提交。

- **算法流程（文字描述）**：
  - 输入图像经Swin-Large骨干提取特征 → 6层MSDeformAttn像素解码器得到H/4大小的特征图 → FRM（ASPP-lite + CBAM）增强 → Transformer解码器（200个对象查询）进行匈牙利匹配 → 输出分割掩码。
  - 训练时，额外辅助头对H/4特征图直接计算交叉熵损失（与主损失以0.4权重相加）。
  - 推理时，对图像进行多尺度、翻转、密集滑动窗口处理，每个裁剪的logits经高斯加权后求和，最后argmax得到最终分割。

## 7. 优点（方法或实验设计的亮点）
