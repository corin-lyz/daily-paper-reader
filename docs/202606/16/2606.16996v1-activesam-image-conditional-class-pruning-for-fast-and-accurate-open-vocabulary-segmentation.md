## 摘要
Segment Anything Model 3（SAM 3）为概念提示分割提供了强大的冻结主干网络，但将其直接应用于开放词汇语义分割（OVSS）效率低下：通常对整个数据集词汇运行全分辨率解码，而每张图像仅包含一小部分活跃的类别。我们提出ActiveSAM，一个无需训练、零样本推理框架，将SAM 3转变为活跃词汇分割器。ActiveSAM首先对类别提示进行规范化和扩展，然后从低分辨率存在预览中估计图像条件下的活跃集合。使用与冻结SAM 3解码器的分桶提示复用，仅对保留的类别进行全分辨率解码。预览阶段仅使用类别存在证据，跳过不必要的分割头部计算；而最终阶段应用边缘感知背景校准来抑制低置信度像素。ActiveSAM无需目标数据集训练、无需权重更新、无需先验类别存在标签。在八个OVSS基准测试中，ActiveSAM改善了无需训练的开放词汇语义分割的速度-准确率权衡，平均mIoU比当前最先进的SegEarth-OV3高出约+1.4，同时在大词汇数据集上运行速度提升高达5.5倍。ActiveSAM在模拟真实世界分布偏移的图像损坏下也表现出最强的鲁棒性，使其非常适合部署在自动驾驶和具身AI等噪声输入领域。代码可在https://github.com/VILA-Lab/ActiveSAM获取。

## Abstract
Segment Anything Model 3 (SAM 3) provides a strong frozen backbone for concept-prompted segmentation, but applying it directly to open-vocabulary semantic segmentation (OVSS) is inefficient: full-resolution decoding is typically run over the entire dataset vocabulary, whereas each image contains only a small active subset of classes. We introduce ActiveSAM, a training-free, zero-shot inference framework that turns SAM 3 into an active-vocabulary segmenter. ActiveSAM first canonicalizes and expands class prompts, then estimates an image-conditioned active set from a low-resolution presence preview. Only the retained classes are decoded at full resolution, using bucketed prompt multiplexing with the frozen SAM 3 decoder. The preview stage uses only class-presence evidence and skips unnecessary segmentation-head computation, while the final stage applies margin-aware background calibration to suppress low-confidence pixels. ActiveSAM requires no target-dataset training, no weight updates, and no oracle class-presence labels. Across eight OVSS benchmarks, ActiveSAM improves the speed-accuracy tradeoff of training-free open-vocabulary semantic segmentation, outperforming the current state-of-the-art SegEarth-OV3 by approximately +1.4 mIoU on average while running up to 5.5x faster on large-vocabulary datasets. ActiveSAM also demonstrates the strongest robustness under image corruption that simulates real-world distribution shift, making it well-suited for deployment in noisy-input domains such as autonomous driving and embodied AI. Code is available at https://github.com/VILA-Lab/ActiveSAM.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：开放词汇语义分割（OVSS）要求模型在测试时接收任意类别词汇并输出密集分割掩码，而实际每张图像仅包含词汇表中的少量类别。现有基于 SAM 3 的方法（如 SegEarth-OV3）直接对整个词汇表进行全分辨率解码，计算成本极高，严重制约了推理速度，尤其在词汇规模较大的数据集中。
- **核心目标**：在保持 SAM 3 冻结、无需任何训练或标注的条件下，实现快速且准确的 OVSS。ActiveSAM 通过引入**图像条件化的类别剪枝**机制，根据低分辨率预览信号仅解码图像中真正活跃的类别，从而提升效率而不牺牲精度。

## 2. 方法论

- **核心思想**：利用 SAM 3 固有的低分辨率存在头（presence head）作为早期路由信号，在进入昂贵的全分辨率解码之前估计出每张图像的活跃类别集合；同时配合上下文提示扩展和边缘感知背景校准以提升分割质量。
- **技术细节**：
  - **Contextual Prompt Expansion (CPE)**：对原始类别名称进行词汇规范化（如 `windowpane` → `window pane`），并通过 WordNet 超义词和词汇空间中最相似的 Ms 个邻居类名扩充提示，形成更丰富的上下文提示 tokens。
  - **Preview-driven Class Selection**：使用 SAM 3 在低分辨率（672×672）下运行一次预览，仅读取每类存在分数 qc（跳过分割头计算），通过分位数选择活跃集 A(I)，并设上限 Vgate=40 防止过多类别。
  - **Bucketed Full-Resolution Decoding**：仅对活跃集 A(I) 内的类别进行全分辨率（1008×1008）图像编码一次，然后将活跃类别分成大小为 K=32 的桶，每个桶通过一次前向传播完成解码，大幅减少解码次数。
  - **Margin-aware Background Calibration (MABC)**：对于含有背景类的数据集，基于像素的 top-1 与 top-2 分数之间的边缘（margin）和 top-1 分数本身计算校准置信度 cMABC(p)，仅当超过阈值 τ⁺ 才保留预测，否则标记为背景。

## 6. 主要结论与发现

- 性能：ActiveSAM 在 8 个基准上平均 mIoU 达 65.3%，比 SegEarth-OV3 高 +1.4%，比 SAM 3 高 +7.8%。
- 速度：在大词汇数据集上比 SegEarth-OV3 快约 5.0–5.5×（例如 ADE20K 上 FPS 从 0.35 提升至 1.92），而精度更高。
- 鲁棒性：在噪声、模糊、压缩、雾等损坏下，ActiveSAM 的 mIoU 降幅最小，远优于 CLIP 类方法。
- 活跃剪枝有效性：每张图像实际活跃类别中位数仅为原词汇的 1/5 到 1/13（如 ADE20K 词汇 150 类，活跃中位数 30 类），证明剪枝带来巨大加速且不影响最终精度（消融实验显示移除剪枝后 mIoU 不变）。

## 7. 优点

- **高效、无训练**：完全冻结 SAM 3，无需任何训练或标注，适用于快速部署和词汇动态更新的场景。
- **创新路由设计**：首次将存在头作为早期剪枝信号，而非仅用于后处理过滤，从根本上改变推理计算结构。
- **质量提升模块**：CPE 和 MABC 在不增加推理成本（仅为预计算和简单运算）的情况下系统提升分割精度。
- **鲁棒性强**：利用 SAM 3 的解码器结构，在图像扰动下保持高准确率，适合真实噪声环境。

## 8. 不足与局限
