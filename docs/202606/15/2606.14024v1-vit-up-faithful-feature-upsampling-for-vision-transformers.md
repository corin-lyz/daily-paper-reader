## 摘要
视觉Transformer已成为视觉表示学习的主流架构，能够提供异常强大且广泛可重用的骨干特征。然而，由于全局自注意力的二次成本，ViT通常操作在相对较小的补丁标记网格上，这为语义分割和深度估计等密集预测任务带来了持续瓶颈。这推动了任务无关特征上采样器的发展。尽管近期最先进方法能生成视觉锐利的密集表示，但它们依赖浅层图像编码器进行引导上采样，可能导致特征泄漏、碎片化和模糊。我们提出ViT-Up，一种隐式特征上采样框架，用来自中间ViT隐藏状态的逐层查询构建替代外部图像引导。这使得能够在任意连续图像坐标上预测特征，同时保持与骨干特征空间的对齐。实验表明，ViT-Up在密集预测和语义对应任务上持续优于最先进的图像引导上采样器。在DINOv3-S+上，ViT-Up在Cityscapes上的mIoU提升高达+2.07，在SPair-71k上的PCK@0.10提升+4.17。使用更大的DINOv3-B骨干时，这些增益分别增加到+3.36 mIoU和+8.09 PCK@0.10，表明ViT-Up随骨干容量扩展而表现更优。

## Abstract
Vision Transformers (ViTs) have become a dominant architecture for visual representation learning, providing exceptionally strong and broadly reusable backbone features. However, ViTs are commonly operated on relatively small patch-token grids due to the quadratic cost of global self-attention, which creates a persistent bottleneck for dense prediction tasks such as semantic segmentation and depth estimation. This has motivated the development of task-agnostic feature upsamplers. While recent state-of-the-art methods produce visually sharp dense representations, their reliance on shallow image encoders for guided upsampling can introduce feature leakage, fragmentation, and blur. We introduce ViT-Up, an implicit feature upsampling framework that replaces external image guidance with layer-wise query construction from intermediate ViT hidden states. This enables feature prediction at arbitrary continuous image coordinates while preserving alignment with the backbone feature space. Experiments demonstrate that ViT-Up consistently outperforms state-of-the-art image-guided upsamplers across dense prediction and semantic correspondence. On DINOv3-S+, ViT-Up improves over prior methods by up to +2.07 mIoU on Cityscapes and +4.17 PCK@0.10 on SPair-71k. With the larger DINOv3-B backbone, these gains increase to +3.36 mIoU and +8.09 PCK@0.10, demonstrating that ViT-Up scales favorably with backbone capacity.

# 论文总结：ViT-Up: Faithful Feature Upsampling for Vision Transformers

## 1. 核心问题与研究背景

-   视觉Transformer（ViT）作为强大的视觉表示骨干，其全局自注意力的二次复杂度限制了特征图的空间分辨率（如14×14或28×28）。
-   这种低分辨率特征成为语义分割、深度估计等密集预测任务的瓶颈。
-   现有任务无关特征上采样方法（如JAFAR、AnyUp、NAF、UpLiFT）多依赖浅层图像编码器提供高分辨率引导，这虽然能产生视觉锐利的特征图，但存在严重缺陷：
    -   **特征泄漏**：视觉相似但语义不同的区域被混合。
    -   **碎片化**：高频细节不稳定，不对应稳定语义区域。
    -   **模糊**：部分方法（如UpLiFT）特征平滑但丢失细节。
-   解决方案：利用ViT本身的分层结构——浅层保留高分辨率空间证据，深层整合抽象语义——从中间层隐状态直接构建密集特征，无需外部图像引导。

## 2. 方法论：ViT-Up

-   **核心思想**：将特征上采样视为坐标条件化的隐式特征预测。给定任意连续查询坐标，从多个中间层ViT隐藏状态逐步构建该坐标对应的特征向量。
-   **技术细节**：
    -   **查询嵌入（Query Embedding）**：重用ViT的patch嵌入层，对输入图像以更高分辨率（224×224 patch网格）计算，然后在查询坐标处双线性插值得到初始查询表示 \(q_0\)。
    -   **ViT-Up块（ViT-Up Block）**：\(T\)个堆叠块（默认\(T=6\)，对应层2,4,6,8,10,12），每个块依次执行：
        1.  **过渡MLP**：将之前的查询表示对齐到当前骨干层特征空间（残差更新）。
        2.  **跨窗口注意力（Cross-window MHA）**：查询与当前层的低分辨率空间token进行注意力交互，使用连续2D RoPE位置编码。
        3.  **FeatX**：从最近邻的patch token中提取子token细节。通过相对偏移编码预测FiLM参数，调制最近邻token特征，再用MLP提取。
        4.  **融合MLP**：将过渡、注意力、FeatX输出求和后经残差MLP得到更新的查询表示。
    -   **决策器**：单层MLP（LayerNorm+线性投影）将最终查询映射回ViT特征空间。
    -   **骨干适配**：采用LoRA（秩16，尺度32，dropout 0.05）对patch嵌入和注意力投影进行轻量级适应。
-   **训练策略**：
    -   **多尺度特征蒸馏**：教师网络处理同一图像在224、448、896三种分辨率下的版本（对应token网格14×14、28×28、56×56）。学生网络接收经下采样后粘贴到固定448×448画布的图像，并在可见区域密集查询56×56网格。
    -   **损失函数**：三部分损失，权重均为1：
        - 目标归一化L2损失（\( \mathcal{L}_{L2} \)）
        - 余弦相似度损失（\( \mathcal{L}_{\cos} \)）
        - 关系型KL散度损失（\( \mathcal{L}_{\text{rel}} \)），保持特征对之间的相似性结构。
    -   **训练数据**：ImageNet-1K，训练1个epoch，batch size 24，初始学习率2e-4，余弦退火。

## 7. 优点

-   **方法论创新**：将上采样从引导式token重组装转为坐标条件化的隐式解码，与ViT层级结构紧密耦合，无需外部图像引导。
-   **特征保真度高**：与骨干特征空间对齐，不产生视觉锐利但语义错误的上采样结果。
-   **训练高效**：多尺度蒸馏策略避免昂贵的高分辨率教师前向传播，仅需1个epoch的ImageNet训练。
-   **可扩展性**：随骨干容量增大性能持续提升，而基于固定浅层编码器的方法受限于引导信号的容量。
-   **灵活性**：支持任意连续坐标查询，可在运行时控制输出分辨率；查询条件独立，支持块处理以平衡内存和速度。
-   **广泛验证**：在密集预测和语义对应两个维度充分评估，并首次将对应性引入上采样评价，揭示上采样特征的内在质量。

## 8. 不足与局限

-   **信息瓶颈**：所有后置上采样方法受限于骨干隐藏状态中编码的信息。对于骨干未捕捉到的细节（如极细结构）无法完全恢复。使用更高分辨率骨干隐藏状态（如56×56）可能缓解，但需额外计算。
-   **骨干耦合**：ViT-Up需为每个骨干单独训练（过渡MLP、FeatX等与特定骨干表示耦合），不具备即插即用的零样本泛化能力。不过一旦训练好，可复用于该骨干的所有下游任务。
-   **对噪声骨干的敏感性**：在DINOv2等含有明显位置伪影的骨干上，ViT-Up直接重建了这些伪影，而图像引导方法（NAF等）通过外部图像信号可起到去伪影作用。对于质量较差的骨干，ViT-Up的表现不如引导方法。论文将其归因于“修复伪影 vs. 忠实重建”的不同目标，但实际应用中骨干质量不可控时可能受限。
-   **计算开销**：虽然内存可通过块处理控制，但ViT-Up的参数规模（约24.9M）远大于其他方法（约0.6-0.8M），推理速度在中高分辨率下慢于UpLiFT和NAF。不过，在112×112输出时已能接近最快基线速度，且性能已超越其他方法448×448的结果，实用中可选择较低输出分辨率换取效率。
-   **分辨率饱和**：输出分辨率超过224×224后性能提升趋于饱和（Cityscapes除外），说明当前架构和训练设置下无法无限恢复高频细节。
