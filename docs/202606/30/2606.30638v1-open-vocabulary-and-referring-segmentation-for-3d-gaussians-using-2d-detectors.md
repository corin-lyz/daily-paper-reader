## 摘要
3D高斯泼溅（3DGS）已成为3D场景重建的前沿技术。将3DGS与语言驱动的开放词汇理解相结合，在具身人工智能等实际应用中引起了广泛关注。现有方法通过学习实例特征属性，并直接将高维对比语言-图像预训练（CLIP）特征蒸馏到场景表示中来分配语义。然而，这些方法的实例分组机制要么需要预定义实例数量，要么在自底向上的分组策略中受到噪声影响。此外，对CLIP的依赖将语义理解限制在简单名词短语上，无法进行复杂的空间推理和指代表达式定位。我们提出GaussDet，该方法利用具有指代表达能力的离散开放词汇2D目标检测器，避免了密集CLIP特征的需求。我们为每个高斯体学习实例特征，以将场景分解为3D实例组。通过渲染这些组并聚合多视图2D检测的语义投票，我们为每个3D实例生成鲁棒的视图聚合语义标签分布（VASD）。这种视图聚合策略作为强正则化器，减弱了由低质量实例分组导致的虚假标签。我们的方法实现了从简单语言查询到复杂指代定位的直接零样本扩展。在两项关键任务——开放词汇分割（LeRF-OVS, ScanNet）和指代表达式定位（Ref-LeRF）上的广泛评估表明，GaussDet相比现有方法取得了一致的改进。最值得注意的是，在严格的零样本设置下，我们在指代定位方面实现了显著的16.7% mIoU提升。

## Abstract
3D Gaussian Splatting (3DGS) has emerged at the forefront of 3D scene reconstruction. Extending 3DGS with language-driven, open-vocabulary understanding has gained significant attention for real-world applications such as embodied AI. Recent methods achieve this by learning an instance feature attribute and assigning semantics by distilling high-dimensional Contrastive Language-Image Pretraining (CLIP) features directly into the scene representation. However, the instance grouping mechanisms of these methods either require a predefined number of instances or suffer from noise in their bottom-up grouping strategies. Furthermore, the reliance on CLIP restricts semantic understanding to simple noun phrases, preventing complex spatial reasoning and referential expression grounding. We present GaussDet, a method that circumvents the need for dense CLIP features by leveraging discrete, open-vocabulary 2D object detectors with referring expression capabilities. We learn instance features for individual Gaussians to decompose the scene into 3D instance groups. By rendering these groups and aggregating semantic votes from multi-view 2D detections, we generate a robust View-Aggregated Semantic Label Distribution (VASD) for each 3D instance. This view-aggregation strategy acts as a strong regularizer, attenuating spurious labels caused by low-quality instance grouping. Our approach enables a straightforward, zero-shot extension from simple language queries to complex referential grounding. Extensive evaluations across two key tasks -- open-vocabulary segmentation (LeRF-OVS, ScanNet) and referring expression grounding (Ref-LeRF) -- demonstrate that GaussDet achieves consistent improvements over existing methods. Most notably, we achieve a substantial 16.7% mIoU improvement in referential grounding within a strict zero-shot setting.

## 2. 论文提出的方法论

### 核心思想
- 不直接学习与CLIP对齐的高斯语义特征，而是：① 学习高斯**实例特征**进行场景分解；② 利用**开放词汇2D目标检测器**（如Qwen-VL、YOLO-World）生成每帧的离散语义标签图；③ 将每个3D实例组渲染到2D图像，通过空间投票从多视图标签图中聚合语义信息，形成**视图聚合语义标签分布（VASD）**。

### 关键技术细节
1. **实例特征学习与分组**（沿用LaGa）：
   - 每个高斯附加32维实例特征，通过SAM掩膜监督的对比学习训练，渲染为2D特征图。
   - 对所有2D掩膜的实例特征进行HDBSCAN聚类，得到3D实例组 \( \mathcal{G}_i \)。
2. **离散语义标签图生成**：
   - 使用2D开放词汇检测器（如Qwen-VL 2.5 或YOLO-World）为每帧生成边界框检测 \( B_v \)。
   - 按框的大小权重（高度+宽度）降序覆盖，生成离散标签图 \( S_v \in \mathbb{Z}^{H\times W} \)，背景像素标记为 -1（作为语义背景正则化器SBR）。
3. **3D实例组视图过滤**：
   - 将实例组 \( \mathcal{G}_i \) 渲染到所有视图，根据**不透明度阈值（0.1）**和**显著性阈值（0.2）**过滤无效高斯。
   - 计算**掩膜可见性分数** \( s_{i,v} \)（可见高斯数/总高斯数），选取前K个最佳视图 \( \mathcal{K}_i \)。
4. **VASD生成**：
   - 对每个实例组 \( \mathcal{G}_i \)，对前K视图的每个高斯，投影到图像坐标 \( \hat{P}^v_i \)，采样标签，并关联高斯显著性分数。
   - 跨K视图聚合并加权计数，得到每个语义类别c的总投票权重，形成VASD。
   - **语义背景正则化器（SBR）**：明确保留背景标签（-1），防止误将背景强制分配为前景语义，且对噪声高斯（浮游物）起到正则作用。

### 核心公式/算法流程（文字说明）
- 输入：RGB图像序列，3DGS预训练的高斯（含实例特征）。
- 输出：每个实例组的VASD。
- 步骤概览：
  1. 训练实例特征 → 2D-3D聚类得到实例组。
  2. 每帧运行2D检测器 → 生成离散标签图 \( S_v \)。
  3. 对每个实例组 \( \mathcal{G}_i \)，渲染所有视图，计算可见性分数，选择top-K视图。
  4. 对top-K视图，投影高斯坐标到 \( S_v \) 采样标签，结合显著性权重统计分布 → VASD。
- 对于开放词汇分割：将查询文本与VASD中标签的文本嵌入进行相似度比较。
- 对于指代分割：直接将指代表达式作为检测提示给2D检测器，生成标签，其余流程相同（零样本）。

## 6. 论文的主要结论与发现

1. **提出了一种** **基于2D检测器**的3D高斯语义标签分配方法GaussDet，有效规避了CLIP特征蒸馏的局限。
2. **VASD（视图聚合语义标签分布）**能够鲁棒地处理低质量实例分组导致的噪声（如误关联、欠分割、背景污染）。
3. **SBR（语义背景正则化器）**是必要组件，能显著提升性能（平均6.56% mIoU）。
4. **零样本指代分割**成为可能：GaussDet在Ref-LeRF上远超需每场景优化的ReferSplat，证明了CLIP瓶颈的解除带来的巨大潜力。
5. VASD可作为**插件模块**整合到现有方法（如OpenGaussian、LaGa）中，带来一致提升。

## 7. 优点

- **方法简洁高效**：无需学习高维CLIP特征，只需2D检测器输出的离散标签。
- **克服CLIP语义局限**：支持任意复杂语言查询（包括位置、属性指代），且零样本即用。
- **鲁棒性高**：VASD的多视图聚合天然抑制了3D分组错误和检测器偶尔的错误。
- **正交性与可迁移性**：VASD独立于底层分组方法，可即插即用。
- **性能显著**：特别是在指代分割任务上，零样本提升16.7% mIoU，极具实用价值。
- **实验充分**：在多个benchmark上验证，消融齐全。

## 8. 不足与局限

- **依赖2D检测器性能**：空间/位置推理能力受限于所用2D检测器（Qwen-VL/YOLO-World）的质量，对密集场景、小目标可能漏检或误检。
- **依赖现有3D分组机制**：底层实例分组（来自LaGa/HDBSCAN）仍可能产生错误，这些错误会传播到语义分配（尽管VASD可缓解）。
- **计算开销**：需要为每帧运行2D检测器（尤其是大模型Qwen-VL），且需渲染所有实例组到所有视图以计算可见性分数（但文中称标签图可预计算，代价可接受）。
