## 摘要
预训练的视觉基础模型因其强大的语义表示和泛化能力已成为现代计算机视觉的核心。然而，其分块化或池化输出本质上为低分辨率，限制了在需要细粒度像素级推理任务中的有效性。现有特征上采样方法要么降低语义保真度，要么依赖特定基础模型的重新训练和重型架构，阻碍了效率和可扩展性。为应对这些挑战，我们提出RaysUp，一个超轻量、任务无关且基础模型无关的特征上采样框架，能够以任意分辨率重建高分辨率特征图。与传统的二维插值或基于注意力的方案不同，RaysUp将特征重建提升至几何感知的射线域。具体而言，我们引入空间解耦引导编码器用于方向感知引导编码，任意分辨率交叉注意力机制用于灵活重建，以及新颖的射线位置编码通过6D Plücker射线坐标注入隐式三维几何先验。最后，几何感知邻域注意力模块在保持几何一致性的同时确保内容自适应双边聚合。在多种密集预测任务上的广泛实验表明，RaysUp在使用仅AnyUp的16%参数且推理速度约快7倍的情况下，实现了最先进的性能。这些结果显著改善了准确率与效率的权衡，并使RaysUp成为通用特征上采样的实用且可扩展的解决方案。代码可在https://github.com/MAP-RaysUp/RaysUp获取。

## Abstract
Pre-trained Vision Foundation Models (VFMs) have become central to modern computer vision due to their powerful semantic representations and strong generalization ability. However, their patchified or pooled outputs are inherently low-resolution, limiting their effectiveness in tasks requiring fine-grained, pixel-level reasoning. Existing feature upsampling approaches either degrade semantic fidelity or rely on VFM-specific retraining and heavy architectures, hindering efficiency and scalability. To address these challenges, we propose RaysUp, an ultra-lightweight, task-agnostic, and VFM-agnostic feature upsampling framework that reconstructs high-resolution feature maps at arbitrary resolutions. Unlike conventional 2D interpolation or attention-based schemes, RaysUp lifts feature reconstruction into a geometry-aware ray domain. Specifically, we introduce a Spatially Decoupled Guidance Encoder for direction-aware guidance encoding, an Any-Resolution Cross-Attention mechanism for resolution-flexible reconstruction, and a novel Ray Positional Encoding (RayPE) that injects implicit 3D geometric priors via 6D Plucker ray coordinates. Finally, a Geometry-Aware Neighborhood Attention module further ensures content-adaptive bilateral aggregation while preserving geometric consistency. Extensive experiments across diverse dense prediction tasks demonstrate that RaysUp achieves state-of-the-art performance while using only 16% of the parameters of AnyUp and delivering approximately 7x faster inference. These results highlight a substantially improved accuracy-efficiency trade-off and establish RaysUp as a practical and scalable solution for universal feature upsampling. Code is available at https://github.com/MAP-RaysUp/RaysUp.

## 论文提出的方法论

### 核心思想
将特征重建从传统2D图像空间提升至**几何感知的射线域**，通过关联每个像素对应的三维相机射线来指导上采样，从而实现几何一致性。

### 关键技术细节
1. **轻量空间解耦引导编码器（Spatially Decoupled Guidance Encoder）**
   - 将标准3×3卷积分解为四个并行分支：1×1（中心）、1×3（水平）、3×1（垂直）、2×2空洞卷积（对角），各分支输出通道为Dg/4。
   - 每个分支采用GN+SiLU+残差结构，最后拼接得到引导特征Fg。
   - 参数量仅为标准3×3卷积的约30.6%（8.25Dg vs 27Dg），且能更好捕捉各向异性空间结构。

2. **任意分辨率交叉注意力机制（Any-Resolution Cross-Attention）**
   - 对引导特征Fg分别进行自适应平均池化，生成高分辨率query Qg（目标分辨率）和低分辨率key Kg（VFM分辨率）。
   - Value V直接取自VFM输出的低分辨率特征Flr。
   - 支持任意目标分辨率重建，无需显式插值。

3. **射线位置编码（RayPE）**
   - 对每个像素，利用相机内参M和外参[R|t]计算6D Plücker射线描述符 r = [o, d]（相机原点+归一化方向）。
   - 多频带谐波相位编码：构造log-spaced频率集{ωf}，计算旋转相位θf,d = ωf·r_d，展平为6N维向量。
   - 旋转调制：将每个注意力头的特征分为两半，按RoPE方式应用旋转矩阵（cosθ, sinθ），得到几何感知的ray特征Qray和Kray。
   - RayPE将位置编码从2D图像网格扩展到单位视球面，使注意力机制建模角度一致性而非像素距离一致性。

4. **几何感知邻域交叉注意力（Geometry-Aware Neighborhood Cross-Attention）**
   - 每个高分辨率query仅聚合低分辨率特征中对应位置周围k×k邻域内的key与value。
   - 使用膨胀因子（dh, dw）自动适配分辨率差异，确保在射线流形上进行局部一致的采样。
   - 局部注意力降低复杂度至O(H_any W_any·k²)，同时保持几何一致性。

### 流程简述
输入RGB图像I和低分辨率VFM特征Flr → 通过空间解耦引导编码器得到Fg → 自适应池化生成Qg和Kg → 经RayPE处理为Qray和Kray → 几何感知邻域交叉注意力以Flr为value，聚合得到高分辨率特征Fhr。

## 主要结论与发现

- RaysUp在多种密集预测任务上达到SOTA或近似最优性能，尤其在几何预测（深度、法线）和视频分割上优势明显。
- 仅用0.14M参数（AnyUp的16%），推理速度提升约7倍，GPU内存大幅降低（224×224时1.26GB vs AnyUp 2.19GB）。
- 即使没有额外分割监督，RaysUp保持高语义保真度，且边界清晰、几何一致。
- 训练仅需1小时，易于部署。

## 优点

1. **创新性强**：首次将NeRF风格的射线几何引入特征上采样，通过RayPE注入隐式3D先验，克服了2D空间假设的局限。
2. **超轻量高效**：空间解耦编码器+局部注意力实现极致参数量和速度优势。
3. **通用性高**：任务无关与VFM无关，单一模型可处理多种骨干和任意分辨率。
4. **实验充分**：覆盖多种任务、骨干、指标，消融研究全面，对比方法丰富。
5. **代码开源**，可复现。

## 不足与局限

1. **依赖相机参数**：RayPE需要相机内参和外参（或简化假设），在没有pose信息的场景（如互联网图片）需额外估计，可能引入误差或限制应用范围。
2. **静态假设**：仅处理单帧图像，未考虑视频时序连续性；虽在DAVIS上评估，但方法本质非时序建模。
3. **训练数据单一**：仅在ImageNet上训练，对特定域（医学、遥感）的泛化能力未验证。
4. **部分指标略逊于LoftUp**：在语义分割和开放词汇任务中LoftUp有时更好（因其使用了SAM掩码辅助训练），RaysUp未采用类似辅助监督。
5. **没有评估实时性**：虽然FPS优于对比方法，但未给出在边缘设备上的性能。
6. **定性结果中**：某些情况下仅基于视觉好于Ground Truth（如附录图8、9），主观性强。
