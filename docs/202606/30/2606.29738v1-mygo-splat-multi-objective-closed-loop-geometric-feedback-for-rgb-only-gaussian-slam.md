## 摘要
实时单目同时定位与地图构建（SLAM）本质上存在尺度模糊性和缺乏几何自校正的问题。尽管3D高斯溅射（3DGS）能够实现高保真渲染，但现有的仅RGB系统仍处于开环状态，因为深度先验被注入到建图中，而精化的几何无法有效调节跟踪漂移。我们提出MyGO-Splat，一种闭环高斯SLAM框架，通过解析地将高斯原语光栅化为像素级深度和表面法线，使地图能够主动监督相机位姿优化。为桥接单目先验与尺度一致性，我们的框架引入了尺度感知自适应对齐，将基础模型深度估计投影到全局优化的高斯空间中，形成尺度反馈的自校正循环。大量评估表明，这种闭环设计提升了尺度稳定性及外观-几何一致性，在使用仅单目输入的情况下实现了与RGB-D方法相当的性能。

## Abstract
Real-time monocular Simultaneous Localization and Mapping (SLAM) fundamentally suffers from scale ambiguity and a lack of geometric self-correction. While 3D Gaussian Splatting (3DGS) enables high-fidelity rendering, existing RGB-only systems remain open-loop because depth priors are injected into mapping but refined geometry cannot effectively regulate tracking drift. We present MyGO-Splat, a closed-loop Gaussian SLAM framework that analytically rasterizes Gaussian primitives into pixel-wise depth and surface normals, allowing the map to actively supervise camera pose optimization. To bridge monocular priors and scale consistency, our framework introduces scale-aware adaptive alignment that projects foundation-model depth estimates into the globally optimized Gaussian space, forming a self-correcting cycle for scale feedback. Extensive evaluations show that this closed-loop design improves scale stability and appearance-geometry consistency, achieving performance comparable to RGB-D methods while using only monocular input.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：实时单目（RGB-only）SLAM 系统存在固有的**尺度模糊性**和**几何自校正缺失**。虽然3D高斯溅射（3DGS）能实现高保真渲染，但现有RGB-only高斯SLAM系统本质上是**开环的**：深度先验（如单目深度估计网络输出）被注入建图模块，但优化后的高斯几何无法有效反馈到跟踪模块以纠正跟踪漂移。这使得系统无法实现可靠的几何自校正，长期运行中尺度漂移和深度失真难以消除。

- **研究动机**：解决开环结构导致的尺度不稳定和外观-几何不一致问题；使高斯地图从被动的渲染器升级为能够主动监督跟踪的几何组件；在**仅使用单目RGB输入**的情况下，达到接近RGB-D SLAM的性能。

- **整体含义**：MyGO-Splat 提出了一种**闭环几何反馈**框架，通过解析可微分光栅化从高斯原语导出像素深度和法线，并利用尺度感知自适应对齐将基础模型（VGGT）的单目深度先验投影到全局一致的高斯空间，形成自校正循环。这项工作证明了闭环设计对单目高斯SLAM的有效性，为低成本、高精度的视觉SLAM提供了新思路。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 构建**双向几何反馈回路**：跟踪模块不仅从地图获取深度先验，地图的几何（渲染深度）也主动参与跟踪优化，替代不稳定、单帧的伪深度，逐步抑制尺度漂移。
- 将高斯地图从仅用于渲染的表示转化为**几何表达性强且可优化的场景表示**，通过解析计算深度和法线，支持几何增强的多目标优化。

### 关键技术细节

1. **在线跟踪（Online Tracking）**
   - 使用基于循环光流网络的方法（Droid-SLAM框架）进行位姿估计，构建关键帧图，通过重投影误差联合优化位姿和深度。
   - 引入视觉相似性检测的**闭环模块**（使用EigenPlaces特征+FAISS数据库），当检测到高置信度闭环时执行全局BA，实现长轨迹的全局一致性与尺度校正。

2. **闭环几何反馈（Closed-Loop Geometric Feedback）**
   - **几何先验生成**：使用3D视觉基础模型VGGT从稀疏图像对快速生成点云和深度，但仅保留深度信息用于引导。
   - **不确定性加权度量同步**：将VGGT生成的深度图与当前高斯地图渲染的深度进行对齐，求解最优尺度λ和偏移τ（最小二乘，加权置信度ω_p），将外部位姿先验投影到SLAM系统的度量空间。对齐后的深度被反馈至全局BA替代原始噪声深度，形成自校正循环。

3. **基于光栅化高斯几何的建图**
   - **光栅化像素深度**：不同于标准3DGS仅用高斯中心投影近似像素深度，本文采用解析公式（基于局部仿射投影下的共面性质）直接计算每个像素的精确深度d = z₀ + p̂ᵀ[u₀–u, v₀–v]ᵀ，提升深度连续性与精度。
   - **表面解析法线**：在光线空间中利用平面方程计算法线n_ray，再通过雅可比矩阵变换回相机坐标系n_cam，提供几何监督。
   - **几何增强的多目标优化**：联合优化外观损失L_rgb、渲染深度与对齐深度之间的L1损失L_d、深度不一致正则项L_dis（减少同一光线上的高斯伪影）、以及解析法线与先验法线的一致性损失L_n。总损失：L = λ_rgb L_rgb + λ_d L_d + λ_dis L_dis + λ_n L_n。

4. **系统流程**：输入单目RGB视频 → 前端流跟踪 → 闭环检测与全局BA → 高斯地图渲染深度/法线 → 对齐基础模型深度 → 反馈深度至跟踪优化 → 多目标优化更新高斯参数 → 闭环循环。

## 6. 主要结论与发现

- **定位精度**：在所有数据集中，MyGO-Splat在RGB-only方法中达到**最优或接近最优的ATE**（Replica: 0.26 cm, TUM: 1.14 cm, ScanNet: 7.22 cm），性能接近RGB-D方法，显著优于其他RGB-only方法（如MonoGS在ScanNet上ATE达105.6 cm）。
- **渲染质量**：PSNR、SSIM、LPIPS均达到RGB-only SOTA，在多个序列上超过RGB-D方法（Replica PSNR 38.33 dB最高）。
- **几何重建**：在Replica上精度1.54 cm、完成度3.69 cm，优于所有对比方法；提取的网格细节更完整。
- **消融实验证实**：
  - 移除闭环导致ATE上升（0.26→0.45 cm），证明全局一致性对长序列重要。
  - 移除CLG反馈导致ATE大幅上升至0.58 cm、PSNR下降至35.12 dB，且地图出现浮动伪影，证明几何反馈对尺度抑制和外观重建至关重要。
  - 移除GEMO优化导致几何精度严重退化（Acc. 5.42 cm, Comp. 9.85 cm），法线/深度图变得扭曲，证明几何正则化显著提升表面质量。

## 7. 优点

- **方法创新性**：首次在RGB-only高斯SLAM中构建**闭环几何反馈**，将高斯地图从被动渲染器变为主动几何监督者，解决了长期存在尺度漂移难题。
- **解析光栅化**：不同于传统近似，推导了高斯原语的解析深度/法线公式，提高了几何精度，且保持可微性。
- **高效集成**：巧妙结合基础模型先验（VGGT）与传统BA框架，利用不确定性加权对齐，既获得强先验又保持度量一致性。
- **性能卓越**：仅用RGB达到与RGB-D方法几乎相同的定位和重建质量，在PSNR等指标上甚至超越部分RGB-D方法，且保持实时（>5 FPS）。
- **消融充分**：三个主要贡献点均有独立验证，定性和定量相结合，论证有力。
