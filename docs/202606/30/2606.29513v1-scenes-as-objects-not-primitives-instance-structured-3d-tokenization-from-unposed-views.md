## 摘要
一个3D场景是通过其物体来理解的，而非构成它们的基元。然而，前馈重建方法输出的是密集、无结构的点或高斯集合，物体级结构需事后恢复。我们提出了一种前馈框架，直接从无位姿的多视图图像中将场景分解为实例结构化的3D令牌组——紧凑的以物体为中心的单元，重建、分割和操作均由此衍生。每个令牌组将一个捕获实体级身份的实例令牌与编码局部几何和外观的锚点令牌配对，这些令牌被解码为一组3D高斯。这种双层分解将物体身份与局部外观解耦，使得物体实例成为表示的原生接口而非派生产物。令牌组通过可微渲染学习，联合重建和分割监督，无需3D标注。我们的前馈模型在与类别无关的实例分割上超越了每场景优化基线，同时在新型视图合成上保持竞争力。超越这些指标，相同的令牌组直接实现了实例级场景编辑——通过对物体组进行操作进行移除、平移或插入物体——以及高效的开词汇3D实例检索，其中检索复杂度随实例数量而非基元数量扩展。

## Abstract
A 3D scene is understood through its objects, not the primitives that compose them. Yet feed-forward reconstruction methods output dense, unstructured sets of points or Gaussians, leaving object-level structure to be recovered after the fact. We propose a feed-forward framework that decomposes a scene into instance-structured 3D token groups directly from unposed multi-view images -- compact object-centric units from which reconstruction, segmentation, and manipulation all follow. Each token group pairs an instance token capturing entity-level identity with anchor tokens that encode local geometry and appearance, which are decoded into a set of 3D Gaussians. This two-level factorization decouples object identity from local appearance, making object instances a native interface of the representation rather than a derived product. The token groups are learned through differentiable rendering with joint reconstruction and segmentation supervision, requiring no 3D annotations. Our feed-forward model surpasses per-scene optimization baselines in class-agnostic instance segmentation while remaining competitive in novel view synthesis. Beyond these metrics, the same token groups directly unlock instance-level scene editing -- removing, translating, or inserting objects by operating on their groups -- as well as efficient open-vocabulary 3D instance retrieval, where retrieval complexity scales with the number of instances rather than primitives.

## 1. 核心问题与整体含义（研究动机和背景）
现有前馈3D重建方法（如3D高斯泼溅）输出的是**密集、无结构的点或高斯基元**，缺乏物体级结构。尽管后续可附加语义特征，但物体级信息仍分散在众多基元中，任何基于物体的操作（查询、编辑、推理）都需要事后分组或聚合。作者认为这是**表示层面的不匹配**：基元是局部几何碎片，无法提供实体级上下文。为此，本文提出直接从无位姿多视图图像中**将场景分解为实例结构化的3D令牌组**，使物体实例成为表示的**原生接口**，而非派生产物，从而自然支持重建、分割、编辑和检索。

## 2. 方法论
- **核心思想**：采用双层分解——每个令牌组包含一个**实例令牌**（捕获实体级身份）和多个**锚点令牌**（编码局部几何和外观），锚点令牌解码为一组3D高斯。实例令牌与锚点令牌之间的软分配通过竞争机制（softmax）实现。
- **关键技术细节**：
  - 使用冻结的3D基础模型(VGGT)提取多视图特征和点图，融合后作为上下文令牌。
  - **图像-锚点变换器(D_anchor)**：锚点令牌通过交叉注意力从上下文令牌中更新。
  - **锚点-分组变换器(D_group)**：分组令牌通过交叉注意力从锚点令牌中更新，分组令牌作为集群查询，通过softmax竞争锚点所有权。
  - 锚点令牌经MLP解码为多个3D高斯（位置偏移、尺度、旋转、不透明度、球谐），每个高斯继承父锚点的分配分数。
  - 训练通过**可微渲染**联合监督：RGB损失（MSE + LPIPS）驱动锚点令牌；2D实例掩码损失（匈牙利匹配 + BCE + Dice损失）驱动分组令牌。无需3D标注。
  - **分解式语义特征蒸馏**：每个组存储一个共享的组级嵌入（D=512），锚点级残差（d=8）捕获局部细节，极大压缩存储（从百万标量降至约6万）。

## 6. 主要结论与发现
- 前馈模型在**类无关实例分割**上**超越所有逐场景优化基线**（AP=0.235，远超Gaussian Grouping的0.139和ObjectGS的0.178），表明原生实例结构是比事后分组更强的归纳偏置。
- 重建质量虽有竞争力，但略逊于密集基元方法（PSNR 25.28 vs Uni3R 25.53），这是紧凑表示的设计取舍。
- **语义特征提升**取得最佳mIoU（0.657），且存储开销极低（59.4K标量 vs Uni3R的8.4M）。
- 令牌组直接支持**实例级场景编辑**（移除、变换、插入）和**开放词汇3D实例检索**，无需后处理。
- 消融实验表明：联合训练和warm-up对实例结构学习至关重要；组级特征加上少量锚点残差已能达到最优。

## 7. 优点
- **表示创新**：将物体实例作为第一类单位，实现原生解耦。
- **无需3D标注**：仅需2D RGB和实例掩码监督，可扩展性强。
- **多任务统一**：重建、分割、编辑、检索均基于同一表示，无需额外模块。
- **极高效的语义存储**：通过组级+低维残差分解，将语义存储从百万级降至万级，实现数量级压缩。
- **编辑与检索操作直接**：无需后处理或额外优化，推理即得。

## 8. 不足与局限
- **场景范围有限**：主要在有界室内场景评估，室外和大规模场景（如城市级）未验证，固定L=100上限可能不适用。
- **重建精度略低**：紧凑表示导致高频细节略有损失，与密集方法有差距。
- **静态场景假设**：不支持动态物体，限制机器人等应用。
- **高遮挡/接触物体**：编辑效果在重遮挡或物体接触时未充分评估。
- **实例token表达能力**：单一组级共享token对复杂多变实例可能不足，需多语义token扩展。
- **无位姿输入依赖预训练基础模型**：VGGT的误差会传播到后续token化。
