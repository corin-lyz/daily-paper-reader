## 摘要
预训练的视觉基础模型（VFMs）因其强大的语义表示和强泛化能力已成为现代计算机视觉的核心。然而，其分块或池化输出本质上为低分辨率，限制了其在需要细粒度像素级推理的任务中的有效性。现有的特征上采样方法要么降低语义保真度，要么依赖于特定VFMs的重新训练和重型架构，阻碍了效率和可扩展性。针对这些挑战，我们提出RaysUp，一个超轻量、任务无关且与VFM无关的特征上采样框架，能够以任意分辨率重建高分辨率特征图。与传统的2D插值或基于注意力的方案不同，RaysUp将特征重建提升到几何感知的光线域中。具体来说，我们引入了一个空间解耦引导编码器用于方向感知的引导编码，一种任意分辨率交叉注意力机制用于分辨率灵活的重建，以及一种新颖的光线位置编码（RayPE），通过6D Plücker光线坐标注入隐式3D几何先验。最后，一个几何感知邻域注意力模块在保持几何一致性的同时进一步确保内容自适应双边聚合。在多种密集预测任务上的大量实验表明，RaysUp仅使用AnyUp参数量的16%即可实现最先进的性能，推理速度提升约7倍。这些结果突显了显著改善的精度-效率权衡，并将RaysUp确立为通用特征上采样的实用且可扩展的解决方案。代码可在https://github.com/MAP-RaysUp/RaysUp获取。

## Abstract
Pre-trained Vision Foundation Models (VFMs) have become central to modern computer vision due to their powerful semantic representations and strong generalization ability. However, their patchified or pooled outputs are inherently low-resolution, limiting their effectiveness in tasks requiring fine-grained, pixel-level reasoning. Existing feature upsampling approaches either degrade semantic fidelity or rely on VFM-specific retraining and heavy architectures, hindering efficiency and scalability. To address these challenges, we propose RaysUp, an ultra-lightweight, task-agnostic, and VFM-agnostic feature upsampling framework that reconstructs high-resolution feature maps at arbitrary resolutions. Unlike conventional 2D interpolation or attention-based schemes, RaysUp lifts feature reconstruction into a geometry-aware ray domain. Specifically, we introduce a Spatially Decoupled Guidance Encoder for direction-aware guidance encoding, an Any-Resolution Cross-Attention mechanism for resolution-flexible reconstruction, and a novel Ray Positional Encoding (RayPE) that injects implicit 3D geometric priors via 6D Plucker ray coordinates. Finally, a Geometry-Aware Neighborhood Attention module further ensures content-adaptive bilateral aggregation while preserving geometric consistency. Extensive experiments across diverse dense prediction tasks demonstrate that RaysUp achieves state-of-the-art performance while using only 16% of the parameters of AnyUp and delivering approximately 7x faster inference. These results highlight a substantially improved accuracy-efficiency trade-off and establish RaysUp as a practical and scalable solution for universal feature upsampling. Code is available at https://github.com/MAP-RaysUp/RaysUp.

# RaysUp 论文总结

## 1. 核心问题与整体含义（研究动机和背景）

预训练的视觉基础模型（VFM），如 DINO、CLIP、SigLIP、MAE 等，在计算机视觉中广泛使用，但它们的输出特征图经过 patch 化或池化后空间分辨率很低（例如 16×16 或 32×32），严重限制了它们在细粒度密集预测任务（如语义分割、深度估计、表面法线估计、视频目标分割等）中的有效性。现有的特征上采样方法存在两个主要问题：传统插值（如双线性）虽然高效但丢失语义信息；基于学习的方法（如 FeatUp、LoftUp、JAFAR）虽然能提升质量，但通常需要针对不同 VFM 重新训练或采用重型架构，导致效率低、可扩展性差。为此，论文提出 **RaysUp**，一个**超轻量、任务无关、VFM 无关**的通用特征上采样框架，能在任意分辨率下重建高分辨率特征图，同时保持语义保真和几何一致性。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
RaysUp 将特征重建从传统 2D 图像空间提升到**几何感知的光线域**，利用 3D 相机射线作为隐式几何先验，引导高分辨率特征的重建。整体框架基于经典的联合双边上采样（JBU）范式，但对其进行了全面推广：引入方向感知的引导编码、任意分辨率交叉注意力、射线位置编码（RayPE）和几何感知邻域注意力。

### 关键技术细节

- **空间解耦引导编码器（Spatially Decoupled Guidance Encoder）**  
  将标准 3×3 卷积分解为四个并行分支：1×1（中心）、1×3（水平）、3×1（垂直）和 2×2 空洞卷积（对角线）。每个分支输出 Dg/4 通道，经 GroupNorm 和 SiLU 激活后残差连接，最后拼接得到引导特征 Fg ∈ R^{Dg×Hin×Win}。这种设计相比标准 3×3 卷积，参数量减少约 69.4%，同时增强了各向异性的空间建模能力。

- **任意分辨率交叉注意力（Any-Resolution Cross-Attention）**  
  基于引导特征 Fg，通过自适应平均池化在目标分辨率 Hany×Wany 上生成查询 Qg，在 VFM 低分辨率 Hlr×Wlr 上生成键 Kg，而值 V 直接取自 VFM 的低分辨特征 Flr。这样能灵活实现跨分辨率特征传播，无需显式插值。

- **射线位置编码（RayPE）**  
  受 NeRF 启发，将每个像素关联到一条 3D 射线 r = (o, d)，其中 o 为相机原点，d 为归一化方向。通过 6D Plücker 坐标表示射线，采用多频带谐波编码（log-spaced 频率）将射线参数投影到高维相位空间，然后利用旋转矩阵对注意力头中的特征进行调制（类似 RoPE 但扩展到 3D 几何位置）。这样隐式注入了几何先验，使注意力计算在光线方向空间上进行，而非简单像素平面距离。

- **几何感知邻域注意力（Geometry-Aware Neighborhood Cross-Attention）**  
  为平衡效率与几何一致性，每个高分辨率查询只与低分辨率特征中对应局部邻域（k×k）进行交叉注意力，并根据分辨率比设置膨胀因子。注意力权重计算在经 RayPE 编码的 Qray 和 Kray 上执行，值 V 为原始 VFM 特征。这既保持了 JBU 的局部性，又具有内容自适应能力。

- **训练目标**  
  使用余弦相似度损失和 L2 距离损失组合，监督重建特征与目标高分辨率特征（从原始高分辨率图像提取）的一致性。

## 7. 优点

1. **超轻量高效**：仅 0.14M 参数，推理速度快，适合资源受限场景。
2. **任务/模型无关**：单一训练即可泛化到不同 VFM、不同下游任务、任意分辨率。
3. **几何感知**：首次将 3D 射线表示引入特征上采样，有效解决 2D 插值导致的几何失真。
4. **设计创新**：空间解耦引导编码器、RayPE 旋转调制、局部交叉注意力联合设计，精度-效率权衡优异。
