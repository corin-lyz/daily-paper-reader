## 摘要
目标检测与实例分割任务密切相关。现有的自上而下实例分割方法通常遵循先检测后分割的范式：首先使用初始检测器通过边界框识别并定位物体，随后在每个边界框内分割实例掩膜。在此类方法中，检测精度直接影响后续分割性能。然而，此前研究鲜有探讨实例分割任务对目标检测的反向影响。本文针对自上而下方法提出一种涡轮推理策略，通过迭代方式利用检测与分割任务间的互补信息。具体而言，我们设计了两个模块：涡轮检测头与涡轮分割头，以促进任务间信息交互。这两个模块构成闭环，可在无需重新训练模型的情况下交织检测与分割结果。在COCO、iFLYTEK和Cityscapes数据集上的综合实验表明，本方法在计算开销有所增加的情况下显著提升了检测与分割精度。所提方法体现了预测精度与推理速度之间的权衡。代码开源于https://github.com/zhaozhen2333/Turbo-Learning.git。

## Abstract
Object detection and instance segmentation tasks are closely related. Existing top-down instance segmentation methods usually follow a detect-then-segment paradigm, where an initial detector is used to recognize and localize objects with bounding boxes, followed by the segmentation of an instance mask within each bounding box. In such methods, the detection accuracy directly influences the subsequent segmentation performance. However, previous research has seldom explored the impact of the instance segmentation task on object detection. In this paper, we present a turbo-inference strategy for the top-down methods that leverages the complementary information between detection and segmentation tasks iteratively. Specifically we design two modules: turbo-detection head and turbo-segmentation head, which facilitate communication between the tasks. The two modules form a closed loop that interlaces the detection and segmentation results without retraining the model. Comprehensive experiments on the COCO, iFLYTEK, and Cityscapes datasets demonstrate that our method substantially enhances both detection and segmentation accuracies with a certain increase in computational cost. The proposed method represents a tradeoff between prediction accuracy and inference speed. Codes are available at https://github.com/zhaozhen2333/Turbo-Learning.git.

## 1. 核心问题与整体含义（研究动机和背景）
- **核心问题**：在自上而下（top-down）的实例分割方法（如 Mask R-CNN）中，检测任务（边界框和分类分数）直接影响后续分割性能，但分割任务产生的像素级掩膜信息未被充分利用来反向优化检测结果（如边界框不够精确、分类分数与掩膜质量不匹配）。现有方法缺少检测与分割之间的双向反馈机制。
- **研究动机**：通过建立检测与分割任务的闭环交互，在不重新训练模型的情况下，利用下游分割任务的信息提升上游检测任务的精度，从而实现整体性能增益。
- **整体含义**：提出一种无需训练的推理阶段策略（turbo-inference），通过迭代交换任务信息，在牺牲一定推理速度的前提下显著提升检测和分割的准确率，属于精度与速度的权衡方案。

## 2. 方法论
### 核心思想
- 在推理阶段引入两个新模块：**turbo-detection head** 和 **turbo-segmentation head**，构成闭环迭代流程。将原始的 detect-then-segment 两阶段流水线扩展为多阶段流水线：检测 -> 分割 -> 优化检测 -> 优化分割 -> ... ，可重复多次。
- 具体流程（以 Mask R-CNN 为例）：
  1. **Stage 1**（原始检测头）：输出边界框 B 和分类分数 S。
  2. **Stage 2**（原始分割头）：基于 B 预测粗掩膜 M。
  3. **Stage 3**（turbo-detection head）：包含两个子模块：
     - **Box refinement**：利用预测掩膜 M 通过双线性插值映射回原图，以阈值 S_B=0.23 二值化，然后计算前景像素的坐标极值得到更紧致的边界框 B_ref。
     - **Maskness**：根据掩膜置信度的不确定性计算不确定性分数 U_mask 和 U_bbox，并与分类分数相乘，得到新的分类分数 S_ref，用于过滤低质量冗余框（公式：U_mask = Σ (B_i>0)*M_i / Σ B_i；U_bbox = (1+U_mask)^2）。
  4. **Stage 4**（turbo-segmentation head）：使用与原始分割头共享权重的网络，基于 B_ref 提取新的 RoI 特征，预测更精细的掩膜 M_ref。
  5. 可重复 Stage 3 和 Stage 4 多次（例如 Stage 5、6）。
- **关键设计**：整个流程无需重新训练，仅修改推理阶段；可与 Soft NMS 结合获得额外增益。

## 6. 主要结论与发现
- Turbo-inference 策略在几乎所有配置下均能提升检测 AP 和分割 AP，提升幅度随骨干变强略有减小。
- 对于 Mask R-CNN（R50-FPN），提升约 +1.1% box AP、+1.3% mask AP；对于 QueryInst，提升约 +0.8% box AP、+1.2% mask AP。
- 引入更多推理阶段可进一步提升性能，但边际收益递减（超过4阶段后增益很小），且推理速度下降。
- Box refinement 主要提升定位精度（box AP），Maskness 主要提升分类分数与掩膜质量匹配（mask AP），两者组合效果更佳。
- 与 Soft NMS 可叠加提升，进一步增加 box AP 但 mask AP 变化不大。
- 在 Cityscapes 和 iFLYTEK 上取得一致增益，说明方法跨场景有效。

## 7. 优点
- **训练无关（training-free）**：无需重新训练模型，可直接应用于预训练好的 top-down 方法，实用性强。
- **简洁有效**：仅需在推理阶段增加少量计算（双线性插值、二值化、不确定性计算），实现显著性能提升。
- **模块化设计**：Box refinement 和 Maskness 可单独使用，也可组合；阶段数可调节，适应不同精度-速度需求。
- **广泛兼容**：适用于多种骨干和多种检测-分割框架（包括 query-based 的 QueryInst）。
- **可视化明确**：图1、图4展示定性结果，直观显示边界框收紧和冗余框去除。

## 8. 不足与局限
- **仅适用于 top-down 方法**：无法用于 bottom-up 方法（如 SOLO、YOLACT）。
- **推理速度下降**：每增加一轮 turbo 阶段，FPS 降低约20%~30%（例如 Mask R-CNN R50 从15.7降至12.0）。对于实时应用可能影响较大。
- **QueryInst 性能退化**：当 stage 数超过3时，mask AP 反而下降，作者解释为动态卷积的交互过程受到干扰，表明方法对某些特定架构的适应性有限。
- **小物体检测退化**：在 COCO 上，采用 turbo-inference 后 AP_S（小物体）在部分实验中有下降（如 Mask R-CNN R50 AP_mS 从19.1降至17.2），原因可能是阈值设置为0.23导致小物体被过度裁剪。
- **超参数固定**：Box refinement 阈值 S_B=0.23 和 Maskness 阈值 S_M=0.5/0.2 是在 COCO 上手工确定的，未说明是否对其他数据集最优，可能存在过拟合风险。
- **未分析训练阶段的影响**：虽然推理阶段训练无关，但训练好的模型本身可能已经包含隐式反馈（如 Cascade R-CNN），turbo-inference 的提升是否完全来自推理阶段的后处理而非模型缺陷，存疑。作者未对比训练时引入类似机制的 baseline。
- **数据集偏见**：iFLYTEK 为私有单类别遥感数据集，结果复制性受限。
