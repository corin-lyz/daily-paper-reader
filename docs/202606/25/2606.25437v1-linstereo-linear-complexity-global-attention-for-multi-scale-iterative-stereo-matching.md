## 摘要
现有的基于视觉基础模型（VFM）的迭代立体流水线未能充分利用三条信息通路：多尺度骨干特征被压缩成单层相关性，几何先验在初始化时未被利用，上下文仅局部传播。这些缺陷在光度线索退化时更加明显，使得水下场景成为严格的泛化测试。为解决此问题，我们提出LinStereo，它基于Depth Anything V3，其核心是位置感知线性注意力（PALA）模块，该模块以线性成本用全局聚合替代局部循环，将可靠估计从匹配良好的区域传播到退化区域，同时保持视差结构。PALA通过两个赋能组件实现高效：层级语义代价体（HSCV），从VFM特征层级提供尺度对齐的相关性；以及深度先验初始化（DPI），将单目深度转换为度量校准的热启动。LinStereo在标准基准上实现了最先进的精度和强大的跨域泛化能力，特别是在水下场景中，严重的光度退化使立体匹配极具挑战性，在TartanAir-UW上取得了最佳整体精度，AbsRel一致降低28%，在真实水下数据集SQUID上降低26%。

## Abstract
Existing Vision Foundation Model (VFM)-based iterative stereo pipelines under-exploit three information pathways: multi-scale backbone features are collapsed into single-level correlations, geometric priors remain untapped at initialization, and context propagates only locally. These gaps widen under degraded photometric cues, making underwater scenes a stringent generalization test. To address this, we propose LinStereo, built upon Depth Anything V3, whose core is a Position-Aware Linear Attention (PALA) module that replaces local recurrence with global aggregation at linear cost, propagating reliable estimates from well-matched regions into degraded areas while preserving disparity structure. PALA is made effective by two enabling components: Hierarchical Semantic Cost Volumes (HSCV), which supply scale-aligned correlations from the VFM feature hierarchy, and a Depth Prior Initialization (DPI) that converts monocular depth into a metrically calibrated warm start. LinStereo achieves state-of-the-art-level accuracy on standard benchmarks and strong cross-domain generalization, particularly on underwater scene where severe photometric degradation makes stereo matching particularly challenging, attaining the best overall accuracy with consistent gains 28% lower AbsRel on TartanAir-UW, 26% on SQUID, a real-world underwater dataset).

## 1. 核心问题与整体含义（研究动机与背景）

- **研究对象**：基于迭代细化的立体匹配（Stereo Matching），特别是使用视觉基础模型（VFM，如 Depth Anything V3）作为骨干的管线。
- **现有瓶颈**：即使采用了强大的 VFM 骨干，迭代更新机制仍存在三条信息通路未被充分利用：
    1. 多尺度骨干特征被压缩为单层相关性，丢失层级语义；
    2. 几何先验（如单目深度估计）在初始化阶段未被利用，迭代从零视差开始；
    3. 上下文传播仅在局部邻域内进行（如 ConvGRU），限制了全局推理能力。
- **退化场景的挑战**：在水下环境中，波长衰减、散射和对比度损失严重破坏光度一致性，使得局部匹配更加困难，成为跨域泛化的极端测试。
- **目标**：设计一个能够以线性计算成本实现全局上下文传播的迭代更新算子，从而提升退化场景下的鲁棒性和泛化能力。

## 2. 方法论：核心思想与关键技术细节

### 整体框架
LinStereo 基于 **Depth Anything V3（DA3）** 骨干，冻结编码器，仅训练解码器。解码器由三个互补组件构成：
- **Hierarchical Semantic Cost Volumes (HSCV)**：解决“匹配什么”。
- **Depth Prior Initialization (DPI)**：解决“从哪开始”。
- **Position-Aware Linear Attention (PALA) Updater**：解决“如何更新”。

### 关键技术细节

#### (1) 特征提取（共享）
- 使用 DA3（DINOv2 ViT-B/14 + Dual-DPT head）一次前向获得：
  - 多尺度特征 `{FL,s, FR,s}`，s ∈ {4,8,16}，经投影到统一通道 cf=128。
  - 单目深度图 `D̂_mono`（仿射不变）。

#### (2) Hierarchical Semantic Cost Volumes (HSCV)
- 针对每个尺度 s 独立构建 1D 相关体：
  ```
  C_s(i,j,d) = (1/√cf) · ⟨F̂_L,s(i,j), F̂_R,s(i, j-d)⟩
  ```
- 每个尺度的相关体进一步构建视差方向的金字塔（4层），以覆盖更大搜索范围。
- 特点：不同于以往只用一个固定尺度的相关体，HSCV 保持所有尺度同时可用，PALA 每次迭代都可按需查询任意尺度。

#### (3) Depth Prior Initialization (DPI)
- 将 DA3 输出的仿射不变深度图转换为度量视差初始化。
- 采用尺度-偏移对齐：
  - 使用 SIFT 在立体对间匹配稀疏点，获得对应视差参考。
  - 最小二乘解算参数 α, β：
    ```
    (α*, β*) = argmin Σ ||d_sp_k - (α/D̂_mono(p_k) + β)||²
    ```
  - 初始化视差：`d^(0) = α*/D̂_mono + β*`
- 若内点数不足 Kmin=20，回退到零视差初始化（本文中仅1%帧发生）。
- 注意：SIFT 仅提供粗匹配，后续迭代会细化。

#### (4) Position-Aware Linear Attention (PALA) Updater
- 在每个尺度使用一个 PALA 块，共三个，按粗到细顺序更新隐藏状态。
- **PALA 块结构**：
  - 输入：当前视差估计 d^(t)_s → 从 HSCV 查找相关特征 c^(t)_s → 运动编码 m^(t)_s。
  - **线性注意力**：使用核函数 ϕ（如 ReLU 后的线性映射）将 Q、K 映射到非负空间，计算 KV 乘积 ⇒ O(N·C_h²) 复杂度。
  - **位置感知**：引入 **2D Rotary Position Embeddings (RoPE)** 到 Q、K，但仅用于分子（`Q̃ K̃^T V`），分母保留原始 `Q̂` 和 `K̂` 的均值进行归一化，避免位置依赖的放大失真。
  - **局部空间编码**：在 Value 分支附加局部卷积（条件位置编码，CPE），强化邻域平滑性。
  - **绝对位置编码**：在块前后添加坐标嵌入。
  - **自适应门控**：使用 sigmoid 门控 zg 控制历史状态与新证据的融合：
    ```
    h_new = (1−zg)⊙h + zg⊙tanh(O)
    ```
    使得在可靠区域大胆更新，不确定区域保留估计。
- 更新策略：三个尺度按 coarse-to-fine 顺序传播隐藏状态，最终从尺度 4 输出视差残差 Δd^(t)。

### 损失函数
- 训练时 T=8 次迭代，指数加权（γ=0.9）累加 L1 损失、边缘平滑损失和梯度损失。

## 6. 主要结论与发现

1. **全局注意力的有效性**：PALA 以 O(N) 复杂度实现全局上下文传播，在遮挡区域（如 Middlebury Occluded）EPE 降低 37%，远优于局部循环方法。
2. **多尺度相关体的必要性**：HSCV 保留每个尺度的相关体供每次迭代查询，比单尺度或多尺度池化效果更好。
3. **深度先验初始化的作用**：DPI 提供几何可解释的初始视差，减少早期迭代对粗布局恢复的浪费，与 PALA 结合实现少于 8 次迭代收敛。
4. **强跨域泛化**：仅用 SceneFlow 训练，LinStereo 在水下基准（TartanAir-UW、SQUID）上超越所有方法（包括使用额外数据训练的），表明其能有效将可靠估计从纹理丰富区域传播到退化区域。
5. **效率与精度平衡**：在 T=2 的实时模式下，仍在水下数据集上达到 AbsRel 0.05（SQUID），远优于所有轻量级方法。

## 7. 优点

- **创新性的注意力设计**：PALA 通过不对称 RoPE 在保持线性复杂度的同时恢复了空间结构感知，解决了标准线性注意力的位置盲点问题。
- **系统性地弥补信息鸿沟**：从“匹配什么”（HSCV）、“从哪开始”（DPI）、“如何更新”（PALA）三条路径分别解决骨干-更新器接口的瓶颈，形成有机整体。
- **极低的数据依赖**：仅用合成 SceneFlow 训练，即可在真实水下场景取得最优泛化，说明模型提取了跨域鲁棒的几何表征。
- **快速收敛**：仅需 8 次迭代即达到最佳精度（更多迭代无改善），相比 RAFT-Stereo 通常需要 12~32 次迭代，效率更高。
- **开放贡献**：开源代码，并发布了新的水下合成数据集 SeaStereo-Dataset（40K 对，物理水下光学模型），推动领域研究。

## 8. 不足与局限

- **骨干依赖导致高计算量**：94% 的参数来自冻结的 DA3（ViT-B），整体推理延时仍较高（T=2 为 80ms），难以在边缘设备实时运行。骨干蒸馏或替换为轻量模型是未来方向。
- **DPI 依赖经典特征**：SIFT 匹配在极低纹理或严重模糊场景可能失效，虽然文中提及回退机制（仅 1% 帧），但引入轻量学习型匹配器可能提升鲁棒性。
- **水下实验覆盖有限**：SQUID 数据集仅 57 对真实图像，且场景类型有限（主要为浅水近场）；实验室水箱的目标为规则结构件，缺乏自然水下场景的多样性。
- **其他退化场景未测试**：论文聚焦水下，但立体匹配同样受雾、雨、夜晚等影响，未验证在这些场景的泛化能力。
- **Booster 基准上的性能稍弱**：在透明/镜面物体最多的 Booster（Bad-2=9.93）上略逊于 Stereo Anywhere（9.91），尽管差距很小，但表明全局注意力在极端的非朗伯表面仍存在挑战。
- **训练策略单一**：仅使用 SceneFlow 进行训练，未探索联合训练或多阶段训练，可能限制了潜力。
