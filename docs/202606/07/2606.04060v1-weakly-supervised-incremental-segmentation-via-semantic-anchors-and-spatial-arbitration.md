## 摘要
弱监督增量学习用于语义分割（WILSS）面临噪声监督持续引入的问题，这逐步破坏类别级表示，导致严重的特征漂移和语义损坏，从而使新学习的类别覆盖旧类别。为解决这些问题，我们提出一种具有漂移鲁棒性的WILSS方法，名为SASA，旨在通过语义锚点与空间仲裁稳定语义学习。具体地，在表示层面，我们引入可学习令牌的语义锚点作为刚性类别级参考，以保留长期语义身份。与之互补，弹性残差适应实现受控的、实例特定的细化，确保稳定且灵活的学习轨迹。在监督层面，我们开发了一种空间标签仲裁机制，执行几何感知决策以直接过滤不可靠信号，并强制执行严格的“一个对象，一个类别”约束。通过协同稳定表示和提高监督可靠性，SASA有效减轻了弱监督下的特征漂移。在标准基准上的大量实验表明，我们的方法持续优于现有最先进方法，尤其是在具有挑战性的多步增量设置中。代码可在https://github.com/ZhonggaiWang/SASA获取。

## Abstract
Weakly Incremental Learning for Semantic Segmentation (WILSS) suffers from the continuous introduction of noisy supervision, which progressively corrupts class-level representations, leading to severe feature drift and semantic corruption, thereby causing newly learned classes to overwrite old ones. To address these issues, we propose a drift-resilient WILSS approach, named SASA, designed to stabilize semantic learning via Semantic Anchors and Spatial Arbitration. Specifically, at the representation level, we introduce semantic anchors of learnable tokens as rigid class-level references to preserve long-term semantic identity. Complementary to this, an elastic residual adaptation facilitates controlled, instance-specific refinement, ensuring a stable yet flexible learning trajectory. At the supervision level, we develop a Spatial Label Arbitration mechanism that performs geometry-aware decisions to directly filter unreliable signals and enforce a strict "one object, one class" constraint. By synergistically stabilizing representations and improving supervision reliability, SASA effectively mitigates feature drift under weak supervision. Extensive experiments on standard benchmarks demonstrate that our approach consistently outperforms existing state-of-the-art methods, particularly in challenging multi-step incremental settings. The code is available at https://github.com/ZhonggaiWang/SASA.

## 一、核心问题与整体含义（研究动机与背景）

- **问题定义**：弱监督增量语义分割（Weakly Incremental Learning for Semantic Segmentation, WILSS）旨在从图像级标签（而非像素级标签）逐步学习新类别，同时保持对旧类别的记忆。然而，这种设置下，通过CAM生成的伪标签天然具有稀疏性和噪声，且噪声会随增量步骤累积，导致**特征漂移（Feature Drift）**——新类别特征向旧类别簇偏移，旧类别特征分布被侵蚀，最终出现**类覆盖（class overwriting）**。
- **现有方法局限**：现有工作要么仅通过增强弱监督质量（如CAM细化、利用基础模型生成密集伪掩码）来缓解，要么通过蒸馏或正则化保持旧知识，但均未从根本上阻止噪声信号的反复注入。当监督信号存在内在矛盾（如CAM对新类激活不足、旧模型将新类误判为旧类），这些方法会放大偏差。
- **核心洞察**：WILSS的关键挑战不在于弱标签的“不完美”，而在于持续噪声导致有偏且累积的训练信号，仅靠伪标签精炼无法可靠纠正——因为一旦语义参考本身（类原型）变得不稳定，后续修正只能治标不治本。

- **本文目标**：提出一个**漂移鲁棒（drift-resilient）**的WILSS框架SASA，通过稳定类级表示（刚性语义锚点）和空间级监督去噪（空间标签仲裁）两个维度，从根本上抑制特征漂移。

## 二、方法论：核心思想、关键技术细节

### 1. 整体框架（SASA）

- 由两个并行组件构成：
  - **Drift-Resilient Semantic Anchors (DSA)**：在表示层面稳定语义学习。
  - **Spatial Label Arbitration (SLA)**：在监督层面过滤空间结构噪声。
- 框架使用ViT-B作为骨干，分割logits由像素特征与最终令牌（Final Tokens）的余弦相似度计算（式2），无需额外mask解码器。SLA仅在训练阶段使用。

### 2. Drift-Resilient Semantic Anchors (DSA)

- **刚性语义锚点（Rigid Anchors）**：  
  为每个类别维护一个可学习的令牌 **A_t ∈ R^{|C_{0:t}|×D}**，作为类别在嵌入空间中的刚性、稳定坐标。通过优化A_t最大化类间可分离性，同时保持长期语义身份。

- **弹性残差令牌（Elastic Residual Tokens, ERT）**：  
  为了在不破坏全局语义结构的前提下适应实例级变化，引入残差令牌 **R_t**，通过交叉注意力生成（锚点A_t作为Query，特征图F作为Key/Value，式1）。最终令牌 **Z_t = A_t + R_t**。  
  为防止残差过度偏离，施加L2正则化： **L_reg = |R_t|₂²**。

- **令牌监督与正则化**：
  - 分割损失L_seg使用交叉熵，监督信号为真实标签（第0步）或仲裁后的伪标签（后续步）。
  - 类分离损失 **L_sep**（式3）：约束最终令牌Z_t与其对应锚点A_t高相似，与其他锚点低相似（实例弹性策略）。
  - 蒸馏损失 **L_dist**（式4）：对旧类别锚点施均匀范数约束，保留旧知识。
  - 总损失：L = L_cls（图像级分类损失，生成CAM）+ λ_seg L_seg + λ_sep L_sep + λ_dist L_dist + λ_reg L_reg。

### 3. Spatial Label Arbitration (SLA)

- **动机**：WILSS中最有害的噪声常具空间结构性（如一个对象内新旧类标签冲突）。SLA利用类无关对象掩码（由SAM或Maskformer生成）强制执行“一对象一类别”约束。

- **空间可靠性图**：  
  对每个掩码m_i，基于像素到质心的欧氏距离，以高斯衰减赋予像素权重w_p（式5），区分语义核心与边界噪声。

- **加权仲裁**：
  1. 计算新类信号Y_new在掩码内的激活密度ρ_i（式6）。
  2. 若ρ_i > 阈值τ（实验设为0.6），候选集K设为当前步新类别C_t；否则K保持为所有旧类别C_{0:t-1}。
  3. 在候选集上执行加权多数投票（式7），得到该掩码的最终标签ŷ_i，并传播给掩码内所有像素。
  4. 仲裁后的伪标签Y用于监督L_seg。

- **效果**：将碎片化、矛盾的像素级信号转化为空间一致的监督，消除旧模型预测与CAM之间的冲突。

## 三、实验设计

- **数据集**：
  - **PASCAL VOC 2012**（增强版，10582张图片），包含20个类别。
  - **MS COCO**（80类别），用于跨数据集实验COCO-to-VOC（先学60个COCO类，再增量学习剩余VOC类）。

- **增量设置**（均采用重叠场景（overlap），即新类与旧类同时出现在训练图像中）：
  - VOC：15-5（2步）、10-10（2步）、10-5（3步）、10-2（6步）。
  - COCO-to-VOC：2步。

- **评估指标**：mIoU（分别报告旧类、新类、全部）。

- **基线方法**：
  - 全监督：MiB, PLOP, SDR, RECALL, ALIFE, DKD, STAR, BARM。
  - 弱监督：SEAM, SS, EPS, WILSON, FMWISS, Teddy, ToCo。
  - 上界：Joint（全监督联合训练）。

- **实现细节**：
  - 骨干：ViT-B/16（统一使用，以保证公平对比）。
  - 优化：线性warm-up（1e-6→6e-5），多项式衰减；增量步学习率2e-5；VOC训练8k迭代，COCO-to-VOC训练20k。
  - 损失权重：λ_seg=0.2, λ_sep=0.2, λ_dist=0.1, λ_reg=0.05；SLA阈值τ=0.6。

## 六、主要结论与发现

1. **SASA在几乎所有设置下均达到新的SOTA**，尤其在多步（10-2）和跨数据集（COCO-to-VOC）场景中提升显著（分别超过WILSON 19.0和6.9个mIoU点）。
2. **刚性锚点+弹性残差的组合有效抑制特征漂移**，使旧类特征保持紧凑，新类特征被分配稳定坐标，避免类覆盖。
3. **空间标签仲裁显著提升伪标签质量**，通过几何感知一致性消除同一对象内的标签冲突，是监督层面抗噪的关键。
4. 消融实验表明：**DSA和SLA对最终性能的贡献是互补的**（DSA侧重表示稳定，SLA侧重监督净化），两者结合增益最大。
5. 超参数分析显示，合理设置损失权重（λ_sep=0.2, λ_dist=0.1, λ_sep=0.2）和SLA阈值（τ=0.6）是达到最优性能的必要条件。

## 八、不足与局限

1. **骨干网络单一**：所有实验仅使用ViT-B，未在ResNet或其他轻量骨干上验证泛化性。而很多早期方法（如WILSON）基于ResNet，本文在对比时也仅使用了ViT版本，可能带来fairness bias。
2. **对SAM的依赖**：SLA需要预训练的类无关分割器（如SAM）生成对象掩码，这引入了额外计算和内存开销，且在弱监督场景下如何选择最优对象分割器未讨论。
3. **未报告计算开销**：缺少训练时间、推理速度、参数量的对比，无法评估实际部署成本。尤其在多步增量中，每一步都需重新生成SAM掩码，在实践中可能昂贵。
4. **背景类处理不够深入**：WILSS中背景类定义复杂（可能包含旧类、新类、未定义类），论文虽用冻结旧模型填充背景，但SLA仲裁时如何区分背景与“旧类未激活”区域未详细分析。
5. **跨数据集扩展性有限**：仅测试了COCO→VOC（60类+20类），未覆盖其他跨域场景（如Cityscapes→VOC），也不涉及更细粒度或长尾数据集。
6. **超参数过多**：损失权重λ_seg, λ_sep, λ_dist, λ_reg及阈值τ共5个超参数，需在验证集上调优，可能对用户不友好。论文虽给出敏感性分析，但未提供自动调优策略。
7. **潜在偏差风险**：SLA仲裁基于密集对象掩码，若SAM在复杂场景（遮挡、小目标）中产生错误掩码，可能传递错误的对象级标签，文中未分析此类失效模式。
