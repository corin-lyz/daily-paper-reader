## 摘要
全球福祉通常依赖于对航空和卫星影像的正确解读。基于此类影像采取行动（如绘制洪水淹没区域、作物范围或受损基础设施）需要像素级分割以确保完美的类别定位。预训练的通用基础模型在直接应用时，常常遗漏重要特征，并非总能找到场景中的所有类别，尤其会忽略那些最关键的小目标。我们使用一个消费级GPU运行视觉-语言模型（VLM）来提供这缺失的引导，改善分割质量，同时生成结构化且可审计的证据，这些证据驱动结果并可以独立检查。我们融合了三种方法：标记每个像素的冻结基础模型，以及对VLM的两次查询——一次用于选择重要类别，另一次用于定位基础模型遗漏的小物体。在四个航空数据集上的评估显示，在基础模型胜任的每个阶段均获得了一致的改进。

## Abstract
Global welfare often depends on the correct interpretation of aerial and satellite imagery. Acting on such imagery (mapping flooded ground, crop extent, or damaged infrastructure) demands pixel-level segmentation to ensure perfect class localization. Pretrained general foundation models, when applied directly, often miss important features and cannot always find all the classes belonging to a given scene, overlooking smaller objects that matter most. We use a single consumer-grade GPU running a vision-language model (VLM) to supply this missing guidance, improving segmentation while producing structured, auditable evidence that drives the result and can be inspected on its own. We fuse three approaches: the frozen foundation model that labels every pixel, and two queries to a VLM, one to choose the classes that matter, and one to locate the small objects the base model misses. Evaluating across four aerial datasets, we see consistent gains at each stage where the base model is competent.

## 1. 核心问题与总体含义（研究动机与背景）

- **研究背景**：航空影像（航拍/卫星）的像素级语义分割是洪水制图、作物监测、基础设施巡检等决策任务的基石。传统方案需针对特定领域从头训练或微调大规模模型，成本高昂且难以随类别变化快速更新。
- **核心问题**：
  - 通用预训练分割基础模型直接用于航拍场景时，缺少“该图像中哪些类别真正存在”的场景级判断，且容易漏掉小、稀疏但关键的对象（如人员、车辆、标牌）。
  - 开放词汇/免词汇方法在专业领域中存在类别命名不一致、词汇选择不可靠等问题。
- **总体主张**：问题不在于模型结构或训练数据规模，而在于**推理时的选择与引导**。一个通用基础模型已编码了足够多的相关知识，缺的只是：哪些词汇适用于当前图像、以及小目标在哪里。通过在两模型之间进行推理时协作，可以低成本获得更好的零样本分割，并产生可审计的证据链。
- **核心思路**：“限制（词汇），而非重训（模型）”——限制通用模型在推理时使用的类别集合，比训练新模型更经济有效。

## 2. 方法论

### 2.1 总体框架
- 冻结的基础分割模型（Frozen Foundation Model）：在约 150 类的自建领域词汇表（以 ADE20K 为基础手工调整）上进行逐像素标注。
- 同一个 VLM（仅选用 **Qwen-VL**，经筛选后确定）被查询两次，提供基础模型缺失的两类信息：
  - **Stage 2（ACW）**：选择图像中出现的关键类别并加权。
  - **Stage 3（MCI）**：用边界框定位被遗漏的小目标。
- 全程不重训任何模型；VLM 的每次输出都是可读的列表或框，方便审计。

### 2.2 Stage 1：基础分割（Baseline + 可选微调）
- 将 150 类词汇表（面向航空场景手工调整）用于基础模型推理；
- 可选地对各数据集标注的类别（6~24 类）进行轻量微调作为“锚点”，其余类别通过零样本嵌入关系获得；作者指出航空类别在预训练中已充分表征，微调并非关键。

### 2.3 Stage 2：自动类别加权（ACW）
- 对每张图像 I，由 VLM 从 150 类词汇 C 中选出显著类别集 B_I；
- 权重公式（式 1）：
  - w_c = W_boost（若 c ∈ B_I，W_boost=100）或 W_neutral（否则，W_neutral=0/1）
- 将权重相乘到逐像素 logits 上再作 softmax 与 argmax（式 2）；
- 类别集 B_I 通过两段式提示获得：第一遍链式思考（CoT）全局+细节分析，第二遍复查补漏，最后输出 Python 可解析的类别列表与权重字典；
- 类别选择质量用 Precision/Recall/F1 评估（式 4）。

### 2.4 Stage 3：少数类识别（MCI）
- 对 Stage 2 后仍未获得任何像素的“少数类”目标，向 VLM 查询其**边界框**；
- 边界框由类无关分割器（SAM）填充为精确像素掩码，再与 Stage 1+2 结果合并；
- 合并策略：新类别直接涂入；已存在类别仅在按类 IoU 得分更高时替换像素；
- 该阶段使最终结果有时超过“Oracle（完美类别选择上限）”，因其能恢复基础模型无法像素级定位的少数类。

## 3. 实验设计

### 3.1 数据集
- **UAVid**：8 类，城市无人机视频，多视角/俯仰角变化大；
- **Aeroscapes**：11 类，多样化航拍视角，视角较一致；
- **DroneSeg**：24 类，地理多样；
- **UDD6**：6 类，校园/城市屋顶，几乎全是垂直俯视图。

### 3.2 Benchmark 与评估协议
- 采用**交叉数据集零样本评估**：在数据集 A 上微调 checkpoint，在数据集 B 上零样本测试（4 个 finetune checkpoint × 4 个测试集）；
- mIoU 计算时将 150 类词汇映射到各数据集 GT 类别；
- GT 仅用于评估指标（mIoU），不参与加权、提示或 MCI；
- 移除 GT 中的“catch-all”类别（如 Clutter、Unlabeled），因为这类标注会错误惩罚正确预测。

### 3.3 对比方法 / 条件
- **基线**：Stage 1 无权重分割；
- **Oracle 类别选择**：使用 GT 类别集合（上限基准）；
- **随机类别加权**：随机选取 30 个类提升权重（下界）；
- **VLM（Qwen）自动选择**：本文方法；
- **VLM 筛选**：对比过 GPT-4o、Claude、Gemini，均无法在航拍图上定位边界框，故仅 Qwen-VL 被采用。

## 6. 主要结论与发现

- **基础模型胜任的场景中，逐阶段增益一致且显著**：Aeroscapes 与 DroneSeg 上 ACW（Stage 2）提升约 +7 mIoU 点（p < 0.0001），MCI（Stage 1→3）累计再提升约 +15 mIoU 点（p < 0.0001）。
- **ACW 与 MCI 互补**：当 ACW 无效时（如 UDD6 上的 −0.62），MCI 仍可恢复小类别并带动整体（全流程可达 +37% 于单张图）；反之亦然。
- **限制词汇本身是主要增益来源**：w 从 0 到 10 的首次非零权重就带来了几乎全部增益，此后平缓至 w=500，说明该方法对权重超参数稳健。
- **类别选择质量而非加权行为本身决定效果**：随机加权在某些数据上甚至不如不加权（积极抑制了正确类别），VLM 选择与 Oracle 接近（差距 ≤ 0.6 mIoU）。
- **VLM 的空间定位能力是当前的主要瓶颈**：对倾斜视角（UAVid）与部分商业模型的框定位精度不够，导致 MCI 失效，说明定位比类别发现更有挑战。

## 7. 优点

- **创新性**：将“推理时轻量引导”应用于航空零样本分割，不重训基础模型，突破了领域模型必须重训/微调的传统路径。
- **可审计性**：VLM 输出结构化类别列表、权重字典和边界框，便于追溯和人工复核，契合决策支持系统的需求——且不依赖 CoT 叙述本身作为解释，避免“解释不忠实”问题。
- **互补性设计**：ACW 与 MCI 两种机制面向不同失败模式，相互独立、可单独适用，框架具通用性（可扩展至医疗、工业等）。
- **实验严谨性**：多数据集交叉验证、配对 t 检验、3 种子去随机化、Oracle/Random 上下界清晰、mIoU 保守下限意识明确（catch-all 类别清理）。
- **计算成本极低**：单消费级 GPU 可完成推理；微调仅需数小时。

---

## 8. 不足与局限

- **VLM 空间定位能力受限**：在视角多变（UAVid）下边界框漂移，MCI 失效。论文只选了 Qwen-VL，GPT-4o 等均因框定位不可用被筛除，通用性受限。
- **mIoU 度量对少数类不敏感**：小目标即使完美恢复，像素占比过低，mIoU 几乎不体现；少数类恢复效果主要靠定性证据（图像展示），定量支撑不足。
- **基准粗粒度偏差**：UDD6 仅 6 个粗类别，150 类精细语义无处安放，导致正确细粒度预测被误判为错误，mIoU 偏低；论文称其为“保守下界”，但这使横向比较口径复杂化。
- **实验范围有限**：没有与现有 SOTA 的开放词汇/零样本分割方法做横向对比；VL M调用的 API 延迟高，尚未在真实“边缘设备”场景实测。
- **类选择偏置风险**：VLM 可能选择 GT 中不存在但视觉合理的类别（作者提及这正是 VLM 可超过 Oracle 的原因），在严格评估中这种“超出标注的合理输出”会人为拉低指标，需要更细粒度 GT 才能解决。
- **多视角问题**：UAVid 上多数图像 VLM 无法定位框，论文回避了为何给定视角会显著降低 grounding 能力的具体机制分析，仅引用外部工作。
